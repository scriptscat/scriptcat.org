本文档站点（docs.scriptcat.org，以下简称「本站」）由 ScriptCat 团队开发并运营。本政策仅适用于本站，我们的其他产品各有独立政策：

- 浏览器扩展：[ScriptCat 隐私政策](./privacy.md)
- 脚本站：见 [scriptcat.org](https://scriptcat.org/) 站内公布的隐私政策

最后更新：2026-08-25

## 一、我们不收集什么

浏览本站无需注册或登录。我们不会主动向你索取姓名、邮箱、手机号等身份信息，也不会为你建立账号。除下文列出的第三方服务，以及你主动提交的内容外，我们不会收集可直接识别你身份的信息。

## 二、我们使用的第三方服务

| 服务 | 用途 | 涉及的数据 |
| --- | --- | --- |
| Google Analytics | 统计访问量与页面浏览情况 | Cookie；已启用 IP 匿名化；页面地址、来源、浏览器与设备的概要信息 |
| Google AdSense | 在部分页面展示广告 | Cookie 或类似的设备标识，用于广告投放、频次控制与效果统计 |
| Algolia DocSearch | 站内搜索 | 你输入的搜索词会发送至 Algolia 以返回结果 |
| ScriptCat 服务器 | 获取 GitHub Star 数等公开统计 | 网络请求本身携带的信息，如 IP 地址与浏览器类型 |

这些服务由各自的提供方独立运营，其数据处理适用各自的隐私政策。

## 三、浏览器本地存储

为了记住你的偏好（例如亮色 / 暗色主题的选择、已经按浏览器语言跳转过哪个语言版本），以及缓存少量公开数据以减少重复请求，本站会在你的浏览器本地保存一些信息。这些信息只留在你的设备上，不会上传至我们的服务器，清除浏览器数据即可删除。

## 四、Cookie 与广告

本站及其第三方服务会使用 Cookie 或类似技术：Google Analytics 借此区分访客、统计访问情况；本站展示广告时，包括 Google 在内的第三方供应商会使用 Cookie，根据你此前对本站或其他网站的访问投放广告。

你可以：

- 通过 [Google 广告设置](https://www.google.com/settings/ads) 关闭个性化广告；
- 通过 [aboutads.info](https://www.aboutads.info/choices/) 管理第三方广告 Cookie；
- 在浏览器设置中阻止第三方 Cookie。

## 五、你主动提交的内容

卸载反馈页会将你选择的卸载原因与填写的反馈内容提交至我们的服务器，用于改进产品。该表单不要求填写任何身份信息，请勿在其中填写个人敏感信息。

## 六、数据保留与安全

统计与反馈数据仅在达成上述目的所必需的期间内保留。本站通过 HTTPS 传输，文档站本身不存储账号、密码等敏感数据。

## 七、你的权利

你可以随时清除浏览器的本地存储与 Cookie，或按第四节的方式退出个性化广告。如你希望了解我们持有的与你有关的信息、要求删除你提交过的反馈内容，或对我们的处理方式提出异议，请通过下一节的邮箱与我们联系。由于本站不建立账号，我们通常无法把某条记录对应到具体的人，联系时请尽量提供可供查找的线索（例如提交反馈的大致时间）。

## 八、政策更新与联系方式

本政策如有更新，将直接在本页发布。如对本政策有任何疑问，请通过 [yz@ggnb.top](mailto:yz@ggnb.top) 与我们联系。
