v1.4 یک بهروزرسانی بزرگ برای ScriptCat است که سیستم کاملاً جدید **Agent** را معرفی میکند و به کاربران امکان میدهد اقدامات مرورگر را خودکار کنند، دادههای وب را استخراج کنند، فایلها را مدیریت کنند و وظایف زمانبندیشده را از طریق گفتگوی زبان طبیعی اجرا کنند.

## Agent

نقطه ورود جدیدی برای چت Agent به داشبورد اضافه شده است که میتوانید گفتگوی چندمرحلهای با مدل هوش مصنوعی داشته باشید؛ هوش مصنوعی بهطور خودکار ابزارهای داخلی را برای تکمیل وظایف فراخوانی میکند.

**قابلیتهای اصلی:**

- **پشتیبانی از چند مدل** — فرمتهای سازگار با OpenAI و بومی Anthropic، با پشتیبانی از Prompt Caching
- **۱۱ ابزار داخلی** — دریافت/جستجوی وب، مدیریت تب، سیستم فایل OPFS، اجرای کد، تعامل با کاربر و موارد دیگر
- **سیستم Skill** — بستههایی از دستورها + اسکریپتهای ابزار + مواد مرجع که دانش حوزه Agent را گسترش میدهند
- **یکپارچهسازی MCP** — پشتیبانی از [Model Context Protocol](https://modelcontextprotocol.io/) برای اتصال به سرورهای ابزار خارجی
- **اتوماسیون DOM** — پیمایش صفحه، اسکرینشات، کلیک، پر کردن، اسکرول، اجرای اسکریپت و موارد دیگر
- **وظایف زمانبندیشده** — زمانبندی وظایف بر اساس عبارات Cron (حالتهای داخلی / رویدادی)
- **زیر-نمایندهها** — میتوانند نمایندههای فرعی مستقل برای انجام وظایف فرعی پیچیده ایجاد کنند
- **مدیریت زمینه** — فشردهسازی خودکار و Prompt Caching برای کاهش مصرف توکن

**API اسکریپت (`CAT.agent.*`):**

اسکریپتهای کاربری میتوانند قابلیتهای Agent را از طریق فضای نام `CAT.agent.*` فراخوانی کنند، از جمله APIهای conversation، dom، skills، task، model، opfs و mcp. هر API نیازمند اعلام مجوز مربوطه با `@grant` است.

**۶ صفحه داشبورد:** چت، پیکربندی مدل، مدیریت Skill، وظایف زمانبندیشده، سرورهای MCP و مرورگر OPFS.

## پشتیبانی از برچسب `@unwrap`

به اسکریپت اجازه میدهد مستقیماً در صفحه تزریق شود و از پوشش سندباکس عبور کند.

## رویداد `window.onurlchange`

شنود رویداد تغییر URL سازگار با Tampermonkey را با استفاده از Navigation API پیادهسازی میکند.

## بهبودهای ویرایشگر

منوی ویرایش (جستجو، جایگزینی، واگرد و…) اضافه شد و چند مشکل میانبر صفحهکلید و راهنما رفع شد.

## موتورهای جستجوی چندپلتفرمی

کشف اسکریپت اکنون امکان انتخاب بین پلتفرمهای مختلف موتور جستجو را فراهم میکند.

## ارائهدهندگان آیکون بیشتر

ارائهدهندگان خدمات آیکون بیشتری برای اسکریپتها اضافه شدند.
