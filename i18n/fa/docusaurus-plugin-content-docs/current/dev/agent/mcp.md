---
title: یکپارچه‌سازی MCP
---

MCP ([Model Context Protocol](https://modelcontextprotocol.io/)) به Agent اجازه می‌دهد به سرورهای MCP خارجی متصل شود و به طور خودکار به ابزارها، منابع و الگوهای prompt ارائه‌شده توسط آن‌ها دسترسی پیدا کند.

> برخلاف سایر زیرسیستم‌های Agent، سرورهای MCP در حال حاضر **فقط توسط کاربر در صفحه مدیریت قابل پیکربندی هستند** — هیچ API مدیریت `CAT.agent.mcp` برای اسکریپت‌ها وجود ندارد. تنها چیزی که یک اسکریپت می‌تواند مشاهده کند این است که ابزارهای این سرورها به طور خودکار در طول گفتگوها فراخوانی می‌شوند.

## پیکربندی یک سرور MCP

یکی را در صفحه مدیریت → **Agent → MCP** اضافه کنید:

| فیلد | توضیحات |
|------|------|
| نام | نام نمایشی سرور |
| URL | نقطه پایانی Streamable HTTP (JSON-RPC 2.0 از طریق POST) |
| کلید API | اختیاری، برای احراز هویت |
| هدرهای سفارشی | اختیاری |
| فعال | آیا سرور فعال است |

کلاینت MCP ScriptCat از انتقال **Streamable HTTP** استفاده می‌کند و از نسخه پروتکل `2025-03-26` پشتیبانی می‌کند.

یک سرور MCP می‌تواند سه نوع قابلیت ارائه دهد:

| قابلیت | توضیحات |
|------|------|
| **ابزارها** | به طور خودکار به عنوان ابزارهایی که Agent می‌تواند فراخوانی کند ثبت می‌شوند |
| **منابع** | منابع قابل خواندن (متن/دودویی) |
| **Prompts** | الگوهای prompt، با پشتیبانی از پارامترها |

## استفاده در یک گفتگو

ابزارهای سرورهای MCP فعال به طور خودکار در فهرست ابزارهای موجود برای گفتگوهای Agent ظاهر می‌شوند، با نام‌گذاری بر اساس الگوی `mcp_{نام پاک‌شده سرور}_{toolName}` — هوش مصنوعی بر اساس قصد کاربر تصمیم می‌گیرد که آیا آن‌ها را فراخوانی کند. این مشابه نحوه بارگذاری خودکار [Skillها](../skill-install) کار می‌کند؛ توسعه‌دهندگان اسکریپت معمولاً نیازی به نگرانی درباره جزئیات زیربنایی ندارند.

برای بررسی اینکه آیا یک ابزار MCP خاص در دسترس است، کافی است مستقیماً در یک گفتگو از هوش مصنوعی بپرسید، یا فهرست ابزارهای کشف‌شده را در جزئیات آن سرور در صفحه مدیریت بررسی کنید.
