فایل باید به جای `UserScript` با `UserSubscribe` شروع شود. لینک نصب باید از پسوند `user.sub.js` استفاده کند و باید یک لینک `https` باشد.

یک اسکریپت اشتراک فقط کادر گفتگوی نصب را نشان می‌دهد تا کاربر اشتراک را هنگام نصب تأیید کند؛ به‌روزرسانی‌های بعدی بی‌صدا هستند و کادر گفتگوی به‌روزرسانی فقط در صورت تغییر مجوز `connect` دوباره نشان داده می‌شود.

یک اسکریپت اشتراک واحد می‌تواند لینک‌های نصب چندین اسکریپت را توصیف کند. اسکریپت‌هایی که از طریق حالت اشتراک نصب می‌شوند، به صورت بی‌صدا و بدون کادر گفتگوی تأیید نصب می‌شوند و اسکریپت‌های نصب‌شده همچنان در فهرست اسکریپت ظاهر می‌شوند — اما مجوز `connect` آن‌ها از `connect` اعلام‌شده در اشتراک استفاده می‌کند نه مجوز `connect` خود اسکریپت.

```js
// ==UserSubscribe==
// @name         xxx
// @description  مشترک شدن در سری اسکریپت‌های xxx
// @version      0.1.0
// @author       شما
// @connect      www.baidu.com
// @scriptUrl    https://script.tampermonkey.net.cn/48.user.js
// @scriptUrl    https://script.tampermonkey.net.cn/49.user.js
// ==/UserSubscribe==
```

## به‌روزرسانی‌های اشتراک و به‌روزرسانی‌های اسکریپت

طبق «بازه به‌روزرسانی» پیکربندی‌شده توسط کاربر، ScriptCat به طور دوره‌ای لینک اشتراک را برای به‌روزرسانی بررسی می‌کند؛ برای اعمال این امر باید `version` پیکربندی شود.

هر به‌روزرسانی یا تغییر اشتراک، لینک‌های اسکریپت را با اسکریپت‌های نصب‌شده فعلی مقایسه می‌کند: اسکریپت‌هایی که دیگر در اشتراک جدید نیستند حذف می‌شوند و اسکریپت‌های تازه اضافه‌شده به صورت بی‌صدا نصب می‌شوند. به‌روزرسانی‌های اسکریپت از `version` خود اسکریپت پیروی می‌کنند و از همان منطق به‌روزرسانی یک اسکریپت معمولی استفاده می‌کنند.

## نصب و به‌روزرسانی بی‌صدا

اسکریپت‌های مشترک‌شده به صورت بی‌صدا نصب و به‌روزرسانی می‌شوند — افزودن، حذف یا به‌روزرسانی یک اسکریپت از اشتراک فقط یک اعلان نشان می‌دهد، بدون نیاز به تأیید مجدد کاربر. به دلیل این مکانیزم به‌روزرسانی بی‌صدا، لطفاً فقط از منابعی که به آن‌ها اعتماد دارید اشتراک بگیرید.


## metadata

معنای برخی از فیلدهای فراداده در یک اسکریپت اشتراک تغییر می‌کند.

### name

نام اشتراک (همچنین می‌تواند مستقیماً در فهرست اشتراک ویرایش شود)

### description

توضیحات اشتراک، که توصیف می‌کند اشتراک برای چیست

### version

نسخه اشتراک. اگر حذف شود، به‌روزرسانی‌ها در عوض با تغییر محتوای اسکریپت اشتراک فعال می‌شوند.

### connect

مجوز دسترسی برای یک سایت را درخواست می‌کند؛ به `GM_cookie` و `GM_xmlhttpRequest` مراجعه کنید. برای اسکریپت‌هایی که از طریق حالت اشتراک نصب می‌شوند، `connect` توسط `connect` اشتراک بازنویسی می‌شود.

### scriptUrl

لینک‌های نصب اسکریپت مورد نیاز اشتراک
