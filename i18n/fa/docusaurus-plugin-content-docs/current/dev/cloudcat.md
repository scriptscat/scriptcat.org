> چندین روش برای اجرا در ابر ارائه شده است؛ برای جزئیات به [محیط‌های اجرا](#running-environments) مراجعه کنید. علاوه بر این، [CloudCat](https://github.com/scriptscat/cloudcat) سرویسی برای اجرای اسکریپت‌های پس‌زمینه در ابر است — یک پلتفرم FAAS که هنوز در حال توسعه است.

⚠ لطفاً توجه کنید ⚠، پس از آپلود به ابر، معنای `once` در عبارت اسکریپت زمان‌بندی‌شده تغییر می‌کند: زمان قبل از `once` هنگام اجرا با حداقل مقدار آن جایگزین می‌شود.

به عنوان مثال:

* `* * once * *` => `0 0 * * *`: یک بار در روز اجرا می‌شود، هر روز ساعت ۰۰:۰۰ اجرا می‌شود
* `* 1-23 once * *` => `0 1 * * *`: یک بار بین 1:00 و 23:00 هر روز اجرا می‌شود، هر روز ساعت 01:00 اجرا می‌شود
* `* 1,3,5 once * *` => `0 1 * * *`: یک بار در ساعت 1:00، 3:00 یا 5:00 هر روز اجرا می‌شود، هر روز ساعت 01:00 اجرا می‌شود
* `* */4 once * *` => `0 0 * * *`: یک بار هر ۴ ساعت هر روز اجرا می‌شود، هر روز ساعت 00:00 اجرا می‌شود
* `* 1-23/4 once * *` => `0 1 * * *`: یک بار هر ۴ ساعت بین 1:00 و 23:00 هر روز اجرا می‌شود، هر روز ساعت 01:00 اجرا می‌شود
* `* 10 once * *` => `0 10 * * *`: یک بار ساعت 10:00 هر روز اجرا می‌شود، هر روز در دقیقه 00 ساعت 10 اجرا می‌شود
* `* * * once *` => `0 0 1 * *`: یک بار در ماه اجرا می‌شود، روز اول هر ماه ساعت 00:00 اجرا می‌شود

## مقادیر توصیفی اضافی CloudCat

یک اسکریپت مرجع: [ورود خودکار Bilibili](https://scriptcat.org/script-show-page/48)

### cloudCat

اعلام این ویژگی به اسکریپت اجازه می‌دهد از طریق `CloudCat` اجرا شود. پس از داشتن این گزینه، دکمه اجرای ابری در فهرست اسکریپت ظاهر می‌شود؛ با کلیک روی آن می‌توانید روش اجرا را انتخاب کنید — به [محیط‌های اجرا](#running-environments) مراجعه کنید.

### exportValue

مقادیری را که باید به ابر صادر شوند توصیف می‌کند؛ اعلام‌های متعدد مجاز است.

```ts
// @exportValue key1,key2,key3
// @exportValue key4,key5,key6
```

### exportCookie

کوکی‌هایی را که باید به ابر صادر شوند توصیف می‌کند؛ اعلام‌های متعدد مجاز است. پارامترها با استفاده از `CookieDetails` از `GM_cookie` توصیف می‌شوند، به عنوان مثال:

```ts
// موارد زیر کوکی با نام cookie1 از https://docs.scriptcat.org/docs/use/ را صادر می‌کند
// @exportCookie url=https://docs.scriptcat.org/docs/use;name=cookie1

// این همه کوکی‌های دامنه scriptcat.org را صادر می‌کند
// @exportCookie domain=scriptcat.org

// همه پارامترهای موجود:
// @exportCookie domain=scriptcat.org;url=https://docs.scriptcat.org/docs/use;name=cookie1;path=/docs/use;secure=true;session=true
```

## محیط‌های اجرا {#running-environments}

### محلی

یک بسته zip صادر می‌کند؛ پس از استخراج در یک پوشه، دستورات زیر را برای اجرای محلی اجرا کنید (به محیط Node.js محلی نیاز دارد):

```bash
npm i
node index.js
```


### Tencent Cloud

ابتدا یک کلید Tencent Cloud در [**کلیدهای دسترسی**](https://console.cloud.tencent.com/cam/capi) ایجاد کنید — اگر از یک زیرحساب استفاده می‌کنید، حتماً مجوز Cloud Function به آن بدهید. سپس سرویس را در [**سرویس تابع**](https://console.cloud.tencent.com/scf/list) فعال کنید، که مقدار معینی استفاده رایگان در هر ماه دارد. منطقه به طور پیش‌فرض شانگهای است؛ در صورت نیاز آن را تنظیم کنید. پس از کلیک روی آپلود، یک تریگر زمان‌بندی‌شده به طور خودکار بر اساس `@crontab` برای اجرای تابع بر اساس برنامه ایجاد می‌شود.
