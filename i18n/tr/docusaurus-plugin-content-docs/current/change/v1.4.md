v1.4, ScriptCat için doğal dil konuşması yoluyla tarayıcı işlemlerini otomatikleştirmenize, web verileri çıkarmanıza, dosyaları yönetmenize ve zamanlanmış görevler çalıştırmanıza olanak tanıyan yepyeni bir **Agent** sistemi sunan büyük bir güncellemedir.

## Agent

Gösterge paneline, bir yapay zekâ modeliyle çok turlu konuşma yapabileceğiniz yeni bir Agent sohbet girişi eklendi; yapay zekâ görevleri tamamlamak için otomatik olarak yerleşik araçları çağırır.

**Temel yetenekler:**

- **Çoklu model desteği** — OpenAI uyumlu ve yerel Anthropic formatları, Prompt Caching desteğiyle
- **11 yerleşik araç** — web getirme/arama, sekme yönetimi, OPFS dosya sistemi, kod yürütme, kullanıcı etkileşimi ve daha fazlası
- **Skill sistemi** — Agent'ın alan bilgisini genişleten prompt + araç betikleri + referans materyali paketleri
- **MCP entegrasyonu** — harici araç sunucularına bağlanmak için [Model Context Protocol](https://modelcontextprotocol.io/) desteği
- **DOM otomasyonu** — sayfa gezinme, ekran görüntüsü, tıklama, doldurma, kaydırma, betik yürütme ve daha fazlası
- **Zamanlanmış görevler** — Cron ifadesi tabanlı görev zamanlama (Dahili / Olay modları)
- **Alt ajanlar** — karmaşık alt görevleri ele almak için bağımsız alt ajanlar oluşturabilir
- **Bağlam yönetimi** — token kullanımını azaltmak için Otomatik sıkıştırma ve Prompt Caching

**Betik API'si (`CAT.agent.*`):**

Kullanıcı betikleri, conversation, dom, skills, task, model, opfs ve mcp API'leri dahil olmak üzere `CAT.agent.*` ad alanı üzerinden Agent yeteneklerini çağırabilir. Her API, ilgili iznin `@grant` ile bildirilmesini gerektirir.

**6 gösterge paneli sayfası:** Sohbet, Model Yapılandırması, Skill Yönetimi, Zamanlanmış Görevler, MCP Sunucuları ve OPFS Tarayıcı.

## `@unwrap` Etiketi Desteği

Bir betiğin kum havuzu sarmalayıcısını atlayarak doğrudan sayfaya enjekte edilmesini sağlar.

## `window.onurlchange` Olayı

Navigation API kullanarak Tampermonkey uyumlu URL değişimi olay dinlemeyi uygular.

## Düzenleyici İyileştirmeleri

Düzenleme menüsü (bul, değiştir, geri al vb.) eklendi ve birçok klavye kısayolu ile ipucu sorunu düzeltildi.

## Çok Platformlu Arama Motorları

Betik keşfi artık farklı arama motoru platformları arasında seçim yapmayı destekliyor.

## Daha Fazla İkon Sağlayıcısı

Daha fazla betik ikonu servis sağlayıcısı eklendi.
