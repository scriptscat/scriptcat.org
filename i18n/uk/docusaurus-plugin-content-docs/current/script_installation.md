---
title: Встановлення скрипта
---

Ця сторінка використовується як проміжний крок для встановлення нового користувацького скрипта в `ScriptCat`.

Після завершення встановлення ця сторінка має автоматично закритися або перенаправити.

Ця сторінка не призначена для безпосереднього перегляду. За потреби відвідайте [Встановлення скрипта](/docs/use/script_installation/).
