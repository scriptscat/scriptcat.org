---
title: Інтеграція MCP
---

MCP ([Model Context Protocol](https://modelcontextprotocol.io/)) дозволяє Agent підключатися до зовнішніх MCP-серверів і автоматично отримувати доступ до інструментів, ресурсів і шаблонів підказок, які вони надають.

> На відміну від інших підсистем Agent, MCP-сервери наразі **можна налаштовувати лише користувачем на сторінці керування** — скриптового API керування `CAT.agent.mcp` не існує. Усе, що може спостерігати скрипт, — це те, що інструменти цих серверів автоматично викликаються під час розмов.

## Налаштування MCP-сервера

Додайте його на сторінці керування → **Agent → MCP**:

| Поле | Опис |
|------|------|
| Ім'я | Відображувана назва сервера |
| URL | Кінцева точка Streamable HTTP (JSON-RPC 2.0 через POST) |
| Ключ API | За бажанням, для автентифікації |
| Власні заголовки | За бажанням |
| Увімкнено | Чи активний сервер |

MCP-клієнт ScriptCat використовує транспорт **Streamable HTTP** і підтримує версію протоколу `2025-03-26`.

MCP-сервер може надавати три види можливостей:

| Можливість | Опис |
|------|------|
| **Інструменти** | Автоматично реєструються як інструменти, які Agent може викликати |
| **Ресурси** | Доступні для читання ресурси (текстові/бінарні) |
| **Підказки** | Шаблони підказок із підтримкою параметрів |

## Використання в розмові

Інструменти з увімкнених MCP-серверів автоматично з'являються в списку інструментів, доступних для розмов Agent, з іменами за шаблоном `mcp_{очищена назва сервера}_{toolName}` — AI вирішує, чи викликати їх, на основі наміру користувача. Це працює подібно до того, як [Skill](../agent-skill-install) завантажуються автоматично; розробникам скриптів зазвичай не потрібно турбуватися про базові деталі.

Щоб перевірити, чи доступний конкретний інструмент MCP, просто запитайте AI безпосередньо в розмові або перевірте виявлений список інструментів у деталях цього сервера на сторінці керування.
