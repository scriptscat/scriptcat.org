Це розширення підтримує три типи скриптів:

- Фонові скрипти
- [Фонові скрипти](./background.md)
- [Заплановані скрипти](./background.md#scheduled-script-crontab)

Фонові скрипти — це те, що люди зазвичай мають на увазі під скриптами Tampermonkey. Фонові скрипти та заплановані скрипти — це типи скриптів, специфічні для розширення ScriptCat — деталі дивіться у відповідній документації.

Ви можете використовувати цю документацію, щоб дізнатися про [API Tampermonkey](./api.md) та [фонові скрипти ScriptCat](./background.md). Ми також підтримуємо сайт [Посібник з розробки скриптів Tampermonkey](https://learn.scriptcat.org/) з великою кількістю навчальних ресурсів — приєднуйтесь до обговорення.

Якщо ви знайдете прогалини в документації, повідомте нам на [GitHub](https://github.com/scriptscat/scriptcat.org) або надішліть PR, щоб допомогти її покращити.
