> Надається кілька способів запуску в хмарі; деталі дивіться в [Середовища запуску](#running-environments). Крім того, [CloudCat](https://github.com/scriptscat/cloudcat) — це сервіс для запуску фонових скриптів у хмарі — платформа FAAS, яка все ще перебуває в розробці.

⚠ Зверніть увагу ⚠, після завантаження в хмару значення `once` у виразі запланованого скрипта змінюється: час перед `once` замінюється його мінімальним значенням під час запуску.

Наприклад:

* `* * once * *` => `0 0 * * *`: запускається один раз на день, виконується о 00:00 щодня
* `* 1-23 once * *` => `0 1 * * *`: запускається один раз між 1:00 і 23:00 щодня, виконується о 01:00 щодня
* `* 1,3,5 once * *` => `0 1 * * *`: запускається один раз о 1:00, 3:00 або 5:00 щодня, виконується о 01:00 щодня
* `* */4 once * *` => `0 0 * * *`: запускається один раз кожні 4 години щодня, виконується о 00:00 щодня
* `* 1-23/4 once * *` => `0 1 * * *`: запускається один раз кожні 4 години між 1:00 і 23:00 щодня, виконується о 01:00 щодня
* `* 10 once * *` => `0 10 * * *`: запускається один раз о 10:00 щодня, виконується о 00 хвилині 10 години щодня
* `* * * once *` => `0 0 1 * *`: запускається один раз на місяць, виконується о 00:00 1-го числа кожного місяця

## Додаткові значення опису CloudCat

Скрипт для довідки: [Bilibili Auto Check-in](https://scriptcat.org/script-show-page/48)

### cloudCat

Оголошення цього атрибута дозволяє скрипту запускатися через `CloudCat`. Коли скрипт має цю опцію, у списку скриптів з'являється кнопка хмарного виконання; натискання дозволяє вибрати метод виконання — дивіться [Середовища запуску](#running-environments).

### cloudServer

> Пов'язано з cloudCat, ще не реалізовано

Адреса сервера cloudCat за замовчуванням


### exportValue

Описує Values для експорту в хмару; дозволено кілька оголошень.

```ts
// @exportValue key1,key2,key3
// @exportValue key4,key5,key6
```

### exportCookie

Описує cookie для експорту в хмару; дозволено кілька оголошень. Параметри описуються за допомогою `CookieDetails` з `GM_cookie`, наприклад:

```ts
// Наступний рядок експортує cookie з іменем cookie1 з https://docs.scriptcat.org/docs/use/
// @exportCookie url=https://docs.scriptcat.org/docs/use;name=cookie1

// Це експортує всі cookie для домену scriptcat.org
// @exportCookie domain=scriptcat.org

// Усі доступні параметри:
// @exportCookie domain=scriptcat.org;url=https://docs.scriptcat.org/docs/use;name=cookie1;path=/docs/use;secure=true;session=true
```

## Середовища запуску {#running-environments}

### Локальне

Експортує zip-пакет; після розпакування його в папку виконайте наступні команди, щоб запустити локально (потрібне локальне середовище Node.js):

```bash
npm i
node index.js
```


### Tencent Cloud

Спочатку створіть ключ Tencent Cloud у [**Ключі доступу**](https://console.cloud.tencent.com/cam/capi) — якщо використовуєте суб-акаунт, обов'язково надайте йому дозволи хмарних функцій. Потім увімкніть сервіс у [**Сервісі функцій**](https://console.cloud.tencent.com/scf/list), який включає певний безкоштовний обсяг щомісяця. Регіон за замовчуванням — Шанхай; за потреби відкоригуйте. Після натискання завантаження автоматично створюється запланований тригер на основі `@crontab` для запуску функції за розкладом.
