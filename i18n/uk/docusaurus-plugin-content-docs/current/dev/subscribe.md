---
title: Режим підписки
---

Файл має починатися з `UserSubscribe` замість `UserScript`. Посилання на встановлення має використовувати розширення `user.sub.js` і має бути посиланням `https`.

Скрипт підписки показує діалогове вікно встановлення лише для того, щоб користувач підтвердив підписку під час встановлення; подальші оновлення виконуються автоматично, і діалогове вікно оновлення знову з'являється лише якщо змінюється дозвіл `connect`.

Один скрипт підписки може описувати посилання на встановлення кількох скриптів. Скрипти, встановлені через режим підписки, встановлюються автоматично, без діалогового вікна підтвердження, і встановлені скрипти все одно з'являються в списку скриптів — але їхній дозвіл `connect` використовує `connect`, оголошений у підписці, а не власний дозвіл `connect` скрипта.

```js
// ==UserSubscribe==
// @name         xxx
// @description  Subscribe to the xxx script series
// @version      0.1.0
// @author       You
// @connect      www.baidu.com
// @scriptUrl    https://script.tampermonkey.net.cn/48.user.js
// @scriptUrl    https://script.tampermonkey.net.cn/49.user.js
// ==/UserSubscribe==
```

## Оновлення підписок і оновлення скриптів

Відповідно до налаштованого користувачем `інтервалу оновлення`, ScriptCat періодично перевіряє посилання підписки на оновлення; для цього має бути налаштований `version`.

Кожне оновлення або зміна підписки порівнює посилання на скрипти з поточними встановленими скриптами: скрипти, яких більше немає в новій підписці, видаляються, а нові скрипти встановлюються автоматично. Оновлення скриптів відбуваються за власним `version` скрипта, використовуючи ту саму логіку оновлення, що й для звичайно встановленого скрипта.

## Автоматичне встановлення та оновлення

Скрипти підписки встановлюються та оновлюються автоматично — додавання, видалення або оновлення скрипта з підписки показує лише сповіщення, без повторного підтвердження користувачем. Через цей механізм автоматичного оновлення підписуйтеся лише на джерела, яким ви довіряєте.


## metadata

Значення деяких полів метаданих змінюється в скрипті підписки.

### name

Назва підписки (можна також редагувати безпосередньо в списку підписок)

### description

Опис підписки, що пояснює, для чого призначена підписка

### version

Версія підписки. Якщо пропущено, оновлення натомість запускаються залежно від того, чи змінився вміст скрипта підписки.

### connect

Запитує дозвіл доступу до сайту; дивіться `GM_cookie` і `GM_xmlhttpRequest`. Для скриптів, встановлених через режим підписки, `connect` перевизначається `connect` підписки.

### scriptUrl

Посилання на встановлення скриптів, необхідні для підписки
