ScriptCat — це браузерне розширення, яке може виконувати користувацькі скрипти, сумісне зі скриптами Tampermonkey і надає більше функцій. Якщо ви знайдете помилки або маєте пропозиції, ви можете відвідати [репозиторій GitHub](https://github.com/scriptscat/scriptcat), щоб надати відгук.

## Встановлення розширення

### Інші браузери

Якщо вашого браузера немає у списку вище, ви можете завантажити файл `zip`/`crx` зі сторінки [Github Release](https://github.com/scriptscat/scriptcat/releases) і встановити його вручну.

### Встановлення розпакованого розширення {#load-unpacked-extension-installation}

① Спочатку завантажте файл `zip` зі сторінки [Github Release](https://github.com/scriptscat/scriptcat/releases) або [Спільнотне завантаження](https://bbs.tampermonkey.net.cn/thread-3068-1-1.html). Якщо це файл `crx`, змініть його розширення на `zip`.

② Підготуйте папку для зберігання плагіна та розпакуйте вищевказаний файл zip у цю папку. Після розпакування це має виглядати так (**Примітка: цю папку не можна видаляти або переміщувати, інакше розширення не працюватиме належним чином**) ![download-zip](./use.assets/download-zip.webp)

③ Відкрийте інтерфейс керування розширеннями браузера, щоб завантажити розпаковане розширення (див. [Увімкнення режиму розробника для підтримки manifest v3 ScriptCat](/docs/use/open-dev/), щоб спочатку ввімкнути режим розробника)

- 1. **Edge** ![edge-load-unpacked](./use.assets/edge-load-unpacked.webp)
- 2. **Chrome** ![chrome-load-unpacked](./use.assets/chrome-load-unpacked.webp)

④ Виберіть папку, створену на кроці ② (після завершення завантаження іконка ScriptCat з'явиться в списку розширень в інтерфейсі керування розширеннями, і ви також можете побачити її, натиснувши кнопку розширення у правому верхньому куті адресного рядка браузера)

- 1. **Edge** ![edge-load-unpacked-img](./use.assets/edge-load-unpacked-img.webp)
- 2. **Chrome** ![chrome-load-unpacked-img](./use.assets/chrome-load-unpacked-img.webp)

⑤ Натисніть іконку ScriptCat у правому верхньому куті, натисніть `┆` > Отримати скрипти у правому верхньому куті інтерфейсу, що з'явився, і ви зможете перейти на скриптовий сайт для пошуку та встановлення скриптів.

Примітка: розширення, встановлені таким чином, не можуть автоматично оновлюватися. Якщо потрібне оновлення, повторіть наведені вище кроки, щоб оновити розширення (замініть файли та перезавантажте один раз).


## Отримання скриптів

> Окрім скриптів, ви також можете отримати деяку інформацію та навчальні посібники з [Китайського форуму Tampermonkey](https://bbs.tampermonkey.net.cn/) та [Посібника з розробки скриптів](https://learn.scriptcat.org/).

### Скриптовий сайт ScriptCat

[Скриптовий сайт ScriptCat](https://scriptcat.org/) — це скриптовий сайт цього розширення, де ви можете публікувати написані вами скрипти.

- Новий скриптовий сайт
- Фонові скрипти/заплановані скрипти
- Зручний інтерфейс

### Пошук Userscript.Zone

[Пошук Userscript.Zone](https://www.userscript.zone/?utm_source=tm.net&utm_medium=scripts) — це новий вебсайт, який дозволяє шукати користувацькі скрипти, вводячи відповідні URL або домени.

- Велика кількість скриптових ресурсів
- Легко знайти відповідні користувацькі скрипти
- Показує лише користувацькі скрипти з перевірених сторінок скриптів або принаймні сторінок із функцією коментарів

### GreasyFork

[GreasyFork](https://greasyfork.org/) — це широко використовувана платформа для розміщення та обміну користувацькими скриптами, яка дозволяє розробникам публікувати, а користувачам встановлювати браузерні скрипти, що покращують або змінюють функціональність вебсайтів. Сайт створено Джейсоном Барнабе, і він відомий своїм акцентом на безпеці та прозорості з відкритим кодом, пропонуючи велику колекцію скриптів для покращення досвіду перегляду.

Джейсон Барнабе також є оригінальним творцем браузерного розширення Stylish. Однак [Stylish](https://userstyles.org/) було продано у 2016 році, і тепер його експлуатує інша компанія, без прямої участі Джейсона Барнабе в його подальшому розвитку.

- Велика кількість скриптових ресурсів
- Можливість синхронізувати скрипти з Github
- Дуже активна [модель розробки з відкритим кодом](https://github.com/JasonBarnabe/greasyfork)

### GitHub/Gist

Ви можете [шукати скриптові ресурси в Github і Gist](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated).

## Ознайомлювальний тур

Після встановлення ScriptCat відкриття панелі керування автоматично запустить ознайомлювальний тур (ви також можете відкрити його будь-коли з "Центру допомоги" у лівій бічній панелі). Тур охоплює:

- [Встановлення скриптів](/docs/use/script_installation/): встановлення зі скриптових маркетплейсів, включаючи підтримку [фонових скриптів](/docs/dev/background/).
- Керування та робота: редагування, запуск/зупинка, [UserConfig](/docs/dev/config/).
- [Резервне копіювання](/docs/use/sync/) та [міграція з інших менеджерів](/docs/use/from-other/migrate-from-tampermonkey/).
- [Синхронізація скриптів](/docs/use/sync/).
- [Підписки](/docs/dev/subscribe/).
