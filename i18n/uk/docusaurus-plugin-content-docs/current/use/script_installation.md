## Кроки встановлення з різних вебсайтів

### Спільнота ScriptCat

[Спільнота ScriptCat](https://scriptcat.org/search) — офіційний сайт ScriptCat

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) — це новий вебсайт, який дозволяє шукати користувацькі скрипти, вводячи відповідні URL або домени.

- **Велика кількість скриптових ресурсів**
- **Легко знайти відповідні користувацькі скрипти**
- **Показує лише користувацькі скрипти з перевірених сторінок скриптів або принаймні сторінок із функцією коментарів**

### GreasyFork

[GreasyFork](https://greasyfork.org/) — це широко використовувана платформа для розміщення та обміну користувацькими скриптами, яка дозволяє розробникам публікувати, а користувачам встановлювати браузерні скрипти, що покращують або змінюють функціональність вебсайтів. Сайт створено Джейсоном Барнабе, і він відомий своїм акцентом на безпеці та прозорості з відкритим кодом, пропонуючи велику колекцію скриптів для покращення досвіду перегляду.

Джейсон Барнабе також є оригінальним творцем браузерного розширення Stylish. Однак [Stylish](https://userstyles.org/) було продано у 2016 році, і тепер його експлуатує інша компанія, без прямої участі Джейсона Барнабе в його подальшому розвитку.

- **Велика кількість скриптових ресурсів**
- **Можливість синхронізувати скрипти з Github**
- **Дуже активна модель розробки з відкритим кодом**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) було створено після GreasyFork. Його створив Sizzle McTwizzle, і, аналогічно, у його сховищі також велика кількість скриптових ресурсів.

- **Можливість синхронізувати скрипти з Github і створювати форки скриптів**
- **Дуже активна модель розробки з відкритим кодом**

### GitHub/Gist

Ви можете шукати скриптові ресурси в Github і Gist.


## Ручне встановлення скрипта

1. Натисніть на іконку розширення ScriptCat
2. Натисніть "Кнопку з шестернею" в інтерфейсі, щоб увійти в інтерфейс керування ScriptCat
3. Натисніть кнопку "Створити новий скрипт" у правому верхньому куті (зазвичай достатньо створити звичайний скрипт)
4. Вставте код скрипта на сторінку, що відкрилася
5. Натисніть `ctrl + s`, щоб зберегти зміни
6. Поверніться до інтерфейсу керування, щоб побачити ваш новостворений скрипт
