v1.4 — це велике оновлення ScriptCat, яке представляє абсолютно нову систему **Agent**, що дозволяє користувачам автоматизувати дії в браузері, витягувати веб-дані, керувати файлами та запускати завдання за розкладом через розмову природною мовою.

## Agent

До панелі керування додано нову точку входу для чату з Agent, де можна вести багатоходову розмову з AI-моделлю; AI автоматично викликає вбудовані інструменти для виконання завдань.

**Основні можливості:**

- **Підтримка кількох моделей** — сумісний з OpenAI та нативний формат Anthropic, з підтримкою Prompt Caching
- **11 вбудованих інструментів** — веб-отримання/пошук, керування вкладками, файлова система OPFS, виконання коду, взаємодія з користувачем тощо
- **Система Skills** — пакети з підказок + скриптів інструментів + довідкових матеріалів, що розширюють знання Agent у предметній області
- **Інтеграція MCP** — підтримка [Model Context Protocol](https://modelcontextprotocol.io/) для підключення до зовнішніх серверів інструментів
- **Автоматизація DOM** — навігація по сторінках, скріншоти, кліки, заповнення, прокрутка, виконання скриптів тощо
- **Завдання за розкладом** — планування завдань на основі Cron-виразів (режими Внутрішній / Подія)
- **Суб-агенти** — можуть створювати незалежних суб-агентів для складних підзавдань
- **Керування контекстом** — автоматичне ущільнення та Prompt Caching для зменшення використання токенів

**API скрипта (`CAT.agent.*`):**

Користувацькі скрипти можуть викликати можливості Agent через простір імен `CAT.agent.*`, включаючи API conversation, dom, skills, task, model, opfs і mcp. Кожен API вимагає оголошення відповідного дозволу за допомогою `@grant`.

**6 сторінок панелі керування:** Чат, Конфігурація моделі, Керування Skills, Завдання за розкладом, MCP-сервери та OPFS-браузер.

## Підтримка тега `@unwrap`

Дозволяє впроваджувати скрипт безпосередньо на сторінку, оминаючи обгортку пісочниці.

## Подія `window.onurlchange`

Реалізує сумісне з Tampermonkey прослуховування подій зміни URL за допомогою Navigation API.

## Покращення редактора

Додано меню редагування (пошук, заміна, скасування тощо) та виправлено кілька проблем із гарячими клавішами та підказками.

## Багатоплатформні пошукові системи

Пошук скриптів тепер підтримує вибір між різними платформами пошукових систем.

## Більше постачальників іконок

Додано більше постачальників послуг іконок для скриптів.
