ScriptCat — це проєкт з відкритим кодом, який підтримують волонтери без підтримки компаній. Сервери, домени та інша інфраструктура, а також величезна кількість часу на розробку та обслуговування — все тримається на підтримці спільноти. Кожен внесок допомагає ScriptCat рухатися далі.

## Куди йдуть ваші спонсорські кошти

Дохід від спонсорства здебільшого йде на:

- **Покриття витрат на роботу** — сервери, домени та інша повсякденна інфраструктура.
- **Винагороду супроводжувачів та учасників** — щоб довгострокові супроводжувачі та всі, хто надсилає код, переклади та документацію, отримували заслужену винагороду.
- **Створення нових функцій** — більше часу на вдосконалення досвіду та розробку нових можливостей.

## Як спонсорувати

Чи ви приватна особа, чи компанія, і незалежно від розміру, кожна підтримка має значення.

Ми збираємо спонсорські внески через [OpenCollective](https://opencollective.com/scriptcat), з одноразовими або щомісячними внесками; ваше ім'я з'явиться у списку спонсорів після пожертви.

Якщо ви хочете **розміщення спонсора** — ваш логотип та інформація в README, на вебсайті або в документації — напишіть нам на [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Розміщення спонсорів

Логотип та опис спонсора можуть відображатися в таких місцях, за домовленістю електронною поштою:

| Місце | Формат |
| --- | --- |
| Верхня частина README на GitHub | Великий банер |
| Зона спонсорів у README на GitHub | Логотип + однорядкова інформація |
| Сторінка спонсорів на вебсайті (ця сторінка) | Логотип + інформація |
| Сторінки документації на вебсайті (наприклад, журнал змін) | Відображення логотипа |
