---
title: Pemasangan Skrip
---

Halaman ini digunakan sebagai langkah perantara untuk memasang skrip pengguna baru di `ScriptCat`.

Setelah pemasangan selesai, halaman ini seharusnya otomatis tertutup atau dialihkan.

Halaman ini tidak cocok untuk dilihat langsung. Jika perlu, silakan kunjungi [Skrip Pemasangan](/docs/use/script_installation/).
