v1.4 adalah pembaruan besar untuk ScriptCat, memperkenalkan sistem **Agent** yang serba baru yang memungkinkan pengguna mengotomatiskan tindakan browser, mengekstrak data web, mengelola file, dan menjalankan tugas terjadwal melalui percakapan bahasa alami.

## Agent

Titik masuk obrolan Agent baru telah ditambahkan ke dasbor, tempat Anda dapat mengadakan percakapan multi-putaran dengan model AI; AI secara otomatis memanggil alat bawaan untuk menyelesaikan tugas.

**Kemampuan inti:**

- **Dukungan multi-model** — format kompatibel OpenAI dan Anthropic asli, dengan dukungan Prompt Caching
- **11 alat bawaan** — pengambilan/penelusuran web, manajemen tab, sistem file OPFS, eksekusi kode, interaksi pengguna, dan lainnya
- **Sistem Skill** — paket prompt + skrip alat + materi referensi yang memperluas pengetahuan domain Agent
- **Integrasi MCP** — mendukung [Model Context Protocol](https://modelcontextprotocol.io/) untuk terhubung ke server alat eksternal
- **Otomatisasi DOM** — navigasi halaman, tangkapan layar, klik, pengisian, gulir, eksekusi skrip, dan lainnya
- **Tugas terjadwal** — penjadwalan tugas berbasis ekspresi Cron (mode Internal / Peristiwa)
- **Sub-agen** — dapat membuat sub-agen independen untuk menangani sub-tugas yang kompleks
- **Manajemen konteks** — Auto-compact dan Prompt Caching untuk mengurangi penggunaan token

**API skrip (`CAT.agent.*`):**

Skrip pengguna dapat memanggil kemampuan Agent melalui namespace `CAT.agent.*`, termasuk API conversation, dom, skills, task, model, opfs, dan mcp. Setiap API memerlukan izin terkait untuk dideklarasikan dengan `@grant`.

**6 halaman dasbor:** Obrolan, Konfigurasi Model, Manajemen Skill, Tugas Terjadwal, Server MCP, dan Peramban OPFS.

## Dukungan untuk Tag `@unwrap`

Memungkinkan skrip diinjeksi langsung ke halaman, melewati pembungkus sandbox.
