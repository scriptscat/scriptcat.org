Perbaikan: pembaruan versi tidak lagi otomatis membuka halaman changelog

## Bilah Sisi Daftar Skrip [#794](https://github.com/scriptscat/scriptcat/issues/794)

Menambahkan penyaringan tingkat lanjut di bilah sisi, beserta fitur penandaan; tag dapat diedit dari Skrip → Pengaturan.

![image-20251016230129315](@site/docs/change/v1.2.assets/image-20251016230129315.png)

## Tampilan Kartu [#860](https://github.com/scriptscat/scriptcat/issues/860)

Menambahkan tampilan kartu, yang otomatis beralih antara tampilan kartu dan tampilan tabel saat pertama kali diluncurkan, sehingga layar sempit dapat menampilkan informasi skrip dengan lebih baik.

![image-20251023103730266](@site/docs/change/v1.2.assets/image-20251023103730266.png)

## Logika Pemeriksaan Pembaruan yang Lebih Ramah [#755](https://github.com/scriptscat/scriptcat/issues/755)

Mengoptimalkan logika pemeriksaan pembaruan — alih-alih memunculkan prompt pembaruan untuk setiap skrip sekaligus, kini semuanya digabungkan ke dalam satu jendela pembaruan, tempat Anda dapat memilih skrip mana yang akan diperbarui atau memperbarui semuanya dengan satu klik. Jumlah perubahan setiap skrip juga ditampilkan.

![image-20251016225931823](@site/docs/change/v1.2.assets/image-20251016225931823.png)

## Menambahkan Konfigurasi Editor dan Definisi Tipe Editor [#708](https://github.com/scriptscat/scriptcat/pull/708)

Anda kini dapat menyesuaikan konfigurasi editor dan definisi tipe editor; konfigurasi editor dapat ditulis dengan mengacu pada [compilerOptions](https://www.typescriptlang.org/tsconfig/#compilerOptions) dari `tsconfig.json`.

![08c2889f-3029-4d3c-b180-c52d77c8077c](@site/docs/change/v1.2.assets/08c2889f-3029-4d3c-b180-c52d77c8077c.png)

## Opsi Berjalan di Latar Belakang [#1048](https://github.com/scriptscat/scriptcat/pull/1048)

Menambahkan opsi berjalan di latar belakang di bawah Pengaturan → Runtime. Saat diaktifkan, browser tetap berjalan di latar belakang dan diminimalkan ke system tray bahkan setelah semua jendela ditutup, hingga Anda keluar dari browser secara manual. Ini memungkinkan skrip latar belakang tetap berjalan.

![image-20251204174034940](@site/docs/change/v1.2.assets/image-20251204174034940.png)

## Pembaruan API

- Mendukung `inject-into`, sehingga skrip kini dapat diinjeksi ke lingkungan konten [#711](https://github.com/scriptscat/scriptcat/issues/711)
- `GM_openInTab` mendukung parameter untuk menyematkan tab, membuka di jendela penyamaran, dan lainnya [#788](https://github.com/scriptscat/scriptcat/pull/788)
- `GM_registerMenuCommand` mendukung menu tingkat kedua dan garis pemisah [#831](https://github.com/scriptscat/scriptcat/pull/831)
