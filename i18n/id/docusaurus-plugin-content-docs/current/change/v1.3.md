## Alur Instalasi Skrip Baru [#842](https://github.com/scriptscat/scriptcat/issues/842)

Alur instalasi skrip didesain ulang — tidak lagi bergantung pada pengalihan situs eksternal atau membuka jendela baru. Skrip kini diinstal langsung di halaman saat ini. Tata letak halaman instalasi juga dioptimalkan dengan desain responsif, pratinjau kode yang dapat digulir, dan tampilan kesalahan inline saat pengunduhan gagal.

## Opsi Waktu Jalannya Skrip [#895](https://github.com/scriptscat/scriptcat/issues/895)

Menambahkan opsi waktu jalannya skrip di pengaturan skrip, yang memungkinkan Anda memilih dari `document-start`, `document-body`, `document-end`, `document-idle`, `early-start`, dan lainnya, untuk kontrol yang presisi atas kapan skrip Anda berjalan.

![Opsi waktu jalannya skrip](v1.3.assets/run-timing.png)

## Dukungan Penyimpanan Amazon S3 [#1146](https://github.com/scriptscat/scriptcat/issues/1146)

Sinkronisasi dan cadangan cloud kini mendukung Amazon S3 sebagai backend penyimpanan, selain opsi yang sudah ada seperti WebDAV, Baidu Netdisk, OneDrive, Google Drive, dan Dropbox.

![Opsi penyimpanan Amazon S3](v1.3.assets/s3-storage.png)

## Melepas Kaitan Penyimpanan Cloud [#1151](https://github.com/scriptscat/scriptcat/issues/1151)

Menambahkan tombol lepas kaitan di pengaturan sinkronisasi cloud, sehingga mudah untuk memutus atau mengganti koneksi penyimpanan cloud.
