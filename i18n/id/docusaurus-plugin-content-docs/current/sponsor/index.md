ScriptCat adalah proyek sumber terbuka yang dirawat oleh relawan, tanpa perusahaan di belakangnya. Server, domain, dan infrastruktur lainnya, bersama dengan banyak waktu pengembangan dan perawatan, semuanya ditopang oleh dukungan komunitas. Setiap kontribusi membantu ScriptCat melangkah lebih jauh.

## Ke mana sumbangan Anda digunakan

Pendapatan sponsor terutama digunakan untuk:

- **Menutup biaya operasional** — server, domain, dan infrastruktur sehari-hari lainnya.
- **Menghargai pengelola & kontributor** — sehingga pengelola jangka panjang, dan semua orang yang mengirim kode, terjemahan, dan dokumen, mendapatkan penghargaan yang layak.
- **Membangun fitur baru** — lebih banyak waktu untuk memoles pengalaman dan mengembangkan kemampuan baru.

## Cara mendukung

Baik Anda individu maupun perusahaan, dan berapa pun besarnya, setiap bentuk dukungan berarti.

Kami mengumpulkan sponsor melalui [OpenCollective](https://opencollective.com/scriptcat), dengan kontribusi sekali atau bulanan; nama Anda akan muncul di daftar pendukung setelah Anda menyumbang.

Jika Anda menginginkan **penempatan sponsor** — logo dan perkenalan Anda ditampilkan di README, di situs web, atau di dokumen — kirim email ke [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Penempatan sponsor

Logo dan deskripsi sponsor dapat ditampilkan di tempat-tempat berikut, diatur melalui email:

| Penempatan | Format |
| --- | --- |
| Bagian atas README GitHub | Spanduk besar |
| Area sponsor README GitHub | Logo + perkenalan satu baris |
| Halaman sponsor situs web (halaman ini) | Logo + perkenalan |
| Halaman dokumen situs web (mis. catatan perubahan) | Tampilan logo |
