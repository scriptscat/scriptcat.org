## Sinkronisasi

Saat skrip diperbarui, skrip akan langsung disinkronkan ke cloud. Namun, saat data cloud berubah, diperlukan waktu untuk memindai dan menyinkronkan ke lokal. Harap perhatikan ini saat beberapa perangkat berbagi penyimpanan cloud yang sama.

Mengklik Simpan di bagian sinkronisasi skrip akan segera melakukan sinkronisasi penuh.
