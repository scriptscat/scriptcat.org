---
title: Migrasi dari Tampermonkey ke Scriptcat
---

Jika Anda saat ini menggunakan Tampermonkey dan ingin migrasi ke Scriptcat, berikut adalah beberapa langkah dan tips untuk membantu Anda menyelesaikan migrasi dengan lancar.

## Ekspor Cadangan dari Tampermonkey

Pertama, klik ikon Tampermonkey untuk masuk ke dasbor

![image-20250716225507707](./migrate-from-tampermonkey.assets/image-20250716225507707.webp)

Klik `Utilitas`, lalu klik `Ekspor` di bagian file zip untuk mengekspor file zip

![image-20250716225611932](./migrate-from-tampermonkey.assets/image-20250716225611932.webp)

## Impor ke Scriptcat

Di ekstensi Scriptcat, klik ikon dasbor untuk masuk ke panel pengelolaan

![image-20250716225719787](./migrate-from-tampermonkey.assets/image-20250716225719787.webp)

Pilih `Alat`, lalu klik `Impor File`, pilih file zip Tampermonkey yang diekspor sebelumnya, dan klik `Buka` untuk mengimpor.

![image-20250716225741428](./migrate-from-tampermonkey.assets/image-20250716225741428.webp)

Kemudian di halaman yang baru dibuka, pilih atau pilih semua skrip yang ingin Anda impor, dan klik tombol `Impor`.
