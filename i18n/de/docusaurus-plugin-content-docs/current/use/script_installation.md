> Bitte folgen Sie zuerst dem [Quick Start](/docs/use/use/), um die ScriptCat-Erweiterung zu installieren.

## Installationsschritte von verschiedenen Websites

### ScriptCat Community

[ScriptCat Community](https://scriptcat.org/search) ScriptCat offizielle Website

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) ist eine neue Website, die es ermöglicht, nach Userskripten zu suchen.

- **Viele Skript-Ressourcen**
- **Einfach passende Userskripte finden**
- **Zeigt nur Userskripte aus überprüften Seiten**

### GreasyFork

[GreasyFork](https://greasyfork.org/) ist eine weit verbreitete Plattform zum Hosten und Teilen von Userskripten.

- **Viele Skript-Ressourcen**
- **Kann Skripte von Github synchronisieren**
- **Sehr aktives Open-Source-Entwicklungsmodell**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) wurde nach GreasyFork erstellt.

- **Kann Skripte von Github synchronisieren**
- **Sehr aktives Open-Source-Entwicklungsmodell**

### GitHub/Gist

Sie können [Skript-Ressourcen in Github und Gist suchen.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## Manuelle Skriptinstallation

1. Klicken Sie auf das ScriptCat-Erweiterungssymbol
2. Klicken Sie auf das „Zahnrad-Symbol" in der Schnittstelle, um zur ScriptCat-Verwaltung zu gelangen
3. Klicken Sie oben rechts auf „Neues Skript erstellen"
4. Fügen Sie den Skriptcode auf der Popup-Seite ein
5. Drücken Sie `ctrl + s`, um die Änderungen zu speichern
6. Kehren Sie zur Verwaltungsoberfläche zurück, um Ihr neu erstelltes Skript zu sehen
