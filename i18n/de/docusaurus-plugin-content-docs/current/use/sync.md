## Synchronisation

Wenn ein Skript aktualisiert wird, sofort in die Cloud synchronisiert. Wenn sich however Cloud-Daten ändern, dauert es einige Zeit, bis sie gescannt und mit dem lokalen synchronisiert werden. Bitte beachten Sie dies, wenn mehrere Geräte denselben Cloud-Speicher teilen.

Klicken Sie in der Skript-Synchronisationssektion auf Speichern, um sofort eine vollständige Synchronisation durchzuführen.
