ScriptCat ist eine Browser-Erweiterung, die Userskripte ausführen kann, kompatibel mit Tampermonkey-Skripten, und bietet weitere Funktionen. Bei Bugs oder Vorschlägen besuchen Sie das [GitHub-Repository](https://github.com/scriptscat/scriptcat).

### Andere Browser

Wenn Ihr Browser nicht in der obigen Liste steht, können Sie die `zip`/`crx`-Datei von der [Github Release](https://github.com/scriptscat/scriptcat/releases)-Seite herunterladen und manuell installieren.

### Unpacked Extension Installation

① Laden Sie die `zip`-Datei von [Github Release](https://github.com/scriptscat/scriptcat/releases) oder [Community Download](https://bbs.tampermonkey.net.cn/thread-3068-1-1.html) herunter.

② Bereiten Sie einen Ordner vor und entpacken Sie die zip-Datei. (**Hinweis: Dieser Ordner kann nicht gelöscht oder verschoben werden**)

③ Öffnen Sie die Erweiterungsverwaltung und laden Sie die unpacked Extension (siehe [Entwicklermodus aktivieren](/docs/use/open-dev/))

④ Wählen Sie den Ordner aus

⑤ Klicken Sie auf das ScriptCat-Symbol und dann auf `┆` > Skripte abrufen

Hinweis: Auf diese Weise installierte Erweiterungen können nicht automatisch aktualisiert werden.
