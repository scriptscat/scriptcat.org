v1.4 ist ein großes Update für ScriptCat, das ein völlig neues **Agent**-System einführt, das es Benutzern ermöglicht, Browser-Aktionen zu automatisieren, Web-Daten zu extrahieren, Dateien zu verwalten und geplante Aufgaben über natürlichsprachlichen Dialog auszuführen.

## Agent

Ein neuer Agent-Chat-Einstiegspunkt wurde zum Dashboard hinzugefügt, in dem Sie ein mehrstufiges Gespräch mit einem KI-Modell führen können; die KI ruft automatisch eingebaute Werkzeuge zur Aufgabenerledigung auf.

**Fähigkeiten:**

- **Multi-Modell-Unterstützung** — OpenAI-kompatible und native Anthropic-Formate mit Prompt-Caching-Unterstützung
- **11 eingebaute Werkzeuge** — Web-Fetch/Suche, Tab-Verwaltung, OPFS-Dateisystem, Code-Ausführung, Benutzerinteraktion und mehr
- **Skill-System** — Pakete aus Prompts + Werkzeugskripten + Referenzmaterial, die das Wissen des Agenten erweitern
- **MCP-Integration** — Unterstützung des [Model Context Protocol](https://modelcontextprotocol.io/) zur Anbindung externer Werkzeugserver
- **DOM-Automatisierung** — Seitennavigation, Screenshots, Klicks, Ausfüllen, Scrollen, Skriptausführung und mehr
- **Geplante Aufgaben** — Cron-basierte Aufgabenplanung (Internal / Event Modi)
- **Sub-Agenten** — Können unabhängige Sub-Agenten zur Bearbeitung komplexer Teilaufgaben starten
- **Kontextverwaltung** — Auto-Compact und Prompt Caching zur Reduzierung der Token-Nutzung

**Script API (`CAT.agent.*`):**

Benutzerskripte können Agent-Fähigkeiten über den Namespace `CAT.agent.*` aufrufen, einschließlich der APIs für Conversation, DOM, Skills, Tasks, Models, OPFS und MCP. Jede API erfordert die entsprechende Berechtigung über `@grant`.

**6 Dashboard-Seiten:** Chat, Modell-Konfiguration, Skill-Verwaltung, Geplante Aufgaben, MCP-Server und der OPFS-Browser.

## Unterstützung des `@unwrap`-Tags

Ermöglicht die direkte Injizierung eines Skripts in die Seite unter Umgehung der Sandbox-Hülle.

## Das `window.onurlchange`-Event

Implementiert tampermonkey-kompatible URL-Änderungs-Event-Überwachung über die Navigation API.

## Editor-Verbesserungen

Kontextmenü im Editor (Suchen, Ersetzen, Rückgängig usw.) hinzugefügt und mehrere Tastaturkürzel- und Hint-Probleme behoben.

## Multi-Plattform-Suchmaschinen

Die Skriptsuche unterstützt nun die Auswahl zwischen verschiedenen Suchmaschinen-Plattformen.

## Weitere Icon-Anbieter

Mehr Skript-Icon-Dienstanbieter hinzugefügt.
