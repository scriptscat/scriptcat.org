ScriptCat ist ein Open-Source-Projekt, das von Freiwilligen gepflegt wird, ohne Firmenunterstützung. Server, Domains und andere Infrastruktur sowie viel Entwicklungs- und Wartungszeit werden durch Community-Unterstützung finanziert. Jeder Beitrag hilft ScriptCat, weiterzumachen.

## Wohin geht Ihre Spende

Spendeneinnahmen fließen hauptsächlich in:

- **Deckung der Betriebskosten** — Server, Domains und andere tägliche Infrastruktur.
- **Belohnung von Maintainer & Mitwirkenden** — damit langfristige Maintainer und alle, die Code, Übersetzungen und Dokumentation beitragen, die verdiente Belohnung erhalten.
- **Aufbau neuer Funktionen** — mehr Zeit, um die Erfahrung zu verfeinern und neue Fähigkeiten zu entwickeln.

## Wie Sie spenden können

Ob als Einzelperson oder Unternehmen, und egal wie groß — jeder Beitrag zählt.

Wir sammeln Spenden über [OpenCollective](https://opencollective.com/scriptcat), mit einmaligen oder monatlichen Beiträgen; Ihr Name erscheint nach der Spende auf der Unterstützerliste.

Wenn Sie eine **Sponsorenplatzierung** möchten — Ihr Logo und Ihre Vorstellung im README, auf der Website oder in der Dokumentation — senden Sie uns eine E-Mail an [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Sponsorenplatzierungen

Das Logo und die Beschreibung eines Sponsors können an folgenden Stellen angezeigt werden:

| Platzierung | Format |
| --- | --- |
| Oben im GitHub README | Großes Banner |
| GitHub README Sponsorenbereich | Logo + einzeilige Vorstellung |
| Website Sponsorenseite (diese Seite) | Logo + Vorstellung |
| Website Dokumentationsseiten | Logo-Anzeige |
