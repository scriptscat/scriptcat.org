---
title: CloudCat
---

CloudCat ist das Cloud-Synchronisationsmodul von ScriptCat, das die Synchronisation Ihrer Skripte und Einstellungen zwischen verschiedenen Geräten ermögigt.

## Unterstützte Cloud-Dienste

- **WebDAV**: Standard-WebDAV-Protokoll, kompatibel mit den meisten WebDAV-Servern
- **OneDrive**: Microsoft OneDrive-Integration
- **Google Drive**: Google Drive-Integration
- **Dropbox**: Dropbox-Integration
- **Amazon S3**: Amazon S3-kompatible Speicherlösungen

## Einrichtung

1. Gehen Sie zu den ScriptCat-Einstellungen
2. Wählen Sie „Cloud-Synchronisation"
3. Wählen Sie Ihren Cloud-Dienst
4. Authentifizieren Sie sich bei Ihrem Cloud-Dienst
5. Wählen Sie einen Ordner für die Synchronisation

## Was wird synchronisiert?

- Installierte Skripte
- Skripteinstellungen
- Benutzerdefinierte Konfigurationen
- Skriptinhalte

## Konfliktbehandlung

Bei Konflikten zwischen Geräten verwendet ScriptCat die neueste Version basierend auf dem Änderungsdatum.
