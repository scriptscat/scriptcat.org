---
title: Abonnements
---

ScriptCat unterstützt die Funktion „Abonnements", mit der Sie Skripte von externen Quellen automatisch aktualisieren können.

## Abonnement einrichten

1. Gehen Sie zu den Skripteinstellungen
2. Aktivieren Sie die Option „Abonnement"
3. Geben Sie die URL des Skripts ein, das Sie abonnieren möchten
4. ScriptCat prüft regelmäßig, ob Updates verfügbar sind

## Automatische Aktualisierung

Wenn ein Update verfügbar ist, ScriptCat kann das Skript automatisch aktualisieren oder Sie benachrichtigen, je nach Ihren Einstellungen.

## Abonnement-URL

Die Abonnement-URL muss eine direkte URL zu einer .user.js-Datei sein. ScriptCat lädt die URL regelmäßig herunter und vergleicht die Version mit der installierten Version.

## Einstellungen

- **Prüfintervall**: Wie oft ScriptCat auf Aktualisierungen prüft
- **Automatische Aktualisierung**: Ob Updates automatisch installiert werden sollen
