ScriptCat é uma extensão de navegador que pode executar userscripts, compatível com scripts do Tampermonkey, e oferece muitos mais recursos.

## Instalar Extensão

| Navegador | Link da Loja | Status |
| --- | --- | --- |
| Chrome | [Versão Estável](https://chrome.google.com/webstore/detail/scriptcat/ndcooeababalnlpkfedmmbbbgkljhpjf) [Versão Beta](https://chromewebstore.google.com/detail/%E8%84%9A%E6%9C%AC%E7%8C%AB-beta/jaehimmlecjmebpekkipmpmbpfhdacom?authuser=0&hl=zh-CN) | ✅ Disponível |
| Edge | [Versão Estável](https://microsoftedge.microsoft.com/addons/detail/scriptcat/liilgpjgabokdklappibcjfablkpcekh) [Versão Beta](https://microsoftedge.microsoft.com/addons/detail/scriptcat-beta/nimmbghgpcjmeniofmpdfkofcedcjpfi) | ✅ Disponível |

### Outros Navegadores

Se seu navegador não está na lista, baixe o arquivo `zip`/`crx` na página [Github Release](https://github.com/scriptscat/scriptcat/releases) e instale manualmente.

### Instalação de Extensão Desempacotada

① Baixe o arquivo `zip` do [Github Release](https://github.com/scriptscat/scriptcat/releases) ou [Download Comunitário](https://bbs.tampermonkey.net.cn/thread-3068-1-1.html)

② Prepare uma pasta e extraia o arquivo zip (**Nota: Esta pasta não pode ser deletada ou movida**)

③ Abra a interface de gerenciamento de extensões para carregar a extensão desempacotada (consulte [Habilitar Modo Desenvolvedor](/docs/use/open-dev/))

④ Selecione a pasta criada no passo ②

⑤ Clique no ícone do ScriptCat, depois em `┆` > Obter Scripts

Nota: Extensões instaladas assim não são atualizadas automaticamente.


## Obter Scripts

> Além de scripts, você pode obter informações e tutoriais no [Fórum Chinês Tampermonkey](https://bbs.tampermonkey.net.cn/) e no [Guia de Desenvolvimento de Scripts](https://learn.scriptcat.org/).

### ScriptCat Script Site

[ScriptCat Script Site](https://scriptcat.org/) é o site de scripts desta extensão.

- Novo site de scripts
- Scripts de fundo/scripts agendados
- Interface fácil de usar

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/?utm_source=tm.net&utm_medium=scripts) para pesquisar userscripts.

- Grande quantidade de recursos de scripts
- Fácil de encontrar userscripts adequados

### GreasyFork

[GreasyFork](https://greasyfork.org/) é uma plataforma amplamente utilizada para userscripts.

- Grande quantidade de recursos de scripts
- Sincronização do Github
- [Modelo de desenvolvimento open source](https://github.com/JasonBarnabe/greasyfork)

### GitHub/Gist

[Pesquisar recursos de scripts no Github e Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)
