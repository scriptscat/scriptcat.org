## Passos de Instalação de Vários Sites

### ScriptCat Community

[ScriptCat Community](https://scriptcat.org/search) Site oficial do ScriptCat

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) é um novo site que permite pesquisar userscripts.

- **Grande quantidade de recursos de scripts**
- **Fácil de encontrar userscripts adequados**
- **Mostra apenas userscripts de páginas revisadas**

### GreasyFork

[GreasyFork](https://greasyfork.org/) é uma plataforma amplamente utilizada para hospedar e compartilhar userscripts.

- **Grande quantidade de recursos de scripts**
- **Capacidade de sincronizar scripts do Github**
- **Modelo de desenvolvimento open source muito ativo**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) foi criado após o GreasyFork.

- **Capacidade de sincronizar scripts do Github**
- **Modelo de desenvolvimento open source muito ativo**

### GitHub/Gist

Você pode [pesquisar recursos de scripts no Github e Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## Instalação Manual de Scripts

1. Clique no ícone da extensão ScriptCat
2. Clique no "Botão de engrenagem" para entrar na interface de gerenciamento
3. Clique em "Criar Novo Script" no canto superior direito
4. Cole o código do script na página popup
5. Pressione `ctrl + s` para salvar as alterações
6. Volte à interface de gerenciamento para ver seu script recém-criado
