# 🎉 Bem-vindo ao ScriptCat

Parabéns por instalar com sucesso a extensão do navegador ScriptCat! ScriptCat é um poderoso gerenciador de userscripts compatível com scripts do Tampermonkey e oferece muitos mais recursos poderosos.

<GithubStar variant="bar" scene="install" />

## Aviso de Segurança

⚠️ **Userscripts têm capacidades poderosas, a segurança é crucial!**

Userscripts têm capacidades poderosas e podem acessar e modificar conteúdo de páginas web, portanto **a segurança é crucial**. Para proteger suas informações pessoais e a segurança do dispositivo:

- ✅ **Instale scripts apenas de sites de scripts confiáveis**
- ✅ **Verifique cuidadosamente as avaliações e comentários**
- ✅ **Compreenda a funcionalidade e requisitos de permissão**
- ❌ **Evite baixar scripts de fontes desconhecidas ou suspeitas**
- ❌ **Não instale arquivos de script de origem desconhecida**

### Fontes de Scripts Confiáveis Recomendadas

- **[ScriptCat Script Site](https://scriptcat.org/)** - Site oficial mantido pelo ScriptCat
- **[GreasyFork](https://greasyfork.org/)** - O maior site de userscripts do mundo
- **[Userscript.Zone](https://www.userscript.zone/)** - Scripts de alta qualidade selecionados

## Próximos Passos

### Acessar a Interface de Gerenciamento

Clique no ícone do ScriptCat na barra de ferramentas, depois no botão "⚙️" para entrar no gerenciamento.

### Obter seu Primeiro Script

Na interface popup, clique em "⋮" e selecione "Obter Scripts" para ir ao site oficial.

### Explorar Funcionalidades

- 📊 **Gerenciamento de Scripts**: Ativar/desativar scripts, ver status
- 🔧 **Configurações Personalizadas**: Configurar parâmetros
- 📝 **Edição de Scripts**: Criar e editar seus próprios scripts
- 🔄 **Sincronização de Dados**: Sincronizar configurações

## Recomendações de Uso

1. **Comece Pequeno**: Novos usuários devem começar com scripts simples e bem avaliados
2. **Verificações Regulares**: Revise e atualize seus scripts regularmente
3. **Backups de Configuração**: Faça backup de configurações importantes
4. **Relate Problemas**: Dê feedback através do [GitHub](https://github.com/scriptscat/scriptcat)

## Isenção de Responsabilidade

- ScriptCat fornece um ambiente de execução mas não é responsável pela segurança de scripts de terceiros
- Você assume os riscos de usar scripts de terceiros
- Recomenda-se ler o código fonte e documentação dos scripts

Para detalhes: [Isenção Completa](/docs/use/policy/disclaimer/)
