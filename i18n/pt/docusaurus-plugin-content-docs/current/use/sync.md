## Sincronização

Quando um script é atualizado, será imediatamente sincronizado para a nuvem. No entanto, quando os dados na nuvem mudam, leva algum tempo para escanear e sincronizar para o local. Observe isso quando múltiplos dispositivos compartilham o mesmo armazenamento em nuvem.

Clicar em Salvar na seção de sincronização de scripts realizará imediatamente uma sincronização completa.
