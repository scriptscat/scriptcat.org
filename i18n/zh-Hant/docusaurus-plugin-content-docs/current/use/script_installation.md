> 請先參閱[快速入門](/docs/use/use/)安裝 ScriptCat 擴充功能。

## 從各網站安裝步驟

### ScriptCat 社群

[ScriptCat 社群](https://scriptcat.org/search) ScriptCat 官方網站

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) 是一個新的網站，可透過輸入適當的 URL 或網域搜尋使用者腳本。

- **大量腳本資源**
- **輕鬆找到合適的使用者腳本**
- **僅顯示經過審核的使用者腳本頁面或至少有留言功能的頁面的腳本**

### GreasyFork

[GreasyFork](https://greasyfork.org/) 是一個廣泛使用的託管和共享使用者腳本的平台。

- **大量腳本資源**
- **具有從 Github 同步腳本的功能**
- **非常活躍的開源開發模式**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) 是在 GreasyFork 之後建立的。

- **具有從 Github 同步腳本的功能**
- **非常活躍的開源開發模式**

### GitHub/Gist

您可以在 [Github 和 Gist 搜尋腳本資源。](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## 手動安裝腳本

1. 點擊 ScriptCat 擴充功能圖示
2. 點擊介面中的「齒輪按鈕」進入 ScriptCat 管理介面
3. 點擊右上角的「建立新腳本」按鈕（通常建立一般腳本即可）
4. 在彈出頁面中貼上腳本代碼
5. 按 `ctrl + s` 儲存變更
6. 回到管理介面查看新建立的腳本
