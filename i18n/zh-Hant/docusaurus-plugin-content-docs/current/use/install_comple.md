# 🎉 歡迎使用 ScriptCat

恭喜您成功安裝 ScriptCat 瀏覽器擴充功能！ScriptCat 是一個強大的使用者腳本管理器，與 Tampermonkey 腳本相容，並提供更多強大功能。

<GithubStar variant="bar" scene="install" />

## 安全提示

⚠️ **使用者腳本具有強大功能，安全至關重要！**

使用者腳本具有強大功能，可以存取和修改網頁內容，因此**安全至關重要**。為保護您的個人資訊和裝置安全，請確保：

- ✅ **僅從可信的腳本網站安裝腳本**
- ✅ **仔細查看腳本評分和使用者留言**
- ✅ **了解腳本的功能和權限需求**
- ❌ **避免從未知或可疑來源下載腳本**
- ❌ **不安裝來源不明的腳本檔案**

### 推薦的可信腳本來源

- **[ScriptCat 腳本網站](https://scriptcat.org/)** - ScriptCat 維護的官方腳本網站
- **[GreasyFork](https://greasyfork.org/)** - 全球最大的使用者腳本網站
- **[Userscript.Zone](https://www.userscript.zone/)** - 精選高品質腳本

## 後續步驟

### 存取腳本管理介面

點擊瀏覽器工具列中的 ScriptCat 圖示，然後點擊右上角的「⚙️」齒輪按鈕進入管理介面。

### 取得您的第一個腳本

在彈出介面中，點擊右上角的「⋮」選單並選擇「取得腳本」，前往官方腳本網站搜尋和安裝腳本。

### 探索功能

- 📊 **腳本管理**：啟用/停用腳本、查看執行狀態
- 🔧 **自訂設定**：配置腳本參數和執行規則
- 📝 **腳本編輯**：建立和編輯您自己的腳本
- 🔄 **資料同步**：在多個裝置間同步腳本設定

## 使用建議

1. **從小開始**：新使用者建議從簡單、評價高的腳本開始
2. **定期檢查**：定期檢查和更新已安裝的腳本
3. **備份設定**：重要的腳本設定應進行備份
4. **回報問題**：如遇問題，可透過 [GitHub](https://github.com/scriptscat/scriptcat) 或官方社群提供回饋

## 免責聲明

使用 ScriptCat 時，您需要了解：

- ScriptCat 提供腳本執行環境，但不對第三方腳本的安全性、功能或內容負責
- 您自行承擔使用第三方腳本的風險
- 建議仔細閱讀腳本的原始碼和文件

詳細免責條款請見：[完整免責聲明](/docs/use/policy/disclaimer/)
