## 關於 ScriptCat

受 Tampermonkey 設計啟發，與 Tampermonkey 腳本相容。ScriptCat 實作了背景腳本執行框架，並提供許多特殊 API 讓腳本能做更多事情，搭配優秀的編輯器，讓撰寫和開發腳本代碼更加舒適流暢。

開發路線圖請參閱 [Project #1](https://github.com/scriptscat/scriptcat/projects/1)，我們在此發布開發計畫。如有任何建議，歡迎建立 [issue](https://github.com/scriptscat/scriptcat/issues) 告訴我們。

**如果覺得實用，請考慮給我們一顆 Star ❤❤❤**
