---
title: MCP 整合
---

MCP（[Model Context Protocol](https://modelcontextprotocol.io/)）讓 Agent 能夠連接到外部 MCP 伺服器，並自動取得它們提供的工具、資源和提示範本。

> 與 Agent 的其他子系統不同，MCP 伺服器目前**只能由使用者在管理頁面上配置** — 腳本沒有 `CAT.agent.mcp` 管理 API。腳本唯一能觀察到的是，這些伺服器的工具在對話過程中會被自動呼叫。

## 配置 MCP 伺服器

在管理頁面上新增 → **Agent → MCP**：

| 欄位 | 描述 |
|------|------|
| 名稱 | 伺服器的顯示名稱 |
| URL | Streamable HTTP 端點（透過 POST 的 JSON-RPC 2.0） |
| API 金鑰 | 選用，用於認證 |
| 自訂標頭 | 選用 |
| 已啟用 | 伺服器是否處於啟用狀態 |

ScriptCat 的 MCP 客戶端使用 **Streamable HTTP** 傳輸，支援協定版本 `2025-03-26`。

MCP 伺服器可以提供三種能力：

| 能力 | 描述 |
|------|------|
| **工具** | 自動註冊為 Agent 可呼叫的工具 |
| **資源** | 可讀取的資源（文字/二進位） |
| **提示** | 提示範本，支援參數 |

## 在對話中使用

已啟用的 MCP 伺服器的工具會自動出現在 Agent 對話可用的工具清單中，使用 `mcp_{已清理的伺服器名稱}_{toolName}` 模式命名 — AI 根據使用者意圖決定是否呼叫它們。這與 [Skills](../agent-skill-install) 自動載入的方式類似；腳本開發者通常不需要擔心底層細節。

要檢查特定的 MCP 工具是否可用，只需在對話中直接詢問 AI，或在管理頁面上該伺服器的詳細資訊中檢查已發現的工具清單。
