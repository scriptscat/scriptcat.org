ScriptCat es una extensión de navegador que puede ejecutar userscripts, compatible con scripts de Tampermonkey, y ofrece más funciones.

## Instalar Extensión

### Otros Navegadores

Si tu navegador no está en la lista, descarga el archivo `zip`/`crx` desde [Github Release](https://github.com/scriptscat/scriptcat/releases) e instálalo manualmente.

### Instalación de Extensión Sin Empaquetar

① Descarga el archivo `zip` desde [Github Release](https://github.com/scriptscat/scriptcat/releases) o [Descarga Comunitaria](https://bbs.tampermonkey.net.cn/thread-3068-1-1.html)

② Prepara una carpeta y extrae el archivo zip (**Nota: Esta carpeta no se puede eliminar ni mover**)

③ Abre la interfaz de gestión de extensiones para cargar la extensión sin empaquetar (consulta [Habilitar Modo Desarrollador](/docs/use/open-dev/))

④ Selecciona la carpeta creada en el paso ②

⑤ Haz clic en el ícono de ScriptCat, luego en `┆` > Obtener Scripts

Nota: Las extensiones instaladas así no se actualizan automáticamente.


## Obtener Scripts

> Además de scripts, puedes obtener información y tutoriales del [Foro Chino de Tampermonkey](https://bbs.tampermonkey.net.cn/) y la [Guía de Desarrollo de Scripts](https://learn.scriptcat.org/).

### ScriptCat Script Site

[ScriptCat Script Site](https://scriptcat.org/) es el sitio de scripts de esta extensión.

- Nuevo sitio de scripts
- Scripts de fondo/scripts programados
- Interfaz fácil de usar

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/?utm_source=tm.net&utm_medium=scripts) para buscar userscripts.

- Gran cantidad de recursos de scripts
- Fácil de encontrar userscripts adecuados

### GreasyFork

[GreasyFork](https://greasyfork.org/) es una plataforma ampliamente utilizada para userscripts.

- Gran cantidad de recursos de scripts
- Sincronización desde Github
- [Modelo de desarrollo open source](https://github.com/JasonBarnabe/greasyfork)

### GitHub/Gist

[Buscar recursos de scripts en Github y Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)
