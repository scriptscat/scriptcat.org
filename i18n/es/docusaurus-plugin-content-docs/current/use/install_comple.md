# 🎉 Bienvenido a ScriptCat

¡Felicitaciones por instalar exitosamente la extensión de navegador ScriptCat! ScriptCat es un potente gestor de userscripts compatible con scripts de Tampermonkey y ofrece muchas más funciones.

<GithubStar variant="bar" scene="install" />

## Aviso de Seguridad

⚠️ **¡Los userscripts tienen capacidades poderosas, la seguridad es crucial!**

Los userscripts tienen capacidades poderosas y pueden acceder y modificar contenido de páginas web, por lo que **la seguridad es crucial**. Para proteger su información personal y la seguridad de su dispositivo:

- ✅ **Solo instale scripts de sitios de scripts confiables**
- ✅ **Revise cuidadosamente las calificaciones y comentarios**
- ✅ **Comprenda la funcionalidad y requisitos de permisos**
- ❌ **Evite descargar scripts de fuentes desconocidas o sospechosas**
- ❌ **No instale archivos de scripts de origen desconocido**

### Fuentes de Scripts Confiables Recomendadas

- **[ScriptCat Script Site](https://scriptcat.org/)** - Sitio oficial mantenido por ScriptCat
- **[GreasyFork](https://greasyfork.org/)** - El sitio de userscripts más grande del mundo
- **[Userscript.Zone](https://www.userscript.zone/)** - Scripts de alta calidad curados

## Próximos Pasos

### Acceder a la Interfaz de Gestión

Haga clic en el ícono de ScriptCat en la barra de herramientas, luego en el botón "⚙️" para entrar a la gestión.

### Obtener su Primer Script

En la interfaz emergente, haga clic en "⋮" y seleccione "Obtener Scripts" para ir al sitio oficial.

### Explorar Funciones

- 📊 **Gestión de Scripts**: Activar/desactivar scripts, ver estado
- 🔧 **Configuración Personalizada**: Configurar parámetros
- 📝 **Edición de Scripts**: Crear y editar sus propios scripts
- 🔄 **Sincronización de Datos**: Sincronizar configuraciones

## Recomendaciones de Uso

1. **Comience Pequeño**: Los nuevos usuarios deben comenzar con scripts simples y bien valorados
2. **Verificaciones Regulares**: Revise y actualice sus scripts regularmente
3. **Respaldos de Configuración**: Respalde configuraciones importantes
4. **Reporte Problemas**: Proporcione retroalimentación a través de [GitHub](https://github.com/scriptscat/scriptcat)

## Descargo de Responsabilidad

- ScriptCat proporciona un entorno de ejecución pero no es responsable de la seguridad de scripts de terceros
- Usted asume los riesgos de usar scripts de terceros
- Se recomienda leer el código fuente y documentación de los scripts

Para más detalles: [Descargo Completo](/docs/use/policy/disclaimer/)
