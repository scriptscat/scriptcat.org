## Pasos de Instalación desde Diversos Sitios Web

### ScriptCat Community

[ScriptCat Community](https://scriptcat.org/search) Sitio oficial de ScriptCat

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) es un nuevo sitio que permite buscar userscripts.

- **Gran cantidad de recursos de scripts**
- **Fácil de encontrar userscripts adecuados**
- **Solo muestra userscripts de páginas revisadas**

### GreasyFork

[GreasyFork](https://greasyfork.org/) es una plataforma ampliamente utilizada para alojar y compartir userscripts.

- **Gran cantidad de recursos de scripts**
- **Capacidad para sincronizar scripts desde Github**
- **Modelo de desarrollo de código abierto muy activo**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) fue creado después de GreasyFork.

- **Capacidad para sincronizar scripts desde Github**
- **Modelo de desarrollo de código abierto muy activo**

### GitHub/Gist

Puedes [buscar recursos de scripts en Github y Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## Instalación Manual de Scripts

1. Haz clic en el ícono de la extensión ScriptCat
2. Haz clic en el "Botón de engranaje" para entrar a la interfaz de administración
3. Haz clic en "Crear Nuevo Script" en la esquina superior derecha
4. Pega el código del script en la página emergente
5. Presiona `ctrl + s` para guardar los cambios
6. Vuelve a la interfaz de administración para ver tu script recién creado
