---
title: Instalación de Scripts
---

Esta página se utiliza como paso intermedio para instalar un nuevo script de usuario en `ScriptCat`.

Después de que se complete la instalación, esta página debería cerrarse automáticamente o redirigir.

Esta página no es adecuada para vista directa. Si es necesario, por favor visita [Script de Instalación](/docs/use/script_installation/).
