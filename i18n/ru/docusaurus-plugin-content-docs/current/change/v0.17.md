Начиная с v0.17.0, ScriptCat обновлён до Manifest V3 и переключил движок хранения данных с `indexedDB` на `chrome.storage.local`. При переключении движка хранения автоматически открывается эта страница и перезапускается расширение. Если вы заметите проблемы с данными, сообщите нам на [GitHub](https://github.com/scriptscat/scriptcat/issues).

## v0.17.0-alpha

Рефакторинг для Manifest V3, переключение движка хранения и изменение некоторых функций

- Для согласованности с Tampermonkey из `GM_xmlhttpRequest` удалён параметр `maxRedirects`, вместо него используется `redirect`
- Из `GM_cookie` удалён метод `store` вместе с `storeId` и `tabId`; теперь при получении кук используется `store` текущей страницы (например, обычные и инкогнито окна имеют разные хранилища)
- Удалён `@require-css`
