v1.5 — это полная пересборка интерфейса ScriptCat: более чистый, более единообразный и удобный в использовании — с отдельными оптимизациями для мобильных устройств, чтобы и десктопные, и мобильные пользователи получали лучший опыт.

## Полностью новый интерфейс [#1514](https://github.com/scriptscat/scriptcat/pull/1514)

Весь интерфейс был полностью пересобран с более единообразным визуальным стилем, более чёткой иерархией и полной поддержкой светлой/тёмной темы. Список скриптов предлагает как табличный, так и карточный вид, а также расширенную фильтрацию по статусу, типу, тегу и источнику — так что управление большим количеством скриптов остаётся комфортным.

![Новый десктопный интерфейс](v1.5.assets/desktop.png)

## Мобильные оптимизации

Макет теперь специально разработан для мобильных браузеров, поддерживающих расширения (таких как Edge для Android и Kiwi): список скриптов отображается в виде карточек, предоставлена нижняя навигационная панель, левое выдвижное меню даёт быстрый доступ к Подпискам, Журналам, Инструментам и Настройкам, а всплывающее окно расширения адаптируется под узкие экраны.

![Мобильный интерфейс](v1.5.assets/mobile.png)

## 💥 Внешний доступ (MCP-мост) [#1573](https://github.com/scriptscat/scriptcat/pull/1573)

Локальный демон `sctl` позволяет CLI и MCP-клиентам единообразно обращаться к ScriptCat: просмотр/чтение метаданных скриптов, установка, включение/отключение, удаление и редактирование — всё защищено **многоуровневой авторизацией и страницей подтверждения** с тремя уровнями — Запретить / Разрешить / Разрешить на эту сессию — и каждая операция записывается в журнал аудита.

## 💥 Корзина скриптов [#1585](https://github.com/scriptscat/scriptcat/pull/1585)

Удалённые скрипты больше не уничтожаются сразу — они попадают в корзину, с поддержкой **восстановления** (сохраняя исходные данные и разрешения скрипта), окончательного удаления и автоматической очистки по истечении срока хранения. Срок хранения по умолчанию составляет 30 дней, настраивается в настройках или может быть установлен в «никогда».

## 💥 Официальная поддержка Firefox MV3 [#1561](https://github.com/scriptscat/scriptcat/pull/1561)

Благодаря улучшенной песочничной/внеконтекстной коммуникации, ScriptCat MV3 теперь официально поддерживает браузер Firefox.

## Выбор типа скрипта из редактора [#1544](https://github.com/scriptscat/scriptcat/pull/1544)

Кнопка «＋» на панели вкладок редактора теперь позволяет выбрать тип создаваемого скрипта (обычный / фоновый / запланированный) напрямую, без возврата на страницу списка.

## Ручное скачивание локальных резервных копий [#1543](https://github.com/scriptscat/scriptcat/pull/1543)

Для локальных резервных копий теперь доступна ссылка для ручного скачивания для экспорта файла резервной копии напрямую на устройство.

## structured_clone для сообщений на Chromium 148+ [#1534](https://github.com/scriptscat/scriptcat/pull/1534)

На Chromium 148+ внутренние сообщения расширения используют сериализацию `structured_clone`, поддерживая более широкий набор типов данных.

## Другие улучшения

- **GM API**: нативный `GM_download` теперь учитывает `@connect`, как и `GM_xmlhttpRequest` [#1506](https://github.com/scriptscat/scriptcat/pull/1506)
- **Производительность**: улучшен кэш загрузки скриптов и исправлены остаточные всплывающие меню [#1511](https://github.com/scriptscat/scriptcat/pull/1511)
- **Редактор**: скорректированы правила `eslint-plugin-userscripts` [#1510](https://github.com/scriptscat/scriptcat/pull/1510)
- Предрелизные (beta) обновления теперь автоматически открывают страницу журнала изменений
- **Исправление**: устранение проблем с запланированными задачами, вызванных автоопределением неверного часового пояса в cron [#1531](https://github.com/scriptscat/scriptcat/pull/1531)
- **Исправление**: замена недоступного демо API в примере crontab [#1542](https://github.com/scriptscat/scriptcat/pull/1542)
- **i18n**: добавлены корейский, турецкий и бразильский португальский
