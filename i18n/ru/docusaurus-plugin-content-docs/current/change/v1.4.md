v1.4 — это крупное обновление ScriptCat, представляющее полностью новую систему **Агента**, которая позволяет пользователям автоматизировать действия в браузере, извлекать веб-данные, управлять файлами и запускать запланированные задачи через разговор на естественном языке.

## Агент

На панели управления добавлена новая точка входа в чат Агента, где можно вести многоходовой диалог с языковой моделью; ИИ автоматически вызывает встроенные инструменты для выполнения задач.

**Основные возможности:**

- **Поддержка нескольких моделей** — совместимые с OpenAI и нативные форматы Anthropic, поддержка Prompt Caching
- **11 встроенных инструментов** — загрузка/поиск в интернете, управление вкладками, файловая система OPFS, выполнение кода, взаимодействие с пользователем и др.
- **Система навыков (Skill)** — комплекты промптов + скрипты инструментов + справочный материал, расширяющие предметные знания Агента
- **Интеграция MCP** — поддержка [Model Context Protocol](https://modelcontextprotocol.io/) для подключения к внешним серверам инструментов
- **Автоматизация DOM** — навигация по страницам, скриншоты, клики, заполнение полей, прокрутка, выполнение скриптов и др.
- **Запланированные задачи** — планирование задач на основе cron-выражений (режимы Internal / Event)
- **Субагенты** — возможность запускать независимые субагенты для решения сложных подзадач
- **Управление контекстом** — авто-сжатие и Prompt Caching для снижения потребления токенов

**Script API (`CAT.agent.*`):**

Пользовательские скрипты могут вызывать функции Агента через пространство имён `CAT.agent.*`, включая API для разговора, DOM, навыков, задач, моделей, OPFS и MCP. Каждый API требует объявления соответствующего разрешения через `@grant`.

**6 страниц панели управления:** Чат, Настройки модели, Управление навыками, Запланированные задачи, Серверы MCP и Браузер OPFS.

## Поддержка тега `@unwrap`

Позволяет инжектить скрипт напрямую в страницу, минуя песочницу-обёртку.

## Событие `window.onurlchange`

Реализовано отслеживание изменения URL, совместимое с Tampermonkey, на основе Navigation API.

## Улучшения редактора

Добавлено контекстное меню редактора (поиск, замена, отмена и т.д.), исправлены проблемы с горячими клавишами и подсказками.

## Мультиплатформенные поисковые системы

Поиск скриптов теперь поддерживает выбор между различными поисковыми платформами.

## Дополнительные поставщики иконок

Добавлены новые сервисы для получения иконок скриптов.
