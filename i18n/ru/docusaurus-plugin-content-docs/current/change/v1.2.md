title: v1.2
---

Исправлена проблема, при которой обновление версии больше не автоматически открывало страницу журнала изменений.

## Боковая панель списка скриптов [#794](https://github.com/scriptscat/scriptcat/issues/794)

В боковую панель добавлена расширенная фильтрация, а также функция тегов; теги можно редактировать через Скрипт → Настройки.

![image-20251016230129315](@site/docs/change/v1.2.assets/image-20251016230129315.png)

## Карточный вид [#860](https://github.com/scriptscat/scriptcat/issues/860)

Добавлен карточный вид, который автоматически переключается между карточным и табличным видом при первом запуске, что позволяет лучше отображать информацию о скриптах на узких экранах.

![image-20251023103730266](@site/docs/change/v1.2.assets/image-20251023103730266.png)

## Улучшенная логика проверки обновлений [#755](https://github.com/scriptscat/scriptcat/issues/755)

Оптимизирована логика проверки обновлений — вместо отдельного окна обновления для каждого скрипта они объединяются в одно окно, где можно выбрать, какие скрипты обновить, или обновить все одним нажатием. Также показывается степень изменений каждого скрипта.

![image-20251016225931823](@site/docs/change/v1.2.assets/image-20251016225931823.png)

## Добавлены настройки редактора и определения типов [#708](https://github.com/scriptscat/scriptcat/pull/708)

Теперь можно настраивать конфигурацию редактора и определения типов; конфигурация редактора может быть написана с ориентацией на [compilerOptions](https://www.typescriptlang.org/tsconfig/#compilerOptions) из `tsconfig.json`.

![08c2889f-3029-4d3c-b180-c52d77c8077c](@site/docs/change/v1.2.assets/08c2889f-3029-4d3c-b180-c52d77c8077c.png)

## Параметр фонового выполнения [#1048](https://github.com/scriptscat/scriptcat/pull/1048)

В разделе Настройки → Среда выполнения добавлён параметр фонового выполнения. При включении браузер продолжает работать в фоне и сворачивается в системный трей даже после закрытия всех окон, пока вы не выйдете из браузера вручную. Это позволяет фоновым скриптам продолжать работу.

![image-20251204174034940](@site/docs/change/v1.2.assets/image-20251204174034940.png)

## Обновления API

- Поддержка `inject-into`, позволяющая инжектить скрипты в среду контента [#711](https://github.com/scriptscat/scriptcat/issues/711)
- `GM_openInTab` поддерживает параметры фиксации вкладки, открытия в окне инкогнито и другие [#788](https://github.com/scriptscat/scriptcat/pull/788)
- `GM_registerMenuCommand` поддерживает меню второго уровня и разделители [#831](https://github.com/scriptscat/scriptcat/pull/831)
