---
title: Installazione degli Script
---

Questa pagina viene utilizzata come passaggio intermedio per installare un nuovo script utente in `ScriptCat`.

Dopo il completamento dell'installazione, questa pagina dovrebbe chiudersi automaticamente o reindirizzare.

Questa pagina non è adatta alla visualizzazione diretta. Se necessario, visitare [Script di Installazione](/docs/use/script_installation/).
