## Passaggi di Installazione da Vari Siti Web

### ScriptCat Community

[ScriptCat Community](https://scriptcat.org/search) Sito ufficiale di ScriptCat

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) è un nuovo sito che permette di cercare userscript.

- **Gran quantità di risorse di script**
- **Facile da trovare userscript adatti**
- **Mostra solo userscript da pagine verificate**

### GreasyFork

[GreasyFork](https://greasyfork.org/) è una piattaforma ampiamente utilizzata per ospitare e condividere userscript.

- **Gran quantità di risorse di script**
- **Capacità di sincronizzare script da Github**
- **Modello di sviluppo open source molto attivo**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) è stato creato dopo GreasyFork.

- **Capacità di sincronizzare script da Github**
- **Modello di sviluppo open source molto attivo**

### GitHub/Gist

Puoi [cercare risorse di script in Github e Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## Installazione Manuale degli Script

1. Clicca sull'icona dell'estensione ScriptCat
2. Clicca sul "Pulsante ingranaggio" per entrare nell'interfaccia di gestione
3. Clicca su "Crea Nuovo Script" in alto a destra
4. Incolla il codice dello script nella pagina popup
5. Premi `ctrl + s` per salvare le modifiche
6. Torna all'interfaccia di gestione per vedere il tuo script appena creato
