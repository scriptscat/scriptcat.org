ScriptCat è un'estensione del browser che può eseguire userscript, compatibile con gli script di Tampermonkey, e offre molte altre funzionalità.

## Installare l'Estensione

| Browser | Link Store | Stato |
| --- | --- | --- |
| Chrome | [Versione Stabile](https://chrome.google.com/webstore/detail/scriptcat/ndcooeababalnlpkfedmmbbbgkljhpjf) [Versione Beta](https://chromewebstore.google.com/detail/%E8%84%9A%E6%9C%AC%E7%8C%AB-beta/jaehimmlecjmebpekkipmpmbpfhdacom?authuser=0&hl=zh-CN) | ✅ Disponibile |
| Edge | [Versione Stabile](https://microsoftedge.microsoft.com/addons/detail/scriptcat/liilgpjgabokdklappibcjfablkpcekh) [Versione Beta](https://microsoftedge.microsoft.com/addons/detail/scriptcat-beta/nimmbghgpcjmeniofmpdfkofcedcjpfi) | ✅ Disponibile |
| Firefox | [Versione Stabile](https://addons.mozilla.org/zh-CN/firefox/addon/scriptcat/) [Versione Beta](https://addons.mozilla.org/zh-CN/firefox/addon/scriptcat-pre/) | ✅ MV2 |

### Altri Browser

Se il tuo browser non è nella lista, scarica il file `zip`/`crx` dalla pagina [Github Release](https://github.com/scriptscat/scriptcat/releases) e installalo manualmente.

### Installazione Estensione Non Impacchettata

① Scarica il file `zip` da [Github Release](https://github.com/scriptscat/scriptcat/releases) o [Download Community](https://bbs.tampermonkey.net.cn/thread-3068-1-1.html)

② Prepara una cartella ed estrai il file zip (**Nota: Questa cartella non può essere eliminata o spostata**)

③ Apri l'interfaccia di gestione estensioni per caricare l'estensione non impacchettata (consulta [Abilita Modalità Sviluppatore](/docs/use/open-dev/))

④ Seleziona la cartella creata al passo ②

⑤ Clicca sull'icona di ScriptCat, poi su `┆` > Ottieni Script

Nota: Le estensioni installate così non si aggiornano automaticamente.


## Ottenere Script

> Oltre agli script, puoi ottenere informazioni e tutorial dal [Forum Cinese Tampermonkey](https://bbs.tampermonkey.net.cn/) e dalla [Guida allo Sviluppo Script](https://learn.scriptcat.org/).

### ScriptCat Script Site

[ScriptCat Script Site](https://scriptcat.org/) è il sito degli script per questa estensione.

- Nuovo sito degli script
- Script di background/script pianificati
- Interfaccia user-friendly

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/?utm_source=tm.net&utm_medium=scripts) per cercare userscript.

- Gran quantità di risorse di script
- Facile da trovare userscript adatti

### GreasyFork

[GreasyFork](https://greasyfork.org/) è una piattaforma ampiamente utilizzata per gli userscript.

- Gran quantità di risorse di script
- Sincronizzazione da Github
- [Modello di sviluppo open source](https://github.com/JasonBarnabe/greasyfork)

### GitHub/Gist

[Cercare risorse di script in Github e Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)
