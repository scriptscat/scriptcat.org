# 🎉 Benvenuto in ScriptCat

Congratulazioni per aver installato con successo l'estensione del browser ScriptCat! ScriptCat è un potente gestore di userscript compatibile con gli script di Tampermonkey e offre molte altre funzionalità potenti.

<GithubStar variant="bar" scene="install" />

## Avviso di Sicurezza

⚠️ **Gli userscript hanno capacità potenti, la sicurezza è fondamentale!**

Gli userscript hanno capacità potenti e possono accedere e modificare il contenuto delle pagine web, quindi **la sicurezza è fondamentale**. Per proteggere le tue informazioni personali e la sicurezza del dispositivo:

- ✅ **Installa script solo da siti di script affidabili**
- ✅ **Controlla attentamente le valutazioni e i commenti**
- ✅ **Comprendi la funzionalità e i requisiti di permessi**
- ❌ **Evita di scaricare script da fonti sconosciute o sospette**
- ❌ **Non installare file di script di origine sconosciuta**

### Fonti di Script Affidabili Raccomandate

- **[ScriptCat Script Site](https://scriptcat.org/)** - Sito ufficiale mantenuto da ScriptCat
- **[GreasyFork](https://greasyfork.org/)** - Il sito di userscript più grande al mondo
- **[Userscript.Zone](https://www.userscript.zone/)** - Script di alta qualità curati

## Prossimi Passi

### Accedere all'Interfaccia di Gestione

Clicca sull'icona di ScriptCat nella barra degli strumenti, poi sul pulsante "⚙️" per entrare nella gestione.

### Ottenere il Tuo Primo Script

Nell'interfaccia popup, clicca su "⋮" e seleziona "Ottieni Script" per andare al sito ufficiale.

### Esplorare le Funzionalità

- 📊 **Gestione Script**: Attiva/disattiva script, visualizza stato
- 🔧 **Impostazioni Personalizzate**: Configura parametri
- 📝 **Modifica Script**: Crea e modifica i tuoi script
- 🔄 **Sincronizzazione Dati**: Sincronizza configurazioni

## Raccomandazioni d'Uso
