- [x] Google Drive
- [x] Dropbox

## Sincronizzazione

Quando uno script viene aggiornato, verrà sincronizzato immediatamente nel cloud. Tuttavia, quando i dati cloud cambiano, ci vuole un po' di tempo per scansionare e sincronizzare localmente. Si prega di notare questo quando più dispositivi condividono lo stesso archivio cloud.

Cliccando Salva nella sezione di sincronizzazione degli script verrà eseguita immediatamente una sincronizzazione completa.
