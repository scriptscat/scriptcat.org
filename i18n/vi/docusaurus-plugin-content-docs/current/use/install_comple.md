# 🎉 Chào mừng đến với ScriptCat

Chúc mừng bạn đã cài đặt thành công tiện ích mở rộng trình duyệt ScriptCat! ScriptCat là trình quản lý userscript mạnh mẽ tương thích với script Tampermonkey và cung cấp nhiều tính năng mạnh mẽ hơn.

<GithubStar variant="bar" scene="install" />

## Thông báo Bảo mật

⚠️ **Userscript có khả năng mạnh mẽ, bảo mật rất quan trọng!**

Userscript có khả năng mạnh mẽ và có thể truy cập, chỉnh sửa nội dung trang web, vì vậy **bảo mật rất quan trọng**. Để bảo vệ thông tin cá nhân và bảo mật thiết bị của bạn:

- ✅ **Chỉ cài đặt script từ các trang script đáng tin cậy**
- ✅ **Kiểm tra kỹ đánh giá và bình luận của người dùng**
- ✅ **Hiểu chức năng và yêu cầu quyền hạn của script**
- ❌ **Tránh tải script từ nguồn không xác định hoặc đáng ngờ**
- ❌ **Không cài đặt file script từ nguồn không rõ ràng**

### Nguồn Script Đáng tin cậy được Đề xuất

- **[ScriptCat Script Site](https://scriptcat.org/)** - Trang web chính thức do ScriptCat duy trì
- **[GreasyFork](https://greasyfork.org/)** - Trang web userscript lớn nhất thế giới
- **[Userscript.Zone](https://www.userscript.zone/)** - Script chất lượng cao được tuyển chọn

## Các Bước Tiếp theo

### Truy cập Giao diện Quản lý

Nhấp vào biểu tượng ScriptCat trên thanh công cụ, sau đó nhấp nút "⚙️" để vào quản lý.

### Lấy Script Đầu tiên

Trong giao diện popup, nhấp "⋮" và chọn "Lấy Script" để đến trang web chính thức.

### Khám phá Tính năng

- �📊 **Quản lý Script**: Bật/tắt script, xem trạng thái
- 🔧 **Tùy chỉnh**: Cấu hình tham số script
- 📝 **Chỉnh sửa Script**: Tạo và chỉnh sửa script của bạn
- 🔄 **Đồng bộ Dữ liệu**: Đồng bộ cài đặt script

## Khuyến nghị Sử dụng

1. **Bắt đầu Nhỏ**: Người dùng mới nên bắt đầu với script đơn giản, được đánh giá cao
2. **Kiểm tra Định kỳ**: Thường xuyên kiểm tra và cập nhật script đã cài đặt
3. **Sao lưu Cài đặt**: Sao lưu các cấu hình script quan trọng
4. **Báo cáo Sự cố**: Đóng góp phản hồi qua [GitHub](https://github.com/scriptscat/scriptcat)

## Miễn trừ Trách nhiệm

- ScriptCat cung cấp môi trường thực thi script nhưng không chịu trách nhiệm về bảo mật của script bên thứ ba
- Bạn tự chịu rủi ro khi sử dụng script bên thứ ba
- Nên đọc kỹ mã nguồn và tài liệu script
