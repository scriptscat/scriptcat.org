ScriptCat là tiện ích mở rộng trình duyệt có thể chạy script, tương thích với script Tampermonkey và cung cấp nhiều tính năng hơn.

### Trình duyệt Khác

Nếu trình duyệt của bạn không có trong danh sách, tải tệp `zip`/`crx` từ trang [Github Release](https://github.com/scriptscat/scriptcat/releases) và cài đặt thủ công.

### Cài đặt Tiện ích Chưa Đóng gói {#load-unpacked-extension-installation}

① Tải tệp `zip` từ [Github Release](https://github.com/scriptscat/scriptcat/releases) hoặc [Tải xuống Cộng đồng](https://bbs.tampermonkey.net.cn/thread-3068-1-1.html)

② Chuẩn bị thư mục và giải nén tệp zip (**Lưu ý: Thư mục này không thể xóa hoặc di chuyển**)

③ Mở giao diện quản lý tiện ích để tải tiện ích chưa đóng gói (tham khảo [Bật Chế độ Nhà phát triển](/docs/use/open-dev/))

④ Chọn thư mục tạo ở bước ②

⑤ Nhấp vào biểu tượng ScriptCat, sau đó `┆` > Lấy Script

Lưu ý: Tiện ích cài đặt theo cách này không thể tự động cập nhật.


## Lấy Script

> Ngoài script, bạn cũng có thể lấy thông tin và hướng dẫn từ [Diễn đàn Trung Quốc Tampermonkey](https://bbs.tampermonkey.net.cn/) và [Hướng dẫn Phát triển Script](https://learn.scriptcat.org/).

### ScriptCat Script Site

[ScriptCat Script Site](https://scriptcat.org/) là trang web script của tiện ích này.

- Trang web script mới
- Script nền / script lên lịch
- Giao diện thân thiện

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/?utm_source=tm.net&utm_medium=scripts) để tìm kiếm script.

- Đa dạng tài nguyên script
- Dễ tìm script phù hợp

### GreasyFork

[GreasyFork](https://greasyfork.org/) là nền tảng được sử dụng rộng rãi cho script.

- Đa dạng tài nguyên script
- Đồng bộ từ Github
- [Mô hình phát triển mã nguồn mở](https://github.com/JasonBarnabe/greasyfork)

### GitHub/Gist

[Tìm tài nguyên script trên Github và Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)
