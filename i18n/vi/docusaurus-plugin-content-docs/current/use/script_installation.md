## Các bước Cài đặt từ Các Trang Web Khác nhau

### ScriptCat Community

[ScriptCat Community](https://scriptcat.org/search) Trang web chính thức của ScriptCat

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) là trang web mới cho phép tìm kiếm userscript.

- **Đại lượng tài nguyên script**
- **Dễ dàng tìm userscript phù hợp**
- **Chỉ hiển thị userscript từ các trang đã được đánh giá**

### GreasyFork

[GreasyFork](https://greasyfork.org/) là nền tảng được sử dụng rộng rãi để lưu trữ và chia sẻ userscript.

- **Đại lượng tài nguyên script**
- **Khả năng đồng bộ script từ Github**
- **Mô hình phát triển mã nguồn mở rất năng động**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) được tạo sau GreasyFork.

- **Khả năng đồng bộ script từ Github**
- **Mô hình phát triển mã nguồn mở rất năng động**

### GitHub/Gist

Bạn có thể [tìm tài nguyên script trên Github và Gist.](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## Cài đặt Script Thủ công

1. Nhấp vào biểu tượng tiện ích ScriptCat
2. Nhấp vào "nút Bánh răng" để vào giao diện quản lý
3. Nhấp vào "Tạo Script Mới" ở góc trên bên phải
4. Dán mã script vào trang popup
5. Nhấn `ctrl + s` để lưu thay đổi
6. Quay lại giao diện quản lý để xem script vừa tạo
