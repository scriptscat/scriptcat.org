ScriptCat はボランティアによって運営されるオープンソースプロジェクトで、企業の支援はありません。サーバー、ドメイン、その他のインフラストラクチャ、そして多くの開発とメンテナンスの時間は、すべてコミュニティの支援によって支えられています。すべての貢献がScriptCatをさらに前へ進めます。

## スポンサー収入の使い道

スポンサー収入は主に以下に使用されます：

- **運用コストのカバー** — サーバー、ドメイン、その他の日常的なインフラストラクチャ。
- **メンテナーとコントリビューターの報酬** — 長期的なメンテナーや、コード、翻訳、ドキュメントを送信するすべての人々が、相応の報酬を受けられるように。
- **新機能の構築** — 体験を磨き、新機能を開発するためのより多くの時間。

## スポンサーになる方法

個人でも企業でも、規模の大小を問わず、すべての支援が重要です。

[OpenCollective](https://opencollective.com/scriptcat) を通じてスポンサーを募集中です。一回または月額の寄付が可能で、寄付後はスポンサーリストに名前が表示されます。

**スポンサー掲載** — README、ウェブサイト、またはドキュメントにロゴと紹介を表示したい場合は、[codfrm@gmail.com](mailto:codfrm@gmail.com) までメールしてください。

## スポンサー掲載場所

スポンサーのロゴと説明は、以下の場所に表示できます（メールで手配）：

| 掲載場所 | フォーマット |
| --- | --- |
| GitHub README のトップ | 大きなバナー |
| GitHub README スポンサー欄 | ロゴ + 1行紹介 |
| ウェブサイトスポンサーページ（このページ） | ロゴ + 紹介 |
| ウェブサイトドキュメントページ（例：更新履歴） | ロゴ表示 |
