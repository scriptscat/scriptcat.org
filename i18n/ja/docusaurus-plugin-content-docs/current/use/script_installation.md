> まず [クイックスタート](/docs/use/use/) を参照して ScriptCat 拡張機能をインストールしてください。

## 各ウェブサイトからのインストール手順

### ScriptCat コミュニティ

[ScriptCat コミュニティ](https://scriptcat.org/search) ScriptCat 公式サイト

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) は、適切な URL やドメインを入力してユーザースクリプトを検索できる新しいサイトです。

- **大量のスクリプトリソース**
- **適切なユーザースクリプトが簡単に見つかる**
- **レビュー済みのユーザースクリプトページまたは少なくともコメント機能があるページのスクリプトのみ表示**

### GreasyFork

[GreasyFork](https://greasyfork.org/) は、ユーザースクリプトのホスティングと共有に広く使用されるプラットフォームです。開発者が公開し、ユーザーがブラウザベースのスクリプトをインストールできます。Jason Barnabe によって作成され、セキュリティとオープンソースの透明性を重視しています。

Jason Barnabe は Stylish ブラウザ拡張機能のオリジナルクリエイターでもあります。しかし、[Stylish](https://userstyles.org/) は2016年に売却され、現在は別の会社が運営しています。

- **大量のスクリプトリソース**
- **Github からスクリプトを同期する機能がある**
- **非常に活発なオープンソース開発モデル**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) は GreasyFork の後に作成されました。Sizzle McTwizzle によって作成され、同様にリポジトリに大量のスクリプトリソースがあります。

- **Github からスクリプトを同期する機能がある**
- **非常に活発なオープンソース開発モデル**

### GitHub/Gist

[Github と Gist でスクリプトリソースを検索できます。](https://gist.github.com/search?l=JavaScript&o=desc&q="%3D%3DUserScript%3D%3D"&s=updated)


## 手動スクリプトインストール

1. ScriptCat 拡張機能アイコンをクリック
2. インターフェースの「歯車ボタン」をクリックして ScriptCat 管理インターフェースに入る
3. 右上の「新しいスクリプトを作成」ボタンをクリック（通常は通常スクリプトを作成するだけで十分です）
4. ポップアップページでスクリプトコードを貼り付け
5. `ctrl + s` を押して変更を保存
6. 管理インターフェースに戻って新しく作成したスクリプトを確認
