# 🎉 ScriptCat へようこそ

ScriptCat ブラウザ拡張機能のインストールに成功しました！ScriptCat は Tampermonkey スクリプトと互換性があり、さらに多くの強力な機能を提供する強力なユーザースクリプトマネージャーです。

<GithubStar variant="bar" scene="install" />

## セキュリティに関する注意

⚠️ **ユーザースクリプトには強力な機能があります。セキュリティが重要です！**

ユーザースクリプトには強力な機能があり、ウェブページの内容にアクセスし変更できるため、**セキュリティが重要です**。個人情報とデバイスのセキュリティを保護するために、以下を確認してください：

- ✅ **信頼できるスクリプトサイトからのみスクリプトをインストールする**
- ✅ **スクリプトの評価とユーザーコメントを注意深く確認する**
- ✅ **スクリプトの機能と権限要件を理解する**
- ❌ **不明または疑わしいソースからのスクリプトのダウンロードを避ける**
- ❌ **不明な出所のスクリプトファイルをインストールしない**

### おすすめの信頼できるスクリプトソース

以下のスクリプトサイトからスクリプトを取得することをお勧めします：

- **[ScriptCat スクリプトサイト](https://scriptcat.org/)** - ScriptCat が運営する公式スクリプトサイト
- **[GreasyFork](https://greasyfork.org/)** - 世界最大のユーザースクリプトサイト
- **[Userscript.Zone](https://www.userscript.zone/)** - 厳選された高品質スクリプト

## 次のステップ

### スクリプト管理インターフェースにアクセス

ブラウザのツールバーにある ScriptCat アイコンをクリックし、右上の「⚙️」ギアボタンをクリックして管理インターフェースに入ります。

### 最初のスクリプトを取得

ポップアップインターフェースで、右上の「⋮」メニューをクリックして「スクリプトを取得」を選択し、公式スクリプトサイトでスクリプトを検索してインストールします。

### 機能を探索

- 📊 **スクリプト管理**: スクリプトの有効/無効、実行状態の確認
- 🔧 **カスタム設定**: スクリプトパラメータと実行ルールの設定
- 📝 **スクリプト編集**: 自分のスクリプトの作成と編集
- 🔄 **データ同期**: 複数デバイス間でスクリプト設定を同期

## 使い方の推奨

1. **小さく始める**: 新しいユーザーは、シンプルで評価の高いスクリプトから始めることをお勧めします
2. **定期的な確認**: インストールしたスクリプトを定期的に確認・更新してください
3. **設定のバックアップ**: 重要なスクリプト設定はバックアップしてください
4. **問題の報告**: 問題が発生した場合は、[GitHub](https://github.com/scriptscat/scriptcat) または公式コミュニティでフィードバックできます

- サードパーティスクリプトの使用によるリスクはご自身で負担します
