## ScriptCat について

Tampermonkey の設計にインスパイアされ、Tampermonkey スクリプトと互換性があります。ScriptCat はバックグラウンドスクリプト実行フレームワークを実装し、スクリプトがさらに多くのことをできるようにする特殊な API を多数提供しています。また、スクリプトコードの作成と開発をより快適でスムーズにする優れたエディタも備えています。

開発ロードマップについては [Project #1](https://github.com/scriptscat/scriptcat/projects/1) を参照してください。開発計画を公開しています。ご提案がありましたら、お気軽に [issue](https://github.com/scriptscat/scriptcat/issues) を作成してください。

**お役に立った場合は、Star を付けていただけると幸いです ❤❤❤**

## Tampermonkey 中国語フォーラム
> [こちらをクリックしてアクセス](https://bbs.tampermonkey.net.cn/)

Tampermonkey 中国語フォーラムは、Tampermonkey スタイルのスクリプトの開発と議論のために作成されたコミュニティです。フォーラムには豊富なスクリプト学習リソースと多くの経験豊富なメンバーがおり、議論や質問ができます。スクリプトの公開とインストールもサポートしており、誰もが自由に自分の作品を共有できます。
