ScriptCat-ը բաց կոդով նախագիծ է, որը պահպանվում է կամավորների կողմից՝ առանց ընկերության աջակցության: Սերվերները, դոմենները և այլ ենթակառուցվածքը, ինչպես նաև զարգացման ու պահպանման մեծ ժամանակը, բոլորը պահպանվում են համայնքի աջակցությամբ: Յուրաքանչյուր ներդրում օգնում է ScriptCat-ին առաջ գնալ:

## Ուր է գնում ձեր հովանավորությունը

Հովանավորության եկամուտը հիմնականում ուղղվում է՝

- **Գործառնական ծախսերի ծածկմանը** — սերվերներ, դոմեններ և այլ առօրյա ենթակառուցվածք:
- **Պահպանողների և ներդրողների պարգևատրմանը** — որպեսզի երկարաժամկետ պահպանողները և բոլոր նրանք, ովքեր ուղարկում են կոդ, թարգմանություններ և փաստաթղթեր, ստանան իրենց արժանի պարգևը:
- **Նոր հնարավորությունների ստեղծմանը** — ավելի շատ ժամանակ փորձը հղկելու և նոր կարողություններ զարգացնելու համար:

## Ինչպես հովանավորել

Անկախ նրանից՝ դուք անհատ եք, թե ընկերություն, և անկախ չափից, աջակցության յուրաքանչյուր կտոր կարևոր է:

Մենք հովանավորություններ ենք հավաքում [OpenCollective](https://opencollective.com/scriptcat) միջոցով՝ միանվագ կամ ամսական ներդրումներով; ձեր անունը կհայտնվի աջակիցների ցուցակում նվիրաբերելուց հետո:

Եթե ցանկանում եք **հովանավորի տեղաբաշխում** — ձեր լոգոն և ներածությունը README-ում, կայքում կամ փաստաթղթերում — գրեք մեզ [codfrm@gmail.com](mailto:codfrm@gmail.com) հասցեին:

## Հովանավորի տեղաբաշխումներ

Հովանավորի լոգոն և նկարագրությունը կարող են ցուցադրվել հետևյալ վայրերում՝ էլ. փոստով համաձայնեցնելով՝

| Տեղաբաշխում | Ձևաչափ |
| --- | --- |
| GitHub README-ի վերևում | Մեծ պաստառ |
| GitHub README հովանավորների հատված | Լոգո + մեկ տողանոց ներածություն |
| Կայքի հովանավորների էջ (այս էջը) | Լոգո + ներածություն |
| Կայքի փաստաթղթերի էջեր (օր.՝ փոփոխությունների տեղեկագիր) | Լոգոյի ցուցադրում |
