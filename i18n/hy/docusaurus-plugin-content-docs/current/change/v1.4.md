v1.4-ը ScriptCat-ի խոշոր թարմացում է, որը ներկայացնում է բոլորովին նոր **Agent** համակարգ՝ թույլ տալով օգտատերերին ավտոմատացնել զննարկչի գործողությունները, հանել վեբ տվյալները, կառավարել ֆայլերը և կատարել ժամանակացույցով առաջադրանքներ բնական լեզվով զրույցի միջոցով:

## Agent

Կառավարման վահանակում ավելացվել է Agent զրույցի նոր մուտք, որտեղ կարող եք բազմափուլ զրույց վարել AI մոդելի հետ. AI-ն ավտոմատ կերպով կանչում է ներկառուցված գործիքներ՝ առաջադրանքները կատարելու համար:

**Հիմնական հնարավորություններ.**

- **Բազմաթիվ մոդելների աջակցություն** — OpenAI համատեղելի և բնիկ Anthropic ձևաչափեր, Prompt Caching աջակցությամբ
- **11 ներկառուցված գործիք** — վեբ ներբեռնում/որոնում, ներդիրների կառավարում, OPFS ֆայլային համակարգ, կոդի կատարում, օգտատիրոջ փոխազդեցություն և այլն
- **Skill համակարգ** — հրահանգների + գործիքային սկրիպտների + տեղեկատու նյութերի փաթեթներ, որոնք ընդլայնում են Agent-ի ոլորտային գիտելիքները
- **MCP ինտեգրացիա** — աջակցում է [Model Context Protocol](https://modelcontextprotocol.io/)՝ արտաքին գործիքային սերվերներին միանալու համար
- **DOM ավտոմատացում** — էջի նավարկում, սքրինշոթեր, սեղմումներ, լրացում, ոլորում, սկրիպտի կատարում և այլն
- **Ժամանակացույցով առաջադրանքներ** — Cron արտահայտությունների վրա հիմնված պլանավորում (Ներքին / Իրադարձություն ռեժիմներ)
- **Ենթա-գործակալներ** — կարող են ստեղծել անկախ ենթա-գործակալներ՝ բարդ ենթաառաջադրանքները կատարելու համար
- **Կոնտեքստի կառավարում** — ավտոմատ սեղմում և Prompt Caching՝ տոկենների ծախսը նվազեցնելու համար

**Սկրիպտի API (`CAT.agent.*`).**

Օգտագործողի սկրիպտները կարող են կանչել Agent-ի հնարավորությունները `CAT.agent.*` անվանատարածքի միջոցով՝ ներառյալ conversation, dom, skills, task, model, opfs և mcp API-ները: Յուրաքանչյուր API պահանջում է համապատասխան թույլտվության հայտարարում `@grant`-ով:

**Կառավարման վահանակի 6 էջ.** Զրույց, Մոդելի կարգավորում, Skill-ների կառավարում, Ժամանակացույցով առաջադրանքներ, MCP սերվերներ և OPFS զննարկիչ:
