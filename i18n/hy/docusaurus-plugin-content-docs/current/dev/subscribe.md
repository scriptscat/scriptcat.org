---
title: Բաժանորդագրության ռեժիմ
---

Ֆայլը պետք է սկսվի `UserSubscribe`-ով՝ `UserScript`-ի փոխարեն: Տեղադրման հղումը պետք է օգտագործի `user.sub.js` ընդլայնումը, և պետք է լինի `https` հղում:

Բաժանորդագրության սկրիպտը տեղադրման ժամանակ ցույց է տալիս միայն տեղադրման երկխոսությունը՝ օգտագործողին բաժանորդագրությունը հաստատելու համար; հետագա թարմացումները կատարվում են լուռ, և թարմացման երկխոսությունը նորից ցուցադրվում է միայն այն դեպքում, եթե `connect` թույլտվությունը փոխվում է:

Մեկ բաժանորդագրության սկրիպտը կարող է նկարագրել մի քանի սկրիպտների տեղադրման հղումներ: Բաժանորդագրության ռեժիմով տեղադրված սկրիպտները տեղադրվում են լուռ՝ առանց հաստատման երկխոսության, և տեղադրված սկրիպտները դեռ հայտնվում են սկրիպտների ցուցակում — բայց դրանց `connect` թույլտվությունը օգտագործում է բաժանորդագրության մեջ հայտարարված `connect`-ը՝ սկրիպտի սեփական `connect` թույլտվության փոխարեն:

```js
// ==UserSubscribe==
// @name         xxx
// @description  Subscribe to the xxx script series
// @version      0.1.0
// @author       You
// @connect      www.baidu.com
// @scriptUrl    https://script.tampermonkey.net.cn/48.user.js
// @scriptUrl    https://script.tampermonkey.net.cn/49.user.js
// ==/UserSubscribe==
```

## Բաժանորդագրության թարմացումներ և սկրիպտի թարմացումներ

Ըստ օգտագործողի կարգավորած `թարմացման միջակայքի`, ScriptCat-ը պարբերաբար ստուգում է բաժանորդագրության հղումը թարմացումների համար; դրա համար գործելու համար պետք է կարգավորված լինի `version`:

Բաժանորդագրության յուրաքանչյուր թարմացում կամ փոփոխություն համեմատում է սկրիպտի հղումները ներկայումս տեղադրված սկրիպտների հետ. նոր բաժանորդագրության մեջ այլևս չգտնվող սկրիպտները հեռացվում են, իսկ նոր ավելացված սկրիպտները տեղադրվում են լուռ: Սկրիպտի թարմացումները հետևում են սկրիպտի սեփական `version`-ին՝ օգտագործելով նույն թարմացման տրամաբանությունը, ինչ սովորաբար տեղադրված սկրիպտը:

## Լուռ տեղադրում և թարմացում

Բաժանորդագրված սկրիպտները տեղադրվում և թարմացվում են լուռ — բաժանորդագրությունից սկրիպտ ավելացնելը, հեռացնելը կամ թարմացնելը ցույց է տալիս միայն ծանուցում՝ առանց օգտագործողի կրկին հաստատում պահանջելու: Այս լուռ թարմացման մեխանիզմի պատճառով խնդրում ենք բաժանորդագրվել միայն այն աղբյուրներին, որոնց վստահում եք:


## metadata

Որոշ մետատվյալների դաշտերի իմաստը փոխվում է բաժանորդագրության սկրիպտի ներսում:

### name

Բաժանորդագրության անունը (կարող է նաև ուղղակիորեն խմբագրվել բաժանորդագրությունների ցուցակում)

### description

Բաժանորդագրության նկարագրությունը, որը նկարագրում է, թե ինչի համար է բաժանորդագրությունը

### version

Բաժանորդագրության տարբերակը: Եթե բացակայում է, թարմացումները փոխարենը գործարկվում են՝ կախված նրանից, թե արդյոք բաժանորդագրության սկրիպտի բովանդակությունը փոխվել է:

### connect

Պահանջում է մուտքի թույլտվություն կայքի համար. տեսեք `GM_cookie` և `GM_xmlhttpRequest`: Բաժանորդագրության ռեժիմով տեղադրված սկրիպտների համար `connect`-ը փոխարինվում է բաժանորդագրության `connect`-ով:

### scriptUrl

Բաժանորդագրության համար պահանջվող սկրիպտի տեղադրման հղումները
