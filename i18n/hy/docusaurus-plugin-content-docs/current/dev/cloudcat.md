> Տրամադրվում են ամպում գործարկելու մի քանի եղանակներ; մանրամասների համար տեսեք [Գործարկման միջավայրերը](#running-environments): Բացի այդ, [CloudCat](https://github.com/scriptscat/cloudcat)-ը ֆոնային սկրիպտները ամպում գործարկելու ծառայություն է — FAAS հարթակ, որը դեռ մշակման փուլում է:

⚠ Խնդրում ենք նկատի ունենալ ⚠, երբ վերբեռնվում է ամպ, պլանավորված սկրիպտի արտահայտության մեջ `once`-ի իմաստը փոխվում է. գործարկման ժամանակ `once`-ից առաջ ժամանակը փոխարինվում է իր նվազագույն արժեքով:

Օրինակ՝

* `* * once * *` => `0 0 * * *`. գործարկվում է օրը մեկ անգամ, դառնում է ամեն օր 00:00-ին գործարկվող
* `* 1-23 once * *` => `0 1 * * *`. օրական մեկ անգամ գործարկվում է 1:00-ից 23:00 միջակայքում, դառնում է ամեն օր 01:00-ին գործարկվող
* `* 1,3,5 once * *` => `0 1 * * *`. օրական մեկ անգամ գործարկվում է 1:00-ին, 3:00-ին կամ 5:00-ին, դառնում է ամեն օր 01:00-ին գործարկվող
* `* */4 once * *` => `0 0 * * *`. օրական մեկ անգամ գործարկվում է յուրաքանչյուր 4 ժամը մեկ, դառնում է ամեն օր 00:00-ին գործարկվող
* `* 1-23/4 once * *` => `0 1 * * *`. օրական մեկ անգամ գործարկվում է յուրաքանչյուր 4 ժամը մեկ՝ 1:00-ից 23:00 միջակայքում, դառնում է ամեն օր 01:00-ին գործարկվող
* `* 10 once * *` => `0 10 * * *`. օրական մեկ անգամ գործարկվում է 10:00-ին, դառնում է ամեն օր ժամը 10-ի 00-րդ րոպեին գործարկվող
* `* * * once *` => `0 0 1 * *`. գործարկվում է ամիսը մեկ անգամ, դառնում է ամեն ամսվա 1-ին 00:00-ին գործարկվող

## CloudCat-ի լրացուցիչ նկարագրության արժեքներ

Հղման սկրիպտ. [Bilibili Auto Check-in](https://scriptcat.org/script-show-page/48)

### cloudCat

Այս ատրիբուտի հայտարարումը թույլ է տալիս սկրիպտը գործարկել `CloudCat`-ի միջոցով: Երբ սկրիպտն ունի այս տարբերակը, սկրիպտի ցուցակում հայտնվում է ամպային գործարկման կոճակ; դրա վրա սեղմելը թույլ է տալիս ընտրել գործարկման եղանակ — տեսեք [Գործարկման միջավայրերը](#running-environments):

### exportValue

Նկարագրում է ամպ արտահանվող Values-ները. թույլատրվում են բազմաթիվ հայտարարումներ:

```ts
// @exportValue key1,key2,key3
// @exportValue key4,key5,key6
```

### exportCookie

Նկարագրում է ամպ արտահանվող քուքիները. թույլատրվում են բազմաթիվ հայտարարումներ: Պարամետրերը նկարագրվում են `GM_cookie`-ի `CookieDetails`-ով, օրինակ՝

```ts
// Հետևյալը արտահանում է cookie1 անունով քուքին https://docs.scriptcat.org/docs/use/-ից
// @exportCookie url=https://docs.scriptcat.org/docs/use;name=cookie1

// Սա արտահանում է բոլոր քուքիները scriptcat.org դոմենի համար
// @exportCookie domain=scriptcat.org

// Բոլոր հասանելի պարամետրերը.
// @exportCookie domain=scriptcat.org;url=https://docs.scriptcat.org/docs/use;name=cookie1;path=/docs/use;secure=true;session=true
```

### Տեղական

Արտահանում է zip փաթեթ; այն թղթապանակում արխիվացնելուց հետո գործարկեք հետևյալ հրամանները՝ այն տեղական գործարկելու համար (պահանջվում է տեղական Node.js միջավայր).

```bash
npm i
node index.js
```


### Tencent Cloud

Նախ ստեղծեք Tencent Cloud բանալի [**Access Keys**](https://console.cloud.tencent.com/cam/capi) կայքում — եթե օգտագործում եք ենթահաշիվ, համոզվեք, որ նրան տրամադրել եք Cloud Function թույլտվություններ: Այնուհետև միացրեք ծառայությունը [**Function Service**](https://console.cloud.tencent.com/scf/list) կայքում, որը գալիս է ամսական որոշակի քանակությամբ անվճար օգտագործմամբ: Տարածաշրջանը լռելյայն Shanghai է. անհրաժեշտության դեպքում կարգավորեք այն: Վերբեռնել սեղմելուց հետո ավտոմատ կերպով ստեղծվում է պլանավորված գործարկիչ՝ հիմնված `@crontab`-ի վրա՝ ֆունկցիան ըստ ժամանակացույցի գործարկելու համար:
