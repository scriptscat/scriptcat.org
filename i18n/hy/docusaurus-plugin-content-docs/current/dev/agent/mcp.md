---
title: MCP ինտեգրացիա
---

MCP ([Model Context Protocol](https://modelcontextprotocol.io/))-ը թույլ է տալիս Agent-ին միանալ արտաքին MCP սերվերներին և ավտոմատ կերպով ստանալ հասանելիություն դրանց տրամադրած գործիքներին, ռեսուրսներին և պրոմպտ ձևանմուշներին:

> Ի տարբերություն Agent-ի այլ ենթահամակարգերի, MCP սերվերները ներկայումս կարող են **կարգավորվել միայն օգտագործողի կողմից կառավարման էջում** — չկա `CAT.agent.mcp` կառավարման API սկրիպտների համար: Այն ամենը, ինչ սկրիպտը կարող է դիտարկել, այն է, որ այս սերվերների գործիքները զրույցների ընթացքում ավտոմատ կերպով կանչվում են:

## MCP սերվերի կարգավորում

Ավելացրեք մեկը կառավարման էջում → **Agent → MCP**՝

| Դաշտ | Նկարագրություն |
|------|------|
| Անուն | Սերվերի ցուցադրվող անունը |
| URL | Streamable HTTP վերջնակետ (JSON-RPC 2.0 POST-ի միջոցով) |
| API Բանալի | Կամընտիր, նույնականացման համար |
| Կաստոմ վերնագրեր | Կամընտիր |
| Միացված | Արդյոք սերվերն ակտիվ է |

ScriptCat-ի MCP հաճախորդը օգտագործում է **Streamable HTTP** տրանսպորտը և աջակցում է `2025-03-26` պրոտոկոլի տարբերակին:

MCP սերվերը կարող է տրամադրել երեք տեսակի կարողություն՝

| Կարողություն | Նկարագրություն |
|------|------|
| **Գործիքներ** | Ավտոմատ կերպով գրանցվում են որպես գործիքներ, որոնք Agent-ը կարող է կանչել |
| **Ռեսուրսներ** | Ընթեռնելի ռեսուրսներ (տեքստ/երկուական) |
| **Պրոմպտներ** | Պրոմպտ ձևանմուշներ, պարամետրերի աջակցությամբ |

## Օգտագործումը զրույցում

Միացված MCP սերվերների գործիքները ավտոմատ կերպով հայտնվում են Agent զրույցներին հասանելի գործիքների ցուցակում՝ անվանված `mcp_{մաքրված սերվերի անուն}_{toolName}` նախշով — AI-ն որոշում է, թե արդյոք կանչել դրանք՝ ելնելով օգտագործողի մտադրությունից: Սա աշխատում է այնպես, ինչպես [Skills](../skill-install)-ը բեռնվում է ավտոմատ կերպով. սկրիպտ մշակողները սովորաբար կարիք չունեն անհանգստանալու հիմքում ընկած մանրամասների մասին:

Ստուգելու համար, թե արդյոք կոնկրետ MCP գործիքը հասանելի է, պարզապես ուղղակիորեն հարցրեք AI-ին զրույցում, կամ ստուգեք հայտնաբերված գործիքների ցուցակը այդ սերվերի մանրամասներում կառավարման էջում:
