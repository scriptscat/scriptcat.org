title: Ներկառուցված գործիքների ռեֆերենս
---

Agent-ը գալիս է ներկառուցված գործիքների հավաքածուով, որոնք AI-ն ավտոմատ կերպով կանչում է զրույցների ընթացքում: Այս գործիքները հասանելի են լռելյայն՝ մշտական զրույցներում. սկրիպտ մշակողները սովորաբար կարիք չունեն դրանք ուղղակիորեն կանչելու — AI-ն ընտրում է ճիշտ գործիքը՝ ելնելով օգտագործողի մտադրությունից:

Հասկանալը, թե ինչ կարող են անել այս գործիքները, օգնում է ձեզ ավելի լավ համակարգային պրոմպտներ և կաստոմ գործիքներ գրել:

## Վեբ տվյալների ֆեչինգ

### web_fetch

Ֆեչում է URL-ի բովանդակությունը՝ HTML-ից-տեքստ արդյունահանման և LLM ամփոփման աջակցությամբ:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `url` | `string` | Այո | Թիրախային URL (միայն http/https) |
| `prompt` | `string` | Ոչ | Ամփոփման պրոմպտ (տրամադրելիս՝ բովանդակությունը թորելու համար օգտագործվում է LLM) |
| `max_length` | `number` | Ոչ | Բովանդակության առավելագույն նիշեր |

**Վարքագծի մանրամասներ՝**
- 30 վայրկյան հարցման թայմաութ
- HTML բովանդակությունը ավտոմատ կերպով արդյունահանում է հիմնական մարմնի տեքստը (հեռացնում է նավիգացիան, կողային տողերը և այլն)
- JSON պատասխանները վերլուծվում են ավտոմատ կերպով
- Սովորական տեքստը վերադարձվում է ինչպես կա
- Երբ տրամադրվում է `prompt`, ֆեչված բովանդակությունը ուղարկվում է LLM-ին՝ ամփոփման համար

**Վերադարձի արժեքը՝**
```json
{
  "url": "https://example.com",
  "content_type": "text/html",
  "content": "Extracted body content...",
  "truncated": false,
  "final_url": "https://example.com/redirected"
}
```

### web_search

Հարցում է կատարում որոնման համակարգին և վերադարձնում կառուցվածքային որոնման արդյունքներ:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `query` | `string` | Այո | Որոնման հիմնաբառեր |
| `max_results` | `number` | Ոչ | Արդյունքների առավելագույն քանակ (լռելյայն 5, սահման 10) |

**Աջակցվող որոնման համակարգեր՝**

| Համակարգ | Նկարագրություն | Կոնֆիգուրացիա պահանջվում է |
|------|------|---------|
| DuckDuckGo | Լռելյայն համակարգ | Ոչ մեկը |
| Bing | Microsoft Bing Search | API բանալի պահանջվում է |
| Baidu | Baidu Search | API բանալի չի պահանջվում |
| Google Custom Search | Google Custom Search | API բանալի + CSE ID պահանջվում է |

Որոնման համակարգերը կոնֆիգուրվում են կառավարման էջում → Agent → Կարգավորումներ:

**Վերադարձի արժեքը՝**
```json
[
  {
    "title": "Search result title",
    "url": "https://example.com/result",
    "snippet": "Result summary text..."
  }
]
```

### get_tab_content

Կարդում է նշված ներդիրի ցուցադրված էջի բովանդակությունը՝ վերածված կառուցվածքային Markdown-ի՝ CSS սելեկտորներով նշված:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `tab_id` | `number` | Այո | Ներդիրի ID |
| `selector` | `string` | Ոչ | CSS սելեկտոր. արդյունահանել միայն համընկնող մասը |
| `prompt` | `string` | Ոչ | ամփոփման պրոմպտ |
| `max_length` | `number` | Ոչ | բովանդակության առավելագույն նիշեր |

Տարբերությունը `web_fetch`-ից. `get_tab_content`-ը կարդում է էջը **ինչպես արդեն ցուցադրված է զննարկչի կողմից** (ներառյալ դինամիկ JS բովանդակությունը), մինչդեռ `web_fetch`-ը կատարում է նոր HTTP հարցում:

**Վերադարձի արժեքը՝**
```json
{
  "tab_id": 123,
  "url": "https://example.com",
  "title": "Page title",
  "content": "Structured content...",
  "truncated": false,
  "used_selector": "main"
}
```

## Ներդիրների կառավարում

### list_tabs

Հարցում է կատարում բաց ներդիրների վերաբերյալ՝ մի քանի զտման պայմանների աջակցությամբ:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `url_pattern` | `string` | Ոչ | URL ռեգեքս համընկնում |
| `title_pattern` | `string` | Ոչ | Վերնագրի ռեգեքս համընկնում |
| `active` | `boolean` | Ոչ | Վերադարձնել միայն ակտիվ ներդիրը |
| `window_id` | `number` | Ոչ | նշված պատուհան |
| `audible` | `boolean` | Ոչ | Վերադարձնել միայն ներկայումս աուդիո նվագարկող ներդիրները |

### open_tab

Բացում է նոր ներդիր կամ նավիգացիա կատարում գոյություն ունեցողի մեջ:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `url` | `string` | Այո | Թիրախային URL |
| `tab_id` | `number` | Ոչ | Գոյություն ունեցող ներդիրի ID (տրամադրելիս՝ այդ ներդիրը նավիգացվում է. հակառակ դեպքում բացվում է նոր ներդիր) |
| `active` | `boolean` | Ոչ | Արդյոք ակտիվացնել այն (լռելյայն `true`) |
| `window_id` | `number` | Ոչ | նշված պատուհան |
| `wait_until_loaded` | `boolean` | Ոչ | Արդյոք սպասել էջի բեռնման ավարտին (լռելյայն `true`) |

### close_tab

Փակում է ներդիրը:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `tab_id` | `number` | Այո | Ներդիրի ID |

### activate_tab

Ակտիվացնում է ներդիրը և ֆոկուսավորում այն պարունակող պատուհանը:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `tab_id` | `number` | Այո | Ներդիրի ID |

## Ֆայլային համակարգ (OPFS)

### opfs_write

Գրում է ֆայլ աշխատանքային տարածքում:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `path` | `string` | Այո | ֆայլի ուղի |
| `content` | `string` | Այո | Ֆայլի բովանդակություն (data URL երկուական աջակցվում է) |

### opfs_read

Կարդում է ֆայլ աշխատանքային տարածքից: Լռելյայն ֆայլի տիպը հայտնաբերվում է ավտոմատ կերպով. տեքստային ֆայլերը վերադարձնում են իրենց բովանդակությունը, երկուական ֆայլերը՝ blob URL:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `path` | `string` | Այո | ֆայլի ուղի |
| `mode` | `string` | Ոչ | `"text"` / `"blob"` / `"auto"` (լռելյայն) — պարտադրում է հատուկ վերադարձի ռեժիմ |
| `offset` | `number` | Ոչ | Սկզբնական տողի համարը (1-հիմքով), միայն տեքստային ռեժիմ |
| `limit` | `number` | Ոչ | Կարդալու տողերի քանակ, միայն տեքստային ռեժիմ (էջավորումը պարտադիր է, երբ տեքստը գերազանցում է 200 տողը) |

### opfs_list

Թվարկում է դիրեկտորիայի բովանդակությունը:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `path` | `string` | Ոչ | Դիրեկտորիայի ուղի (լռելյայն արմատային դիրեկտորիա) |

### opfs_delete

Ջնջում է ֆայլ կամ դիրեկտորիա:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `path` | `string` | Այո | Ֆայլի/դիրեկտորիայի ուղի |

## Օգտագործողի հետ փոխազդեցություն

### ask_user

Հարց է տալիս օգտագործողին՝ աջակցելով կամ ազատ ձևի մուտքագրմանը, կամ կառուցվածքային ընտրությանը:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `question` | `string` | Այո | Հարցը |
| `options` | `string[]` | Ոչ | Ընտրությունների ցուցակ (տրամադրելիս՝ սա դառնում է բազմակի ընտրության հարց) |
| `multiple` | `boolean` | Ոչ | Արդյոք թույլատրվում են բազմակի ընտրություններ (լռելյայն `false`) |

**Թայմաութ.** 5 րոպե առանց պատասխանի վերադարձնում է `{ answer: null, reason: "timeout" }`:

**Վերադարձի արժեքը՝**
```json
{ "answer": "The user's answer text" }
```

### execute_script

Կատարում է JavaScript կոդ էջում կամ սանդբոքսում:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `code` | `string` | Այո | JavaScript կոդ |
| `target` | `string` | Այո | `"page"` կամ `"sandbox"` |
| `tab_id` | `number` | Ոչ | Որ ներդիրը թիրախավորել, երբ `target`-ը `page` է (լռելյայն ընթացիկ ակտիվ ներդիր). անտեսվում է սանդբոքսի համար |

**Կատարման միջավայրի համեմատություն՝**

| Միջավայր | DOM | Էջի JS | Ընդլայնման blob URL | Լավագույնը |
|------|-----|---------|---------------|---------|
| `target: "page"` (միշտ MAIN world) | այո | այո | ոչ | DOM կարդալը/փոփոխելը, էջի ֆունկցիաների կանչը, էջի փոփոխականների ընթերցումը |
| `target: "sandbox"` | ոչ | ոչ | ոչ | Մաքուր հաշվարկներ |

> `page` ռեժիմը միշտ գործարկվում է էջի MAIN world-ում՝ կիսելով `window`-ը էջի հետ — ուստի այն չի կարող մուտք գործել ընդլայնման սեփական blob URL-ները (օր.՝ այն հասցեն, որը `opfs_read`-ը վերադարձնում է blob ռեժիմում): Blob URL-ով աշխատելու անհրաժեշտության դեպքում փոխարենը օգտագործեք SkillScript:

## Ենթա-գործակալներ

### agent

Գործարկում է անկախ ենթա-գործակալ՝ բարդ ենթա-առաջադրանքը լուծելու համար:

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |
|------|------|------|------|
| `prompt` | `string` | Այո | Ենթա-առաջադրանքի նկարագրություն |
| `description` | `string` | Ոչ | Կարճ պիտակ (մի քանի բառ, UI ցուցադրման համար) |
| `type` | `string` | Ոչ | Ենթա-գործակալի տիպ (տես ստորև), լռելյայն `"general"` |
| `tab_id` | `number` | Ոչ | Ներդիրի ID՝ ենթա-գործակալին փոխանցելու համար. ենթա-գործակալը կգործի այդ ներդիրում |

**Ենթա-գործակալի տիպեր՝**

| type | Նկարագրություն | Հասանելի գործիքներ |
|------|------|---------|
| `researcher` | Տեղեկատվության որոնում (միայն կարդալու) | web_search, web_fetch, էջի բովանդակության ընթերցում |
| `page_operator` | Զննարկչի ավտոմատացում | Ներդիրների կառավարում, DOM մանիպուլյացիա, էջի փոխազդեցություն |
| `general` | Ընդհանուր նշանակության (լռելյայն) | Բոլոր գործիքները |

**Բնութագրեր.**
- Ենթա-գործակալն ունի իր սեփական անկախ զրույցի կոնտեքստը
- Այն **չի կարող** օգտագործել `ask_user` կամ `agent` (ռեկուրսիան կանխելու համար)
- Ենթա-գործակալի իրադարձությունները փոխանցվում են ծնող զրույցին `sub_agent_event`-ի միջոցով

## Առաջադրանքների կառավարում

### create_task

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |

| `subject` | `string` | Այո | Առաջադրանքի վերնագիր |
| `description` | `string` | Ոչ | Մանրամասն նկարագրություն |

### update_task

| Պարամետր | Տիպ | Պարտադիր | Նկարագրություն |

| `task_id` | `string` | Այո | Առաջադրանքի ID |

| `subject` | `string` | Ոչ | Նոր վերնագիր |
