# 🎉 Bienvenue sur ScriptCat

Félicitations, vous avez installé avec succès l'extension de navigateur ScriptCat ! ScriptCat est un puissant gestionnaire de scripts utilisateur, compatible avec les scripts Tampermonkey, et offrant bien plus de fonctionnalités.

<GithubStar variant="bar" scene="install" />

## Rappel de sécurité

⚠️ **Les scripts utilisateur ont des capacités étendues — la sécurité est essentielle !**

Les scripts utilisateur peuvent accéder au contenu des pages web et le modifier ; **la sécurité est donc primordiale**. Pour protéger vos informations personnelles et la sécurité de votre appareil, veillez à :

- ✅ **N'installer des scripts que depuis des sites de confiance**
- ✅ **Consulter attentivement les notes et avis des utilisateurs**
- ✅ **Comprendre les fonctionnalités et les permissions requises par un script**
- ❌ **Éviter de télécharger des scripts depuis des sources inconnues ou suspectes**
- ❌ **Ne pas installer de fichiers de script d'origine incertaine**

### Sources de scripts recommandées et fiables

Nous vous recommandons d'obtenir vos scripts depuis les sites suivants :

- **[Site de scripts ScriptCat](https://scriptcat.org/)** — le site de scripts officiellement maintenu par ScriptCat
- **[GreasyFork](https://greasyfork.org/)** — le plus grand site de scripts utilisateur au monde
- **[Userscript.Zone](https://www.userscript.zone/)** — une sélection de scripts de haute qualité

## Prochaines étapes

### Accéder à l'interface de gestion des scripts

Cliquez sur l'icône ScriptCat dans la barre d'outils du navigateur, puis sur le bouton « ⚙️ » en haut à droite pour accéder à l'interface de gestion.

### Obtenir votre premier script

Dans la fenêtre qui s'ouvre, cliquez sur le menu « ⋮ » en haut à droite, puis sélectionnez « Obtenir des scripts » pour accéder au site officiel de scripts, où vous pourrez rechercher et installer des scripts.

### Découvrir les fonctionnalités

- 📊 **Gestion des scripts** : activer/désactiver des scripts, consulter leur état d'exécution
- 🔧 **Paramètres personnalisés** : configurer les paramètres et règles d'exécution des scripts
- 📝 **Édition de scripts** : créer et modifier vos propres scripts
- 🔄 **Synchronisation des données** : synchroniser votre configuration de scripts entre plusieurs appareils

## Conseils d'utilisation

1. **Commencez petit** : nous recommandons aux débutants de commencer par des scripts simples et bien notés
2. **Vérifiez régulièrement** : vérifiez et mettez à jour régulièrement vos scripts installés
3. **Sauvegardez votre configuration** : il est conseillé de sauvegarder les configurations de scripts importantes
4. **Signalez les problèmes** : en cas de problème, vous pouvez nous contacter via [GitHub](https://github.com/scriptscat/scriptcat) ou la communauté officielle

## Avis de non-responsabilité

En utilisant ScriptCat, vous devez comprendre que :

- ScriptCat fournit un environnement d'exécution pour les scripts, mais n'est pas responsable de la sécurité, des fonctionnalités ou du contenu des scripts tiers
- Vous assumez seul les risques liés à l'utilisation de scripts tiers
- Il est recommandé de lire attentivement le code source et la description d'un script afin d'en comprendre le fonctionnement

Pour les conditions détaillées, consultez : [l'avis de non-responsabilité complet](/docs/use/policy/disclaimer/)
