- [x] Google Drive
- [x] Dropbox

## Synchronisation

Lorsqu'un script est mis à jour, il est immédiatement synchronisé vers le cloud. En revanche, lorsque les données cloud changent, l'analyse et la synchronisation vers le local prennent un certain temps. Veuillez en tenir compte lorsque plusieurs appareils partagent le même stockage cloud.

Cliquer sur Enregistrer dans la section de synchronisation des scripts déclenche immédiatement une synchronisation complète.
