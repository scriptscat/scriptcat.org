## Étapes d'installation depuis les principaux sites

### Communauté ScriptCat

[Communauté ScriptCat](https://scriptcat.org/search) — le site officiel de ScriptCat.

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/) est un site récent permettant de rechercher des scripts utilisateur en saisissant une URL ou un domaine.

- **Grand nombre de scripts disponibles**
- **Facile de trouver le bon script utilisateur**
- **N'affiche que les scripts issus de pages vérifiées ou disposant au moins d'une fonction de commentaires**

### GreasyFork

[GreasyFork](https://greasyfork.org/) est une plateforme largement utilisée pour le partage et l'hébergement de scripts utilisateur, permettant aux développeurs de publier des scripts et aux utilisateurs de les installer. Créé par Jason Barnabe, ce site met l'accent sur la sécurité et la transparence open source, et regroupe une large collection de scripts pour étendre les fonctionnalités des sites web ou améliorer l'expérience de navigation.

Jason Barnabe est également l'auteur original de l'extension de navigateur Stylish. Cependant, [Stylish](https://userstyles.org/) a changé de propriétaire en 2016 et est désormais géré par une autre société, sans lien direct avec Jason Barnabe depuis.

- **Grand nombre de scripts disponibles**
- **Fonction de synchronisation des scripts depuis GitHub**
- **Développement open source très actif**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/) a été créé après GreasyFork, par Sizzle McTwizzle. Il dispose lui aussi d'une large collection de scripts.

- **Fonction de synchronisation et de fork de scripts depuis GitHub**
- **Développement open source très actif**

### GitHub / Gists

Vous pouvez également rechercher des scripts directement sur GitHub et dans les Gists.

## Installer un script manuellement

1. Cliquez sur l'icône de l'extension ScriptCat
2. Cliquez sur le bouton « roue crantée » de l'interface pour accéder au panneau de gestion de ScriptCat
3. Cliquez sur le bouton « Nouveau script » en haut à droite (un script normal suffit généralement)
4. Collez le code du script dans la page qui s'affiche
5. Appuyez sur `Ctrl + S` pour enregistrer les modifications
6. Retournez au panneau de gestion : votre nouveau script y apparaît
