---
title: Installation de script
---

Cette page sert d'étape intermédiaire pour installer un nouveau script utilisateur dans `ScriptCat`.

Une fois l'installation terminée, cette page devrait se fermer ou être redirigée automatiquement.

Cette page n'est pas destinée à être consultée directement ; si nécessaire, rendez-vous sur [Installer un script](/docs/use/script_installation/).
