Cette extension prend en charge trois types de scripts :

- Scripts de premier plan
- [Scripts en arrière-plan](./background.md)
- [Scripts planifiés](./background.md#scripts-planifiés-crontab)

Les scripts de premier plan sont les scripts Tampermonkey classiques ; les scripts en arrière-plan et les scripts planifiés sont des fonctionnalités propres à l'extension ScriptCat — voir la documentation correspondante pour plus de détails.

Ce document vous permet d'apprendre à utiliser l'[API de Tampermonkey](./api.md) et les [scripts en arrière-plan de ScriptCat](./background.md). Nous maintenons également un site de documentation dédié au [développement de scripts Tampermonkey](https://learn.scriptcat.org/), riche en ressources d'apprentissage — n'hésitez pas à nous rejoindre.

Si vous trouvez des lacunes dans la documentation, faites-le-nous savoir sur [Github](https://github.com/scriptscat/scriptcat.org), ou aidez-nous à l'améliorer via une PR.
