> ক্লাউডে চালানোর জন্য বিভিন্ন পদ্ধতি দেওয়া হয়েছে; বিস্তারিত জানতে [চলমান পরিবেশ](#running-environments) দেখুন। উপরন্তু, [CloudCat](https://github.com/scriptscat/cloudcat) ক্লাউডে ব্যাকগ্রাউন্ড স্ক্রিপ্ট চালানোর একটি পরিষেবা — একটি FAAS প্ল্যাটফর্ম যা এখনও উন্নয়নাধীন।

⚠ অনুগ্রহ করে লক্ষ্য করুন ⚠, একবার ক্লাউডে আপলোড করা হলে, নির্ধারিত-স্ক্রিপ্ট এক্সপ্রেশনে `once`-এর অর্থ পরিবর্তিত হয়: চালানোর সময় `once`-এর আগের সময়টি তার ন্যূনতম মান দিয়ে প্রতিস্থাপিত হয়।

উদাহরণস্বরূপ:

* `* * once * *` => `0 0 * * *`: প্রতিদিন একবার চলে, প্রতিদিন 00:00-এ চলতে শুরু করে
* `* 1-23 once * *` => `0 1 * * *`: প্রতিদিন 1:00 এবং 23:00-এর মধ্যে একবার চলে, প্রতিদিন 01:00-এ চলতে শুরু করে
* `* 1,3,5 once * *` => `0 1 * * *`: প্রতিদিন 1:00, 3:00 বা 5:00-এ একবার চলে, প্রতিদিন 01:00-এ চলতে শুরু করে
* `* */4 once * *` => `0 0 * * *`: প্রতিদিন প্রতি ৪ ঘণ্টায় একবার চলে, প্রতিদিন 00:00-এ চলতে শুরু করে
* `* 1-23/4 once * *` => `0 1 * * *`: প্রতিদিন 1:00 এবং 23:00-এর মধ্যে প্রতি ৪ ঘণ্টায় একবার চলে, প্রতিদিন 01:00-এ চলতে শুরু করে
* `* 10 once * *` => `0 10 * * *`: প্রতিদিন 10:00-এ একবার চলে, প্রতিদিন ঘণ্টা 10-এর মিনিট 00-এ চলতে শুরু করে
* `* * * once *` => `0 0 1 * *`: প্রতি মাসে একবার চলে, প্রতি মাসের ১ তারিখে 00:00-এ চলতে শুরু করে

## অতিরিক্ত CloudCat বর্ণনার মান

একটি রেফারেন্স স্ক্রিপ্ট: [Bilibili অটো চেক-ইন](https://scriptcat.org/script-show-page/48)

### cloudCat

এই বৈশিষ্ট্যটি ঘোষণা করলে স্ক্রিপ্টটি `CloudCat`-এর মাধ্যমে চলতে পারে। একবার স্ক্রিপ্টে এই বিকল্প থাকলে, স্ক্রিপ্ট তালিকায় একটি ক্লাউড-এক্সিকিউশন বাটন দেখা যায়; এটিতে ক্লিক করলে আপনি একটি এক্সিকিউশন পদ্ধতি বেছে নিতে পারেন — [চলমান পরিবেশ](#running-environments) দেখুন।

ডিফল্ট cloudCat সার্ভার ঠিকানা


### exportValue

ক্লাউডে এক্সপোর্ট করার মান বর্ণনা করে; একাধিক ঘোষণা অনুমোদিত।

```ts
// @exportValue key1,key2,key3
// @exportValue key4,key5,key6
```

### exportCookie

ক্লাউডে এক্সপোর্ট করার কুকিগুলি বর্ণনা করে; একাধিক ঘোষণা অনুমোদিত। প্যারামিটারগুলি `GM_cookie`-এর `CookieDetails` ব্যবহার করে বর্ণনা করা হয়, উদাহরণস্বরূপ:

```ts
// নিম্নলিখিতটি https://docs.scriptcat.org/docs/use/ থেকে cookie1 নামের কুকিটি এক্সপোর্ট করে
// @exportCookie url=https://docs.scriptcat.org/docs/use;name=cookie1

// এটি scriptcat.org ডোমেইনের জন্য সমস্ত কুকি এক্সপোর্ট করে
// @exportCookie domain=scriptcat.org

// সমস্ত উপলব্ধ প্যারামিটার:
// @exportCookie domain=scriptcat.org;url=https://docs.scriptcat.org/docs/use;name=cookie1;path=/docs/use;secure=true;session=true
```

## চলমান পরিবেশ {#running-environments}

### লোকাল

একটি zip প্যাকেজ এক্সপোর্ট করে; একটি ফোল্ডারে এক্সট্র্যাক্ট করার পরে, এটি লোকালি চালানোর জন্য নিম্নলিখিত কমান্ডগুলি চালান (একটি লোকাল Node.js পরিবেশ প্রয়োজন):

```bash
npm i
node index.js
```


### Tencent Cloud

প্রথমে [**অ্যাক্সেস কী**](https://console.cloud.tencent.com/cam/capi)-এ একটি Tencent Cloud কী তৈরি করুন — যদি একটি সাব-অ্যাকাউন্ট ব্যবহার করেন, নিশ্চিত করুন এটিকে Cloud Function অনুমতি দেওয়া হয়েছে। তারপর [**ফাংশন সার্ভিস**](https://console.cloud.tencent.com/scf/list)-এ পরিষেবাটি সক্রিয় করুন, যা প্রতি মাসে একটি নির্দিষ্ট পরিমাণ বিনামূল্যে ব্যবহারের সাথে আসে। অঞ্চলটি ডিফল্টভাবে সাংহাই; প্রয়োজনে এটি সামঞ্জস্য করুন। আপলোডে ক্লিক করার পরে, `@crontab`-এর উপর ভিত্তি করে একটি নির্ধারিত ট্রিগার স্বয়ংক্রিয়ভাবে তৈরি হয় ফাংশনটিকে সময়সূচীতে চালানোর জন্য।
