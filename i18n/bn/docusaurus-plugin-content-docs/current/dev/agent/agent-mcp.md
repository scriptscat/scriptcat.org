title: MCP ইন্টিগ্রেশন
---

MCP ([Model Context Protocol](https://modelcontextprotocol.io/)) Agent-কে বাহ্যিক MCP সার্ভারের সাথে সংযোগ করতে এবং তাদের প্রদান করা টুল, রিসোর্স এবং prompt টেমপ্লেটগুলিতে স্বয়ংক্রিয়ভাবে অ্যাক্সেস পেতে দেয়।

> Agent-এর অন্যান্য সাবসিস্টেমের বিপরীতে, MCP সার্ভারগুলি বর্তমানে **শুধুমাত্র ব্যবহারকারী দ্বারা ম্যানেজমেন্ট পেজে কনফিগার করা যায়** — স্ক্রিপ্টগুলির জন্য কোনো `CAT.agent.mcp` ম্যানেজমেন্ট API নেই। একটি স্ক্রিপ্ট কেবল লক্ষ্য করতে পারে যে এই সার্ভারগুলির টুলগুলি কথোপকথনের সময় স্বয়ংক্রিয়ভাবে কল হয়।

## একটি MCP সার্ভার কনফিগার করা

ম্যানেজমেন্ট পেজে একটি যোগ করুন → **Agent → MCP**:

| ফিল্ড | বর্ণনা |
|------|------|
| নাম | সার্ভারের জন্য প্রদর্শনের নাম |
| URL | Streamable HTTP এন্ডপয়েন্ট (POST-এর উপর JSON-RPC 2.0) |
| API কী | ঐচ্ছিক, প্রমাণীকরণের জন্য |
| কাস্টম হেডার | ঐচ্ছিক |
| সক্রিয় | সার্ভার সক্রিয় কিনা |

ScriptCat-এর MCP ক্লায়েন্ট **Streamable HTTP** ট্রান্সপোর্ট ব্যবহার করে এবং প্রোটোকল সংস্করণ `2025-03-26` সমর্থন করে।

একটি MCP সার্ভার তিন ধরনের ক্ষমতা প্রদান করতে পারে:

| ক্ষমতা | বর্ণনা |
|------|------|
| **টুল** | স্বয়ংক্রিয়ভাবে Agent-এর কলযোগ্য টুল হিসাবে নিবন্ধিত হয় |
| **রিসোর্স** | পঠনযোগ্য রিসোর্স (টেক্সট/বাইনারি) |
| **Prompts** | prompt টেমপ্লেট, প্যারামিটার সমর্থন সহ |

## কথোপকথনে এটি ব্যবহার

সক্রিয় MCP সার্ভারের টুলগুলি স্বয়ংক্রিয়ভাবে Agent কথোপকথনের জন্য উপলব্ধ টুল তালিকায় দেখা যায়, `mcp_{স্যানিটাইজড সার্ভার নাম}_{toolName}` প্যাটার্ন ব্যবহার করে নামকরণ করা হয় — AI ব্যবহারকারীর অভিপ্রায়ের ভিত্তিতে সেগুলি কল করবে কিনা তা সিদ্ধান্ত নেয়। এটি কীভাবে [Skill](../agent-skill-install) স্বয়ংক্রিয়ভাবে লোড হয় তার মতোই কাজ করে; স্ক্রিপ্ট ডেভেলপারদের সাধারণত অন্তর্নিহিত বিবরণ নিয়ে চিন্তা করতে হয় না।

একটি নির্দিষ্ট MCP টুল উপলব্ধ কিনা তা পরীক্ষা করতে, কেবল কথোপকথনে সরাসরি AI-কে জিজ্ঞাসা করুন, অথবা ম্যানেজমেন্ট পেজে সেই সার্ভারের বিবরণে আবিষ্কৃত টুল তালিকা পরীক্ষা করুন।
