---
title: সাবস্ক্রিপশন মোড
---

ফাইলটি অবশ্যই `UserScript`-এর পরিবর্তে `UserSubscribe` দিয়ে শুরু করতে হবে। ইনস্টলেশন লিংকটি অবশ্যই `user.sub.js` এক্সটেনশন ব্যবহার করবে এবং একটি `https` লিংক হতে হবে।

একটি সাবস্ক্রিপশন স্ক্রিপ্ট শুধুমাত্র ইনস্টল করার সময় ব্যবহারকারীকে সাবস্ক্রিপশন নিশ্চিত করতে ইনস্টলেশন ডায়ালগ দেখায়; পরবর্তী আপডেটগুলি নীরব এবং আপডেট ডায়ালগ শুধুমাত্র `connect` অনুমতি পরিবর্তন হলে আবার দেখানো হয়।

একটি একক সাবস্ক্রিপশন স্ক্রিপ্ট একাধিক স্ক্রিপ্টের ইনস্টলেশন লিংক বর্ণনা করতে পারে। সাবস্ক্রিপশন মোডের মাধ্যমে ইনস্টল করা স্ক্রিপ্টগুলি নীরবে ইনস্টল করা হয়, নিশ্চিতকরণ ডায়ালগ ছাড়াই, এবং ইনস্টল করা স্ক্রিপ্টগুলি এখনও স্ক্রিপ্ট তালিকায় দেখা যায় — তবে তাদের `connect` অনুমতি সাবস্ক্রিপশনে ঘোষিত `connect` ব্যবহার করে, স্ক্রিপ্টের নিজস্ব `connect` অনুমতি নয়।

```js
// ==UserSubscribe==
// @name         xxx
// @description  xxx স্ক্রিপ্ট সিরিজে সাবস্ক্রাইব করুন
// @version      0.1.0
// @author       আপনি
// @connect      www.baidu.com
// @scriptUrl    https://script.tampermonkey.net.cn/48.user.js
// @scriptUrl    https://script.tampermonkey.net.cn/49.user.js
// ==/UserSubscribe==
```

## সাবস্ক্রিপশন আপডেট এবং স্ক্রিপ্ট আপডেট

ব্যবহারকারীর কনফিগার করা `আপডেট ইন্টারভাল` অনুসারে, ScriptCat পর্যায়ক্রমে আপডেটের জন্য সাবস্ক্রিপশন লিংকটি পরীক্ষা করে; এটি কার্যকর হওয়ার জন্য `version` কনফিগার করতে হবে।

প্রতিটি সাবস্ক্রিপশন আপডেট বা পরিবর্তন বর্তমানে ইনস্টল করা স্ক্রিপ্টগুলির সাথে স্ক্রিপ্ট লিংকগুলির তুলনা করে: নতুন সাবস্ক্রিপশনে আর নেই এমন স্ক্রিপ্টগুলি সরানো হয় এবং নতুন যোগ করা স্ক্রিপ্টগুলি নীরবে ইনস্টল করা হয়। স্ক্রিপ্ট আপডেটগুলি স্ক্রিপ্টের নিজস্ব `version` অনুসরণ করে, একটি সাধারণভাবে ইনস্টল করা স্ক্রিপ্টের মতো একই আপডেট লজিক ব্যবহার করে।

## নীরব ইনস্টল এবং আপডেট

সাবস্ক্রাইব করা স্ক্রিপ্টগুলি নীরবে ইনস্টল ও আপডেট হয় — একটি সাবস্ক্রিপশন থেকে একটি স্ক্রিপ্ট যোগ, অপসারণ বা আপডেট করলে শুধুমাত্র একটি বিজ্ঞপ্তি দেখায়, আবার ব্যবহারকারীর নিশ্চিতকরণের প্রয়োজন হয় না। এই নীরব-আপডেট ব্যবস্থার কারণে, অনুগ্রহ করে শুধুমাত্র এমন উৎসে সাবস্ক্রাইব করুন যা আপনি বিশ্বাস করেন।


## metadata

সাবস্ক্রিপশন স্ক্রিপ্টের মধ্যে কিছু মেটাডেটা ফিল্ডের অর্থ পরিবর্তিত হয়।

### name

সাবস্ক্রিপশন নাম (সাবস্ক্রিপশন তালিকায় সরাসরি সম্পাদনাও করা যায়)

### description

সাবস্ক্রিপশন বর্ণনা, যা বর্ণনা করে সাবস্ক্রিপশন কীসের জন্য

### version

সাবস্ক্রিপশন সংস্করণ। বাদ দিলে, সাবস্ক্রিপশন স্ক্রিপ্টের বিষয়বস্তু পরিবর্তিত হয়েছে কিনা তার দ্বারা আপডেট ট্রিগার হয়।

### connect

একটি সাইটের জন্য অ্যাক্সেস অনুমতি অনুরোধ করে; `GM_cookie` এবং `GM_xmlhttpRequest` দেখুন। সাবস্ক্রিপশন মোডের মাধ্যমে ইনস্টল করা স্ক্রিপ্টগুলির জন্য, `connect` সাবস্ক্রিপশনের `connect` দ্বারা ওভাররাইড করা হয়।

### scriptUrl

সাবস্ক্রিপশনের জন্য প্রয়োজনীয় স্ক্রিপ্ট ইনস্টলেশন লিংক
