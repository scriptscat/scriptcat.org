## Agent

ড্যাশবোর্ডে একটি নতুন Agent চ্যাট এন্ট্রি পয়েন্ট যোগ হয়েছে, যেখানে আপনি একটি AI মডেলের সাথে বহু-পালার কথোপকথন করতে পারেন; AI কাজ সম্পন্ন করতে স্বয়ংক্রিয়ভাবে অন্তর্নির্মিত টুলগুলো কল করে।

**মূল সক্ষমতা:**

- **মাল্টি-মডেল সমর্থন** — OpenAI-সামঞ্জস্যপূর্ণ এবং নেটিভ Anthropic ফরম্যাট, Prompt Caching সমর্থনসহ
- **১১টি অন্তর্নির্মিত টুল** — ওয়েব ফেচ/সার্চ, ট্যাব ব্যবস্থাপনা, OPFS ফাইল সিস্টেম, কোড এক্সিকিউশন, ব্যবহারকারীর ইন্টারঅ্যাকশন এবং আরও অনেক কিছু
- **Skill সিস্টেম** — প্রম্পট + টুল স্ক্রিপ্ট + রেফারেন্স সামগ্রীর প্যাকেজ যা Agent-এর ডোমেইন জ্ঞান বাড়ায়
- **MCP ইন্টিগ্রেশন** — বাহ্যিক টুল সার্ভারে সংযোগের জন্য [Model Context Protocol](https://modelcontextprotocol.io/) সমর্থন
- **DOM অটোমেশন** — পেজ নেভিগেশন, স্ক্রিনশট, ক্লিক, ফিল, স্ক্রল, স্ক্রিপ্ট এক্সিকিউশন এবং আরও অনেক কিছু
- **নির্ধারিত কাজ** — Cron এক্সপ্রেশন-ভিত্তিক কাজের সময়সূচি (ইন্টারনাল / ইভেন্ট মোড)
- **সাব-এজেন্ট** — জটিল সাব-টাস্ক পরিচালনার জন্য স্বাধীন সাব-এজেন্ট তৈরি করতে পারে
- **কনটেক্সট ব্যবস্থাপনা** — টোকেন ব্যবহার কমানোর জন্য অটো-কমপ্যাক্ট এবং Prompt Caching

**স্ক্রিপ্ট API (`CAT.agent.*`):**

ইউজার স্ক্রিপ্টগুলো `CAT.agent.*` নেমস্পেসের মাধ্যমে Agent সক্ষমতা কল করতে পারে, যার মধ্যে conversation, dom, skills, task, model, opfs এবং mcp API অন্তর্ভুক্ত। প্রতিটি API-এর জন্য সংশ্লিষ্ট অনুমতি `@grant` দিয়ে ঘোষণা করতে হয়।

**ড্যাশবোর্ডের ৬টি পৃষ্ঠা:** চ্যাট, মডেল কনফিগারেশন, Skill ব্যবস্থাপনা, নির্ধারিত কাজ, MCP সার্ভার এবং OPFS ব্রাউজার।

## `@unwrap` ট্যাগ সমর্থন

স্ক্রিপ্টকে স্যান্ডবক্স র্যাপার অতিক্রম করে সরাসরি পেজে ইনজেক্ট করতে দেয়।

## `window.onurlchange` ইভেন্ট

Navigation API ব্যবহার করে Tampermonkey-সামঞ্জস্যপূর্ণ URL পরিবর্তন ইভেন্ট শোনার বাস্তবায়ন করে।

## এডিটর উন্নতি

এডিট মেনু (খুঁজুন, প্রতিস্থাপন, আনডু ইত্যাদি) যোগ হয়েছে এবং বেশ কিছু কীবোর্ড শর্টকাট ও হিন্ট সমস্যা ঠিক হয়েছে।

## মাল্টি-প্ল্যাটফর্ম সার্চ ইঞ্জিন

স্ক্রিপ্ট আবিষ্কারে এখন বিভিন্ন সার্চ ইঞ্জিন প্ল্যাটফর্মের মধ্যে বেছে নেওয়া যায়।

## আরও আইকন প্রদানকারী

আরও স্ক্রিপ্ট আইকন সার্ভিস প্রদানকারী যোগ হয়েছে।
