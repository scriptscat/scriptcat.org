## Synchronisatie

Wanneer een script wordt bijgewerkt, wordt het onmiddellijk naar de cloud gesynchroniseerd. Wanneer cloudgegevens echter veranderen, kost het enige tijd om naar lokaal te scannen en te synchroniseren. Houd hier rekening mee wanneer meerdere apparaten dezelfde cloudopslag delen.

Klikken op Opslaan in het gedeelte script synchronisatie voert onmiddellijk een volledige synchronisatie uit.
