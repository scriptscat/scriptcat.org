v1.4 is een grote update voor ScriptCat en introduceert een volledig nieuw **Agent**-systeem waarmee gebruikers browseracties kunnen automatiseren, webgegevens kunnen extraheren, bestanden kunnen beheren en geplande taken kunnen uitvoeren via conversatie in natuurlijke taal.

## Agent

Er is een nieuw Agent-chatvenster toegevoegd aan het dashboard, waar u een gesprek met meerdere rondes kunt voeren met een AI-model; de AI roept automatisch ingebouwde tools aan om taken uit te voeren.

**Kerntaken:**

- **Ondersteuning voor meerdere modellen** — OpenAI-compatibele en native Anthropic-formaten, met ondersteuning voor Prompt Caching
- **11 ingebouwde tools** — web ophalen/zoeken, tabbladbeheer, het OPFS-bestandssysteem, code-uitvoering, gebruikersinteractie en meer
- **Skillsysteem** — pakketten van prompts + toolscripts + referentiemateriaal die de domeinkennis van de Agent vergroten
- **MCP-integratie** — ondersteunt het [Model Context Protocol](https://modelcontextprotocol.io/) om verbinding te maken met externe toolservers
- **DOM-automatisering** — paginanavigatie, schermafbeeldingen, klikken, invullen, scrollen, scriptuitvoering en meer
- **Geplande taken** — taakplanning op basis van Cron-expressies (Interne / Gebeurtenis-modus)
- **Sub-agents** — kunnen onafhankelijke sub-agents starten voor complexe deeltaken
- **Contextbeheer** — Auto-compact en Prompt Caching om tokenverbruik te verminderen

**Script-API (`CAT.agent.*`):**

Gebruikersscripts kunnen Agent-mogelijkheden aanroepen via de `CAT.agent.*`-naamruimte, waaronder de conversation-, dom-, skills-, task-, model-, opfs- en mcp-API's. Voor elke API moet de bijbehorende toestemming worden gedeclareerd met `@grant`.

**6 dashboardpagina's:** Chat, Modelconfiguratie, Skillbeheer, Geplande taken, MCP-servers en de OPFS-browser.

## Ondersteuning voor de `@unwrap`-tag

Laat een script rechtstreeks in de pagina injecteren, waarbij de sandbox-wrapper wordt omzeild.

## De `window.onurlchange`-gebeurtenis

Implementeert Tampermonkey-compatibele URL-wijzigingsgebeurtenisluisteraars met behulp van de Navigation API.

## Editorverbeteringen

Een bewerkingsmenu (zoeken, vervangen, ongedaan maken, enz.) toegevoegd en verschillende toetsenbord- en hintproblemen opgelost.

## Multi-platform zoekmachines

Bij het ontdekken van scripts kunt u nu kiezen tussen verschillende zoekmachines.

## Meer icoonproviders

Meer providers voor scripticonen toegevoegd.
