ScriptCat is een open-sourceproject dat door vrijwilligers wordt onderhouden, zonder steun van een bedrijf. Servers, domeinen en andere infrastructuur, samen met veel ontwikkel- en onderhoudstijd, worden allemaal ondersteund door de community. Elke bijdrage helpt ScriptCat verder te komen.

## Waar je sponsorgeld naartoe gaat

Sponsorinkomsten gaan voornamelijk naar:

- **Dekking van de operationele kosten** — servers, domeinen en andere dagelijkse infrastructuur.
- **Belonen van onderhouders & bijdragers** — zodat langdurige onderhouders, en iedereen die code, vertalingen en documentatie stuurt, de beloning krijgen die ze verdienen.
- **Bouwen van nieuwe functies** — meer tijd om de ervaring te verfijnen en nieuwe mogelijkheden te ontwikkelen.

## Hoe te sponsoren

Of je nu een individu of een bedrijf bent, en ongeacht de omvang, elke steun telt.

We verzamelen sponsoring via [OpenCollective](https://opencollective.com/scriptcat), met eenmalige of maandelijkse bijdragen; je naam verschijnt op de supporterslijst nadat je doneert.

Als je een **sponsorplaatsing** wilt — je logo en intro getoond in de README, op de website of in de documentatie — stuur dan een e-mail naar [codfrm@gmail.com](mailto:codfrm@gmail.com).

## Sponsorplaatsingen

Het logo en de beschrijving van een sponsor kunnen op de volgende plaatsen worden getoond, geregeld via e-mail:

| Plaatsing | Formaat |
| --- | --- |
| Bovenkant van de GitHub README | Grote banner |
| Sponsorgebied in GitHub README | Logo + intro van één regel |
| Sponsorpagina op de website (deze pagina) | Logo + intro |
| Documentatiepagina's op de website (bijv. changelog) | Logoweergave |
