ScriptCat مشروع مفتوح المصدر يديره متطوعون، دون شركة تدعمه. الخوادم والنطاقات والبنية التحتية الأخرى، إلى جانب قدر كبير من وقت التطوير والصيانة، كلها مدعومة بدعم المجتمع. كل مساهمة تساعد ScriptCat على المضي قدماً.

## أين تذهب تبرعاتك

تذهب إيرادات الدعم بشكل أساسي إلى:

- **تغطية تكاليف التشغيل** — الخوادم والنطاقات والبنية التحتية اليومية الأخرى.
- **مكافأة القائمين على الصيانة والمساهمين** — حتى يحصل القائمون على الصيانة على المدى الطويل، وكل من يرسل أكواداً وترجمات ووثائق، على المكافأة التي يستحقونها.
- **بناء ميزات جديدة** — مزيد من الوقت لتحسين التجربة وتطوير قدرات جديدة.

## كيفية الدعم

سواء كنت فرداً أو شركة، وبغض النظر عن الحجم، كل دعم مهما كان صغيراً له قيمته.

نجمع التبرعات عبر [OpenCollective](https://opencollective.com/scriptcat)، بمساهمات لمرة واحدة أو شهرية؛ سيظهر اسمك في قائمة الداعمين بعد التبرع.

إذا كنت ترغب في **ظهور دعاية** — عرض شعارك ومقدمتك في ملف README أو على الموقع أو في الوثائق — راسلنا على [codfrm@gmail.com](mailto:codfrm@gmail.com).

## أماكن عرض الداعمين

يمكن عرض شعار الداعم ووصفه في الأماكن التالية، ويتم الترتيب عبر البريد الإلكتروني:

| المكان | الصيغة |
| --- | --- |
| أعلى ملف README على GitHub | لافتة كبيرة |
| منطقة الداعمين في README على GitHub | شعار + سطر تعريف |
| صفحة الداعمين على الموقع (هذه الصفحة) | شعار + مقدمة |
| صفحات الوثائق على الموقع (مثل سجل التغييرات) | عرض الشعار |
