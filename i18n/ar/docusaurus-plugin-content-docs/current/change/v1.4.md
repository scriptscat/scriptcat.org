v1.4 هو تحديث رئيسي لـ ScriptCat، يقدم نظام **Agent** الجديد كلياً الذي يتيح للمستخدمين أتمتة إجراءات المتصفح، واستخراج بيانات الويب، وإدارة الملفات، وتشغيل المهام المجدولة من خلال المحادثة باللغة الطبيعية.

## Agent

تمت إضافة نقطة دخول جديدة لمحادثة Agent في لوحة التحكم، حيث يمكنك إجراء محادثة متعددة الجولات مع نموذج ذكاء اصطناعي؛ يقوم الذكاء الاصطناعي تلقائياً باستدعاء الأدوات المدمجة لإنجاز المهام.

**القدرات الأساسية:**

- **دعم نماذج متعددة** — تنسيقات متوافقة مع OpenAI ونظام Anthropic الأصلي، مع دعم Prompt Caching
- **11 أداة مدمجة** — جلب/بحث الويب، إدارة التبويبات، نظام ملفات OPFS، تنفيذ الكود، التفاعل مع المستخدم، والمزيد
- **نظام Skills** — حزم من التعليمات + سكرپتات أدوات + مواد مرجعية توسع المعرفة المجالية للـ Agent
- **تكامل MCP** — يدعم [Model Context Protocol](https://modelcontextprotocol.io/) للاتصال بخوادم أدوات خارجية
- **أتمتة DOM** — التنقل في الصفحات، لقطات الشاشة، النقر، التعبئة، التمرير، تنفيذ السكرپتات، والمزيد
- **المهام المجدولة** — جدولة المهام عبر تعبيرات Cron (أنماط داخلية / أحداث)
- **الوكلاء الفرعيون** — يمكن إنشاء وكلاء فرعيين مستقلين للتعامل مع المهام الفرعية المعقدة
- **إدارة السياق** — الضغط التلقائي وPrompt Caching لتقليل استهلاك الرموز

**واجهة برمجة السكرپت (`CAT.agent.*`) :**

يمكن لسكرپتات المستخدم استدعاء قدرات الـ Agent عبر مساحة الأسماء `CAT.agent.*`، بما في ذلك واجهات المحادثة وdom والـ Skills والمهام والنموذج وopfs وmcp. تتطلب كل واجهة الإعلان عن الإذن المقابل باستخدام `@grant`.

**6 صفحات في لوحة التحكم:** المحادثة، إعدادات النموذج، إدارة الـ Skills، المهام المجدولة، خوادم MCP، ومتصفح OPFS.

## دعم وسم `@unwrap`

يتيح حقن سكرپت مباشرة في الصفحة، متجاوزاً غلاف الحماية.

## حدث `window.onurlchange`

تنفيذ الاستماع لتغييرات عنوان URL المتوافق مع Tampermonkey باستخدام Navigation API.

## تحسينات المحرر

إضافة قائمة تحرير (بحث، استبدال، تراجع، إلخ)، وإصلاح العديد من مشاكل اختصارات لوحة المفاتيح والتلميحات.

## محركات بحث متعددة المنصات

أصبح اكتشاف السكرپتات يدعم الآن الاختيار بين منصات محركات بحث مختلفة.

## المزيد من مزودي الأيقونات

إضافة المزيد من مزودي خدمات أيقونات السكرپتات.
