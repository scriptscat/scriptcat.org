---
title: تكامل MCP
---

MCP ([Model Context Protocol](https://modelcontextprotocol.io/)) يتيح لـ Agent الاتصال بخوادم MCP الخارجية والحصول تلقائياً على الأدوات والموارد وقوالب المطالبات التي توفرها.

> على عكس الأنظمة الفرعية الأخرى في Agent، لا يمكن **تكوين خوادم MCP حالياً إلا من قبل المستخدم على صفحة الإدارة** — لا توجد واجهة برمجية لإدارة `CAT.agent.mcp` للسكرپتات. كل ما يمكن للسكرپت ملاحظته هو أن أدوات هذه الخوادم تُستدعى تلقائياً أثناء الحوارات.

## تكوين خادم MCP

أضف واحداً على صفحة الإدارة → **Agent → MCP**:

| الحقل | الوصف |
|------|------|
| الاسم | اسم العرض للخادم |
| الرابط (URL) | نقطة نهاية HTTP Streamable (JSON-RPC 2.0 عبر POST) |
| مفتاح API | اختياري، للمصادقة |
| الترويسات المخصصة | اختيارية |
| مفعّل | يحدد ما إذا كان الخادم نشطاً |

يستخدم عميل MCP في ScriptCat النقل **Streamable HTTP** ويدعم إصدار البروتوكول `2025-03-26`.

يمكن لخادم MCP توفير ثلاثة أنواع من القدرات:

| القدرة | الوصف |
|------|------|
| **أدوات** | تُسجل تلقائياً كأدوات يمكن لـ Agent استدعاءها |
| **موارد** | موارد قابلة للقراءة (نص/ثنائي) |
| **مطالبات** | قوالب مطالبات، مع دعم المعلمات |

## الاستخدام في حوار

تظهر أدوات خوادم MCP المفعّلة تلقائياً في قائمة الأدوات المتاحة لحوارات Agent، مسماة وفق النمط `mcp_{اسم الخادم المعقّم}_{toolName}` — يقرر الذكاء الاصطناعي ما إذا كان سيستدعيها بناءً على نية المستخدم. يعمل هذا بشكل مشابه لتحميل [Skills](../agent-skill-install) تلقائياً؛ عادةً لا يحتاج مطورو السكرپتات إلى القلق بشأن التفاصيل الأساسية.

للتحقق مما إذا كانت أداة MCP محددة متاحة، ما عليك سوى سؤال الذكاء الاصطناعي مباشرة في حوار، أو التحقق من قائمة الأدوات المكتشفة في تفاصيل ذلك الخادم على صفحة الإدارة.
