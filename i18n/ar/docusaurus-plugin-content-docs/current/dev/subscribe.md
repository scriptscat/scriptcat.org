title: وضع الاشتراك
---

يجب أن يبدأ الملف بـ `UserSubscribe` بدلاً من `UserScript`. يجب أن يستخدم رابط التثبيت امتداد `user.sub.js`، ويجب أن يكون رابطاً `https`.

يعرض سكرپت الاشتراك مربع حوار التثبيت فقط ليؤكد المستخدم الاشتراك عند التثبيت؛ التحديثات اللاحقة صامتة، ولا يُعرض مربع حوار التحديث مرة أخرى إلا إذا تغير إذن `connect`.

يمكن لسكرپت اشتراك واحد وصف روابط التثبيت لعدة سكرپتات. تُثبت السكرپتات المثبتة عبر وضع الاشتراك بصمت، دون مربع حوار تأكيد، ولا تزال السكرپتات المثبتة تظهر في قائمة السكرپتات — لكن إذن `connect` الخاص بها يستخدم `connect` المُصرح عنه في الاشتراك بدلاً من إذن `connect` الخاص بالسكرپت نفسه.

```js
// ==UserSubscribe==
// @name         xxx
// @description  Subscribe to the xxx script series
// @version      0.1.0
// @author       You
// @connect      www.baidu.com
// @scriptUrl    https://script.tampermonkey.net.cn/48.user.js
// @scriptUrl    https://script.tampermonkey.net.cn/49.user.js
// ==/UserSubscribe==
```

## تحديثات الاشتراك وتحديثات السكرپت

وفقاً لـ `فاصل التحديث` الذي يكوّنه المستخدم، يفحص ScriptCat دورياً رابط الاشتراك بحثاً عن التحديثات؛ يجب تكوين `version` لكي يسري هذا المفعول.

يقارن كل تحديث أو تغيير في الاشتراك روابط السكرپت بالسكرپتات المثبتة حالياً: تتم إزالة السكرپتات التي لم تعد موجودة في الاشتراك الجديد، وتُثبت السكرپتات المضافة حديثاً بصمت. تتبع تحديثات السكرپت `version` الخاص بالسكرپت نفسه، باستخدام نفس منطق التحديث المتبع مع السكرپت المثبت بشكل عادي.

## التثبيت والتحديث الصامت

تُثبت السكرپتات المشتركة وتُحدَّث بصمت — إضافة أو إزالة أو تحديث سكرپت من اشتراك يعرض إشعاراً فقط، دون طلب تأكيد المستخدم مرة أخرى. بسبب آلية التحديث الصامت هذه، يرجى الاشتراك فقط في المصادر التي تثق بها.


## البيانات الوصفية

يتغير معنى بعض حقول البيانات الوصفية داخل سكرپت اشتراك.

### name

اسم الاشتراك (يمكن أيضاً تحريره مباشرة في قائمة الاشتراكات)

### description

وصف الاشتراك، الذي يصف الغرض من الاشتراك

### version

إصدار الاشتراك. إذا تم حذفه، يتم بدلاً من ذلك تفعيل التحديثات بناءً على ما إذا كان محتوى سكرپت الاشتراك قد تغير.

### connect

يطلب إذن الوصول إلى موقع؛ راجع `GM_cookie` و `GM_xmlhttpRequest`. للسكرپتات المثبتة عبر وضع الاشتراك، يتم تجاوز `connect` بواسطة `connect` الخاص بالاشتراك.

### scriptUrl

روابط تثبيت السكرپت المطلوبة بواسطة الاشتراك
