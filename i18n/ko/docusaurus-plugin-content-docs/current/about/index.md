## ScriptCat 소개

Tampermonkey의 디자인에서 영감을 받고 Tampermonkey 스크립트와 호환되는 ScriptCat은 백그라운드 스크립트 실행 프레임워크를 구현하고 스크립트가 더 많은 일을 할 수 있게 해주는 여러 특수 API를 제공하며, 스크립트 코드 작성과 개발을 더 편안하고 유연하게 만들어 주는 훌륭한 편집기를 제공합니다.

개발 로드맵은 [프로젝트 #1](https://github.com/scriptscat/scriptcat/projects/1)을 참조하세요. 여기에서 개발 계획을 공개합니다. 제안 사항이 있으면 언제든지 [issue](https://github.com/scriptscat/scriptcat/issues)를 열어 알려주세요.

**유용하다고 생각되시면 별(Star)을 눌러 주세요 ❤❤❤**

## Tampermonkey 중국어 포럼
> [여기를 클릭하여 방문](https://bbs.tampermonkey.net.cn/)

Tampermonkey 중국어 포럼은 Tampermonkey 스타일 스크립트를 개발하고 논의하기 위해 우리가 만든 커뮤니티입니다. 포럼에는 풍부한 스크립트 학습 자료와 경험 많은 회원들이 있으므로 자유롭게 토론하고 질문할 수 있습니다. 또한 스크립트 게시와 설치도 지원하므로 누구나 자신의 작업을 자유롭게 공유할 수 있습니다.
