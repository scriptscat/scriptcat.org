이 확장 프로그램은 세 가지 유형의 스크립트를 지원합니다:

- 전경 스크립트
- [백그라운드 스크립트](./background.md)
- [예약 스크립트](./background.md#scheduled-script-crontab)

전경 스크립트는 사람들이 일반적으로 Tampermonkey 스크립트라고 부르는 것입니다. 백그라운드 스크립트와 예약 스크립트는 ScriptCat 확장 프로그램에 특화된 스크립트 유형입니다 — 자세한 내용은 해당 문서를 참조하세요.

이 문서를 사용하여 [Tampermonkey의 API](./api.md)와 [ScriptCat의 백그라운드 스크립트](./background.md)에 대해 배울 수 있습니다. 또한 풍부한 학습 리소스가 있는 [Tampermonkey 스크립트 개발 가이드](https://learn.scriptcat.org/) 사이트도 운영하고 있습니다 — 토론에 참여하신 것을 환영합니다.

문서에서 부족한 부분을 발견하면 [GitHub](https://github.com/scriptscat/scriptcat.org)를 통해 알려주거나, 개선을 위해 PR을 보내주세요.
