---
title: MCP 통합
---

MCP([Model Context Protocol](https://modelcontextprotocol.io/))를 사용하면 Agent가 외부 MCP 서버에 연결하고 제공하는 도구, 리소스 및 프롬프트 템플릿에 자동으로 액세스할 수 있습니다.

> Agent의 다른 하위 시스템과 달리 MCP 서버는 현재 **사용자가 관리 페이지에서만 구성할 수 있습니다** — 스크립트용 `CAT.agent.mcp` 관리 API는 없습니다. 스크립트가 관찰할 수 있는 것은 이러한 서버의 도구가 대화 중에 자동으로 호출된다는 것뿐입니다.

## MCP 서버 구성

관리 페이지 → **Agent → MCP**에서 추가하세요:

| 필드 | 설명 |
|------|------|
| 이름 | 서버의 표시 이름 |
| URL | Streamable HTTP 엔드포인트 (POST를 통한 JSON-RPC 2.0) |
| API 키 | 선택 사항, 인증용 |
| 사용자 지정 헤더 | 선택 사항 |
| 활성화 | 서버가 활성 상태인지 여부 |

ScriptCat의 MCP 클라이언트는 **Streamable HTTP** 전송을 사용하며 프로토콜 버전 `2025-03-26`을 지원합니다.

MCP 서버는 세 가지 종류의 기능을 제공할 수 있습니다:

| 기능 | 설명 |
|------|------|
| **도구** | Agent가 호출할 수 있는 도구로 자동 등록 |
| **리소스** | 읽을 수 있는 리소스 (텍스트/바이너리) |
| **프롬프트** | 매개변수를 지원하는 프롬프트 템플릿 |

## 대화에서 사용

활성화된 MCP 서버의 도구는 `mcp_{정리된 서버 이름}_{toolName}` 패턴으로 명명되어 Agent 대화에서 사용할 수 있는 도구 목록에 자동으로 나타납니다. AI는 사용자 의도에 따라 호출 여부를 결정합니다. 이는 [Skill](../skill-install)이 자동으로 로드되는 방식과 유사하게 작동하므로 스크립트 개발자는 일반적으로 기본 세부 사항에 대해 걱정할 필요가 없습니다.

특정 MCP 도구를 사용할 수 있는지 확인하려면 대화에서 AI에게 직접 물어보거나 관리 페이지의 해당 서버 세부 정보에서 발견된 도구 목록을 확인하세요.
