ScriptCat은 회사의 지원 없이 자원봉사자들이 유지 관리하는 오픈소스 프로젝트입니다. 서버, 도메인 및 기타 인프라와 많은 개발 및 유지 관리 시간은 모두 커뮤니티 지원으로 유지됩니다. 모든 기여는 ScriptCat이 더 멀리 나아가는 데 도움이 됩니다.

## 후원금의 사용처

후원 수입은 주로 다음에 사용됩니다:

- **운영 비용 충당** — 서버, 도메인 및 기타 일상적인 인프라.
- **유지 관리자 및 기여자 보상** — 장기 유지 관리자와 코드, 번역, 문서를 보내주는 모든 사람이 받을 만한 보상을 받도록.
- **새 기능 개발** — 경험을 다듬고 새로운 기능을 개발할 시간 확보.

## 후원 방법

개인이든 회사든, 규모에 관계없이 모든 지원이 소중합니다.

[OpenCollective](https://opencollective.com/scriptcat)를 통해 일회성 또는 월간 기부로 후원을 받고 있습니다. 기부 후에는 후원자 목록에 이름이 표시됩니다.

**후원자 배치**를 원하시면 — README, 웹사이트 또는 문서에 로고와 소개를 게재하는 것 — [codfrm@gmail.com](mailto:codfrm@gmail.com)으로 이메일을 보내주세요.

## 후원자 배치

후원자의 로고와 설명은 이메일로 협의하여 다음 위치에 표시할 수 있습니다:

| 배치 위치 | 형식 |
| --- | --- |
| GitHub README 상단 | 대형 배너 |
| GitHub README 후원자 영역 | 로고 + 한 줄 소개 |
| 웹사이트 후원 페이지 (이 페이지) | 로고 + 소개 |
| 웹사이트 문서 페이지 (예: 변경 로그) | 로고 표시 |
