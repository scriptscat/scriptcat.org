## 상세 설명

### 1. 당사는 어떤 개인정보도 수집하지 않습니다

ScriptCat의 설계 철학은 사용자 프라이버시를 보호하는 것입니다. 당사 제품은:

- 귀하의 개인 식별 정보(이름, 이메일, 전화번호 등)를 **수집하지 않습니다**
- 귀하의 브라우징 기록, 검색 기록 또는 기타 온라인 활동 데이터를 **수집하지 않습니다**
- 귀하의 기기 정보, 위치 정보 또는 기타 기술 식별자를 **수집하지 않습니다**
- 귀하가 설치한 스크립트 콘텐츠나 사용 환경 설정을 **수집하지 않습니다**

### 2. 로컬 데이터 처리

ScriptCat의 핵심 기능은 전적으로 귀하의 로컬 기기에서 실행됩니다:

- 사용자 스크립트와 그 구성은 주로 귀하의 로컬 브라우저에 저장됩니다
- 모든 스크립트 실행 및 데이터 처리는 로컬에서 완료됩니다
- 당사는 귀하의 스크립트 콘텐츠, 브라우징 데이터 또는 기타 개인정보에 접근할 수 없습니다

**클라우드 동기화 기능에 대해:**

- 클라우드 동기화는 선택 기능으로, 귀하가 적극적으로 활성화해야 합니다
- 동기화 데이터는 귀하의 기기와 선택한 클라우드 서비스 사이에서 직접 전송됩니다
- 동기화 서비스의 안정성을 보장하기 위해 필요한 기술 자격 증명을 일시적으로 저장하지만, 귀하의 동기화 콘텐츠에는 접근하지 않습니다

### 3. 데이터 보안 보장

당사는 어떤 개인정보도 수집하지 않으므로 개인정보 저장 문제가 없습니다. 당사는 약속합니다:

- 귀하의 모든 데이터는 귀하의 기기에 저장됩니다
- 당사는 귀하의 로컬 데이터에 접근할 수 없습니다
- 원하더라도 귀하의 개인정보를 얻을 수 없습니다

- 스크립트를 설치하기 전에 기능과 권한을 이해할 것을 권장합니다
