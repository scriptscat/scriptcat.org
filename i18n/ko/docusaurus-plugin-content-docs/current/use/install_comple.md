# 🎉 ScriptCat에 오신 것을 환영합니다

ScriptCat 브라우저 확장 프로그램을 성공적으로 설치하신 것을 축하합니다! ScriptCat은 Tampermonkey 스크립트와 호환되는 강력한 사용자 스크립트 관리자이며 훨씬 더 많은 강력한 기능을 제공합니다.

<GithubStar variant="bar" scene="install" />

## 보안 공지

⚠️ **사용자 스크립트는 강력한 기능을 가지므로 보안이 중요합니다!**

사용자 스크립트는 강력한 기능을 가지며 웹 페이지 콘텐츠에 접근하고 수정할 수 있으므로 **보안이 중요합니다**. 개인 정보와 기기 보안을 보호하기 위해 다음을 확인하세요:

- ✅ **신뢰할 수 있는 스크립트 사이트에서만 스크립트를 설치하세요**
- ✅ **스크립트 평점과 사용자 댓글을 주의 깊게 검토하세요**
- ✅ **스크립트의 기능과 권한 요구 사항을 이해하세요**
- ❌ **알 수 없거나 의심스러운 출처의 스크립트 다운로드를 피하세요**
- ❌ **출처를 알 수 없는 스크립트 파일을 설치하지 마세요**

### 권장되는 신뢰할 수 있는 스크립트 출처

다음 스크립트 사이트에서 스크립트를 받을 것을 권장합니다:

- **[ScriptCat 스크립트 사이트](https://scriptcat.org/)** - ScriptCat이 유지 관리하는 공식 스크립트 사이트
- **[GreasyFork](https://greasyfork.org/)** - 세계 최대의 사용자 스크립트 사이트
- **[Userscript.Zone](https://www.userscript.zone/)** - 엄선된 고품질 스크립트

## 다음 단계

### 스크립트 관리 인터페이스 접근

브라우저 도구 모음에서 ScriptCat 아이콘을 클릭한 다음 오른쪽 상단의 "⚙️" 기어 버튼을 클릭하여 관리 인터페이스로 들어갑니다.

### 첫 번째 스크립트 받기

팝업 인터페이스에서 오른쪽 상단의 "⋮" 메뉴를 클릭하고 "스크립트 받기"를 선택하여 공식 스크립트 사이트에서 스크립트를 검색하고 설치합니다.

### 기능 살펴보기

- 📊 **스크립트 관리**: 스크립트 활성화/비활성화, 실행 상태 확인
- 🔧 **사용자 설정**: 스크립트 매개변수 및 실행 규칙 구성
- 📝 **스크립트 편집**: 자신만의 스크립트 생성 및 편집
- 🔄 **데이터 동기화**: 여러 기기에서 스크립트 구성 동기화

## 사용 권장 사항

1. **작게 시작**: 새 사용자는 단순하고 평점이 높은 스크립트부터 시작하는 것이 좋습니다
2. **정기 확인**: 설치된 스크립트를 정기적으로 확인하고 업데이트하세요
3. **구성 백업**: 중요한 스크립트 구성은 백업해야 합니다
4. **문제 보고**: 문제가 발생하면 [GitHub](https://github.com/scriptscat/scriptcat) 또는 공식 커뮤니티를 통해 피드백할 수 있습니다

## 면책 조항

ScriptCat을 사용할 때 다음을 이해해야 합니다:

- ScriptCat은 스크립트 실행 환경을 제공하지만 타사 스크립트의 보안, 기능 또는 콘텐츠에 대해 책임을 지지 않습니다
- 타사 스크립트 사용에 따른 위험은 사용자가 직접 부담합니다
- 스크립트의 기능을 이해했는지 확인하기 위해 스크립트의 소스 코드와 문서를 주의 깊게 읽는 것이 좋습니다

자세한 면책 조항은 다음을 참조하세요: [전체 면책 조항](/docs/use/policy/disclaimer/)
