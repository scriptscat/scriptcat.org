> 먼저 [빠른 시작](/docs/use/use/)을 참조하여 ScriptCat 확장 프로그램을 설치하세요.

## 다양한 웹사이트에서의 설치 단계

### ScriptCat 커뮤니티

[ScriptCat 커뮤니티](https://scriptcat.org/search) ScriptCat 공식 사이트

### Userscript.Zone

[Userscript.Zone](https://www.userscript.zone/)은 적절한 URL이나 도메인을 입력하여 사용자 스크립트를 검색할 수 있는 새로운 웹사이트입니다.

- **많은 스크립트 리소스**
- **적합한 사용자 스크립트를 쉽게 찾을 수 있음**
- **검토된 사용자 스크립트 페이지 또는 최소한 댓글 기능이 있는 페이지만 표시**

### GreasyFork

[GreasyFork](https://greasyfork.org/)는 사용자 스크립트를 호스팅하고 공유하는 널리 사용되는 플랫폼으로, 개발자가 게시하고 사용자가 웹사이트 기능을 향상하거나 수정하는 브라우저 기반 스크립트를 설치할 수 있게 해줍니다. 이 사이트는 Jason Barnabe가 만들었으며 보안과 오픈소스 투명성을 강조하는 것으로 유명하며, 브라우징 경험을 개선하는 많은 스크립트를 제공합니다.

Jason Barnabe는 Stylish 브라우저 확장 프로그램의 원래 제작자이기도 합니다. 그러나 [Stylish](https://userstyles.org/)는 2016년에 매각되어 현재 다른 회사가 운영하고 있으며, 이후 개발에 Jason Barnabe가 직접 관여하지 않았습니다.

- **많은 스크립트 리소스**
- **Github에서 스크립트를 동기화하는 기능**
- **매우 활발한 오픈소스 개발 모델**

### OpenUserJS

[OpenUserJS](https://openuserjs.org/)는 GreasyFork 이후에 만들어졌습니다. Sizzle McTwizzle이 만들었으며, 마찬가지로 저장소에 많은 스크립트 리소스가 있습니다.

- **Github에서 스크립트 동기화 및 스크립트 포크 기능**
- **매우 활발한 오픈소스 개발 모델**

### GitHub/Gist

Github과 Gist에서 스크립트 리소스를 검색할 수 있습니다.


## 수동 스크립트 설치

1. ScriptCat 확장 프로그램 아이콘을 클릭합니다
2. 인터페이스의 "기어 버튼"을 클릭하여 ScriptCat 관리 인터페이스로 들어갑니다
3. 오른쪽 상단의 "새 스크립트 만들기" 버튼을 클릭합니다 (일반적으로 일반 스크립트를 만드는 것으로 충분합니다)
4. 팝업 페이지에 스크립트 코드를 붙여넣습니다
5. `ctrl + s`를 눌러 변경 사항을 저장합니다
6. 관리 인터페이스로 돌아가 새로 만든 스크립트를 확인합니다
