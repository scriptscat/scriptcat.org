수정: 버전 업데이트 시 더 이상 변경 로그 페이지가 자동으로 열리지 않습니다

## 스크립트 목록 사이드바 [#794](https://github.com/scriptscat/scriptcat/issues/794)

사이드바에 고급 필터링과 태그 기능이 추가되었습니다. 태그는 스크립트 → 설정에서 편집할 수 있습니다.

![image-20251016230129315](@site/docs/change/v1.2.assets/image-20251016230129315.png)

## 카드 보기 [#860](https://github.com/scriptscat/scriptcat/issues/860)

카드 보기가 추가되었습니다. 첫 실행 시 카드 보기와 테이블 보기가 자동으로 전환되므로 좁은 화면에서도 스크립트 정보를 더 잘 표시할 수 있습니다.

![image-20251023103730266](@site/docs/change/v1.2.assets/image-20251023103730266.png)

## 더 친숙한 업데이트 확인 로직 [#755](https://github.com/scriptscat/scriptcat/issues/755)

업데이트 확인 로직이 개선되었습니다. 모든 스크립트에 대해 한꺼번에 업데이트 프롬프트를 띄우는 대신, 이제 하나의 업데이트 창으로 통합되어 업데이트할 스크립트를 선택하거나 한 번의 클릭으로 모두 업데이트할 수 있습니다. 각 스크립트의 변경량도 표시됩니다.

![image-20251016225931823](@site/docs/change/v1.2.assets/image-20251016225931823.png)

## 편집기 구성 및 편집기 유형 정의 추가 [#708](https://github.com/scriptscat/scriptcat/pull/708)

이제 편집기 구성과 편집기 유형 정의를 사용자 지정할 수 있습니다. 편집기 구성은 `tsconfig.json`의 [compilerOptions](https://www.typescriptlang.org/tsconfig/#compilerOptions)를 참조하여 작성할 수 있습니다.

![08c2889f-3029-4d3c-b180-c52d77c8077c](@site/docs/change/v1.2.assets/08c2889f-3029-4d3c-b180-c52d77c8077c.png)

## 백그라운드 실행 옵션 [#1048](https://github.com/scriptscat/scriptcat/pull/1048)

설정 → 실행 아래에 백그라운드 실행 옵션이 추가되었습니다. 활성화하면 모든 창이 닫힌 후에도 브라우저가 백그라운드에서 계속 실행되고 시스템 트레이로 최소화되어, 수동으로 브라우저를 종료할 때까지 유지됩니다. 이를 통해 백그라운드 스크립트가 계속 실행될 수 있습니다.

![image-20251204174034940](@site/docs/change/v1.2.assets/image-20251204174034940.png)

## API 업데이트

- `inject-into` 지원 — 이제 스크립트를 콘텐츠 환경에 주입할 수 있습니다 [#711](https://github.com/scriptscat/scriptcat/issues/711)
- `GM_openInTab`이 탭 고정, 시크릿 창에서 열기 등의 매개변수를 지원합니다 [#788](https://github.com/scriptscat/scriptcat/pull/788)
- `GM_registerMenuCommand`가 2단계 메뉴와 구분선을 지원합니다 [#831](https://github.com/scriptscat/scriptcat/pull/831)
