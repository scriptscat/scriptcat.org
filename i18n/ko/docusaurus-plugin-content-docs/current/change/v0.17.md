v0.17.0부터 ScriptCat은 Manifest V3로 업그레이드되었고 저장 엔진이 `indexedDB`에서 `chrome.storage.local`로 전환되었습니다. 저장 엔진 전환 시 이 페이지가 자동으로 열리며 확장 프로그램이 다시 시작됩니다. 데이터 문제가 발견되면 [GitHub](https://github.com/scriptscat/scriptcat/issues)에서 알려주세요.

## v0.17.0-alpha

Manifest V3에 맞게 리팩토링하고 저장 엔진을 전환했으며 일부 기능을 수정했습니다

- Tampermonkey와의 일관성을 위해 `GM_xmlhttpRequest`에서 `maxRedirects`를 제거하고 `redirect`를 사용합니다
- `GM_cookie`의 `store` 메서드와 `storeId`, `tabId`를 제거했습니다. 쿠키 가져오기는 이제 현재 페이지의 `store`를 직접 사용합니다 (예: 시크릿 창과 일반 창은 서로 다른 store를 가짐)
- `@require-css` 제거
