v1.4는 ScriptCat의 주요 업데이트로, 자연어 대화를 통해 브라우저 작업 자동화, 웹 데이터 추출, 파일 관리, 예약 작업 실행을 가능하게 하는 완전히 새로운 **Agent** 시스템을 도입합니다.

## Agent

대시보드에 AI 모델과 다중 턴 대화를 나눌 수 있는 새로운 Agent 채팅 진입점이 추가되었습니다. AI는 작업을 완료하기 위해 자동으로 내장 도구를 호출합니다.

**핵심 기능:**

- **멀티 모델 지원** — OpenAI 호환 및 네이티브 Anthropic 형식, Prompt Caching 지원
- **11가지 내장 도구** — 웹 가져오기/검색, 탭 관리, OPFS 파일 시스템, 코드 실행, 사용자 상호작용 등
- **Skill 시스템** — Agent의 도메인 지식을 확장하는 프롬프트 + 도구 스크립트 + 참고 자료 패키지
- **MCP 통합** — 외부 도구 서버에 연결하기 위한 [Model Context Protocol](https://modelcontextprotocol.io/) 지원
- **DOM 자동화** — 페이지 탐색, 스크린샷, 클릭, 입력, 스크롤, 스크립트 실행 등
- **예약 작업** — Cron 표현식 기반 작업 스케줄링 (내부/이벤트 모드)
- **하위 에이전트** — 복잡한 하위 작업을 처리하기 위해 독립적인 하위 에이전트 생성 가능
- **컨텍스트 관리** — 토큰 사용량을 줄이기 위한 자동 압축 및 Prompt Caching

**스크립트 API (`CAT.agent.*`):**

사용자 스크립트는 `CAT.agent.*` 네임스페이스를 통해 conversation, dom, skills, task, model, opfs, mcp API를 포함한 Agent 기능을 호출할 수 있습니다. 각 API는 해당 권한을 `@grant`로 선언해야 합니다.

**대시보드 6개 페이지:** 채팅, 모델 설정, Skill 관리, 예약 작업, MCP 서버, OPFS 브라우저.

## `@unwrap` 태그 지원

스크립트를 샌드박스 래퍼를 우회하여 페이지에 직접 주입할 수 있게 합니다.

## `window.onurlchange` 이벤트

Navigation API를 사용하여 Tampermonkey 호환 URL 변경 이벤트 리스닝을 구현합니다.

## 편집기 개선

편집 메뉴(찾기, 바꾸기, 실행 취소 등)가 추가되고 여러 키보드 단축키 및 힌트 문제가 수정되었습니다.

## 다중 플랫폼 검색 엔진

스크립트 검색에서 이제 다양한 검색 엔진 플랫폼을 선택할 수 있습니다.

## 더 많은 아이콘 제공자

더 많은 스크립트 아이콘 서비스 제공자가 추가되었습니다.
