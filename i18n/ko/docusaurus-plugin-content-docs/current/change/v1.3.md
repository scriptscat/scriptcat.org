## 새로운 스크립트 설치 흐름 [#842](https://github.com/scriptscat/scriptcat/issues/842)

스크립트 설치 흐름이 재설계되었습니다. 더 이상 외부 웹사이트 리디렉션에 의존하거나 새 창을 열지 않으며, 이제 스크립트가 현재 페이지 안에서 직접 설치됩니다. 설치 페이지 레이아웃도 반응형 디자인, 스크롤 가능한 코드 미리보기, 다운로드 실패 시 인라인 오류 표시로 최적화되었습니다.

## 스크립트 실행 시점 옵션 [#895](https://github.com/scriptscat/scriptcat/issues/895)

스크립트 설정에 실행 시점 옵션이 추가되어 `document-start`, `document-body`, `document-end`, `document-idle`, `early-start` 등에서 선택할 수 있어 스크립트가 실행되는 시점을 정밀하게 제어할 수 있습니다.

![스크립트 실행 시점 옵션](v1.3.assets/run-timing.png)

## Amazon S3 스토리지 지원 [#1146](https://github.com/scriptscat/scriptcat/issues/1146)

클라우드 동기화 및 백업은 이제 WebDAV, Baidu Netdisk, OneDrive, Google Drive, Dropbox와 같은 기존 옵션에 더해 Amazon S3를 스토리지 백엔드로 지원합니다.

![Amazon S3 스토리지 옵션](v1.3.assets/s3-storage.png)

## 클라우드 스토리지 연결 해제 [#1151](https://github.com/scriptscat/scriptcat/issues/1151)

클라우드 동기화 설정에 연결 해제 버튼이 추가되어 클라우드 스토리지 연결을 쉽게 끊거나 전환할 수 있습니다.
