:::caution 테스트 단계
v1.5는 현재 베타 테스트 단계에 있습니다. 아래의 기능은 정식 출시 전에 변경될 수 있으며, 사용해 보시고 피드백을 주시면 감사하겠습니다. [GitHub Discussions](https://github.com/scriptscat/scriptcat/discussions)에서 새 UI/UX에 대한 논의에 참여할 수도 있습니다.

v1.5는 ScriptCat 인터페이스의 전면 재구축입니다. 더 깔끔하고, 일관되고, 사용하기 쉬우며, 모바일 전용 최적화가 포함되어 데스크톱과 모바일 사용자 모두 더 나은 경험을 얻을 수 있습니다.

## 완전히 새로운 인터페이스 [#1514](https://github.com/scriptscat/scriptcat/pull/1514)

전체 인터페이스가 완전히 재구축되어 더 일관된 비주얼 스타일, 더 명확한 계층 구조, 완전한 라이트/다크 테마 지원을 갖추었습니다. 스크립트 목록은 테이블 및 카드 보기를 제공하며 상태, 유형, 태그, 소스별 고급 필터링을 지원하므로 많은 스크립트를 관리하기 편안합니다.

![새로운 데스크톱 인터페이스](v1.5.assets/desktop.png)

## 모바일 최적화

레이아웃은 이제 확장 프로그램을 지원하는 모바일 브라우저(예: Android용 Edge 및 Kiwi)를 위해 특별히 설계되었습니다. 스크립트 목록은 카드로 표시되고, 하단 탐색 모음이 제공되며, 왼쪽 서랍에서 구독, 로그, 도구, 설정에 빠르게 접근할 수 있고, 확장 프로그램 팝업도 좁은 화면에 적응합니다.

![모바일 인터페이스](v1.5.assets/mobile.png)

## 💥 외부 접근 (MCP 브리지) [#1573](https://github.com/scriptscat/scriptcat/pull/1573)

로컬 `sctl` 데몬을 통해 CLI 및 MCP 클라이언트가 ScriptCat에 통일된 방식으로 접근할 수 있습니다. 스크립트 메타데이터 나열/읽기, 설치, 활성화/비활성화, 삭제, 편집은 모두 **계층화된 권한 부여 및 인간 확인 페이지**로 보호되며, 거부 / 허용 / 이 세션만 허용의 세 단계가 있고 모든 작업은 감사 로그에 기록됩니다.

## 💥 스크립트 휴지통 [#1585](https://github.com/scriptscat/scriptcat/pull/1585)

삭제된 스크립트는 더 이상 즉시 파괴되지 않고 먼저 휴지통으로 이동하며, **복원**(원래 스크립트 데이터와 권한 보존), 영구 삭제, 보존 기간 기반 자동 정리를 지원합니다. 보존 기간은 기본 30일이며 설정에서 조정하거나 '없음'으로 설정할 수 있습니다.

## 💥 공식 Firefox MV3 지원 [#1561](https://github.com/scriptscat/scriptcat/pull/1561)

개선된 샌드박스/오프스크린 통신으로 ScriptCat MV3가 이제 Firefox 브라우저를 공식 지원합니다.

## 편집기에서 스크립트 유형 선택 [#1544](https://github.com/scriptscat/scriptcat/pull/1544)

편집기 탭 모음의 "＋"를 사용하면 목록 페이지로 돌아가지 않고도 만들 스크립트 유형(일반/백그라운드/예약)을 직접 선택할 수 있습니다.

## 로컬 백업 수동 다운로드 [#1543](https://github.com/scriptscat/scriptcat/pull/1543)

로컬 백업에 수동 다운로드 링크가 추가되어 백업 파일을 기기로 직접 내보낼 수 있습니다.

## Chromium 148+의 structured_clone 메시징 [#1534](https://github.com/scriptscat/scriptcat/pull/1534)

Chromium 148+에서 내부 확장 메시지는 `structured_clone` 직렬화를 사용하여 더 다양한 데이터 유형을 지원합니다.

## 기타 개선 사항

- **GM API**: 네이티브 `GM_download`가 이제 `GM_xmlhttpRequest`와 일관되게 `@connect`를 존중합니다 [#1506](https://github.com/scriptscat/scriptcat/pull/1506)
- **성능**: 스크립트 로딩 캐시 개선 및 남아있는 팝업 메뉴 수정 [#1511](https://github.com/scriptscat/scriptcat/pull/1511)
- **편집기**: `eslint-plugin-userscripts` 규칙 조정 [#1510](https://github.com/scriptscat/scriptcat/pull/1510)
- 사전 출시(베타) 업데이트 시 변경 로그 페이지가 자동으로 열립니다
- **수정**: cron이 잘못된 시간대를 자동 감지하여 발생하는 예약 작업 문제 방지 [#1531](https://github.com/scriptscat/scriptcat/pull/1531)
- **수정**: crontab 예제의 사용할 수 없는 데모 API 교체 [#1542](https://github.com/scriptscat/scriptcat/pull/1542)
- **i18n**: 한국어, 터키어, 브라질 포르투갈어 추가
